# Daily note - 2026-09-28

Monday's arXiv listing exposes the Friday, 25 September submission batch. The strongest research and release signals all tighten admission decisions inside agent systems.

## Findings

### 1. Admit shared memory only after lineage-aware evidence

CPB tracks claim sources, writes, retrievals, and downstream adoption. Uncontested false beliefs were repeated in 0.97 to 0.99 of probes. A declared-source-type gate reduced false adoption to 0.06 to 0.09. Repetition inside one lineage is not independent evidence.

Analysis: [AgenticAI](../AgenticAI/2026-09-28/reasoning.md#admit-shared-memory-only-after-lineage-aware-evidence), [Strategy](../Strategy/2026-09-28/sovereignty.md#make-shared-memory-admission-a-provenance-decision)
Sources: [paper](https://arxiv.org/abs/2609.30813v1), [MIT artifact](https://github.com/lxy1134/iclr_2027)
Implementability score: 0.88

### 2. Skip workflow components only with counterfactual evidence

Controlled component omissions let a router learn when planning, verification, or summarization is unnecessary in the current state. The paper reports 8.6 to 31.2 percent token savings while preserving or improving aggregate accuracy, with a documented MMLU case where agreement would have skipped the corrective verifier.

Analysis: [AgenticAI](../AgenticAI/2026-09-28/reasoning.md#skip-workflow-components-only-with-counterfactual-evidence)
Source: [Learning What to Skip](https://arxiv.org/abs/2609.30734v1)
Implementability score: 0.83

### 3. Train tool search against confusing neighbors and full trajectories

ToolSearcher combines hard same-category negatives, event rewards for target discovery, and trajectory credit. It reports F1 of 0.513 versus 0.496 on StableToolBench and task completion of 0.334 versus 0.277 on AppWorld. The public code is populated, but no repository license or release tag was detected.

Analysis: [AgenticAI](../AgenticAI/2026-09-28/reasoning.md#train-tool-search-against-confusing-neighbors-and-full-trajectories)
Sources: [paper](https://arxiv.org/abs/2609.30906v1), [repository](https://github.com/zhenlongDai/ToolSearcher)
Implementability score: 0.72

### 4. Admit MCP credentials independently from tool authority

Codex CLI 0.158.0 adds pre-registered MCP OAuth client secrets and bearer-authenticated exec-server WebSockets. LiteLLM 1.103.0 requires admission for delegated MCP OAuth and preserves request-selected guardrails during tool execution. A credential establishes client identity; gateway policy still decides delegation and effects.

Analysis: [Strategy](../Strategy/2026-09-28/sovereignty.md#admit-mcp-credentials-independently-from-tool-authority)
Sources: [Codex 0.158.0](https://github.com/openai/codex/releases/tag/rust-v0.158.0), [LiteLLM 1.103.0](https://github.com/BerriAI/litellm/releases/tag/v1.103.0)
Implementability score: 0.91
