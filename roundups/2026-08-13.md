# Daily Agent Research Roundup, 2026-08-13

## Thesis

Capability packaging is getting easier, so evaluation must move below the package boundary. The strongest work today measures the tool interface, the full serving cost of memory, and the executable environment that converts context into effects.

## Top findings

1. **Tool architecture changes coding-agent behavior even when capability stays similar.** Six interfaces, three actors, and 11,700 trajectories produced up to 4.7 times better repeat-run consistency; CodeAct-style interfaces used 41.6 percent fewer steps and 56.3 percent fewer tokens. Score: 0.72. Source: https://arxiv.org/abs/2608.11386v1
2. **Memory needs a serving-cost break-even test.** Across three memory systems, two baselines, two backbones, conversations up to 400 turns, and 665 questions, internal memory behavior made simple cost models miss by 18 to 69 percent. Score: 0.82. Source: https://arxiv.org/abs/2608.11879v1
3. **Agent security evaluation should use executable hostile worlds.** ToolHazard generates stateful environments, long tasks, attack points, and deterministic checks across 28 domains. Its public MIT artifact includes environment, task, attack, and result trees. Score: 0.78. Sources: https://arxiv.org/abs/2608.11878v1 and https://github.com/MurrayTom/ToolHazard
4. **Agent Plugins 1.0 is ready for a bounded portability pilot.** GitHub now supports one skill-and-MCP package across VS Code, Copilot CLI, the Copilot SDK, and the Copilot app, with client-specific behavior kept namespaced. Score: 0.96. Sources: https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app/ and https://github.com/agentplugins/agent-plugins-spec/blob/main/spec/1.0.0.md

## What is implementable now

- Package one low-risk skill and one read-only MCP server against Agent Plugins 1.0, then validate it independently in each client.
- Add interface identity to coding-agent traces and compare equivalent-capability interfaces on repeated runs.
- Build a per-stage cost ledger for memory ingest, retrieval, reflection, storage, and answer generation.
- Convert gateway and tool incidents into isolated, stateful adversarial regression environments with deterministic final-state checks.

## Classification

- AgenticAI: tool-interface architecture, memory serving economics, executable security environments, portable plugin packaging.
- Strategy: plugin admission across clients, per-component authority grants, hostile-world release gates.

## Scope and caveats

No external repository was cloned, installed, built, imported, or executed. GitHub artifacts were inspected through metadata, tree listings, and rendered documentation. The tool-architecture paper's advertised repository returned 404, so its artifact is not implementation-ready. ToolHazard is populated and MIT-licensed, but its generated environments still require realism and containment review. Agent Plugins 1.0 is GA in GitHub clients; portability elsewhere remains client-specific.
