# Daily Roundup: 2026-11-18

## The signal

Agent evaluation fails when evidence, cache behavior, or worker handoffs change invisibly. The practical response is a replayable substrate that freezes evidence, prices the full trajectory, preserves conflict, and reruns acceptance tests after every capability change.

## Top findings

### Capture evidence before the answer exists

ForecastGym stores four search providers' results while prediction questions are open, then replays the frozen evidence after settlement. Its first release has 150 questions, 614 evidence states, and 131,000 search results. Retrospective queries exposed the outcome for up to 92 percent of questions despite date filters.

Source: [ForecastGym v1](https://arxiv.org/abs/2611.23045v1)

Implementability score: 0.78

### Measure context by total trajectory cost

Across more than 20,000 coding-agent runs, retrieved evidence reduced search commands by 18 to 34 percent but raised modeled cost by 33 to 42 percent under a one-tenth cached-input price, without a measurable resolution gain. Deleting observations could become more expensive when it broke prefix reuse.

Source: [Context Has a Price v1](https://arxiv.org/abs/2611.22238v1)

Implementability score: 0.88

### Preserve contradictions through delegation

Mandatory delegation retrieved both claims more often but detected fewer conflicts because workers dropped evidence before it reached the lead. A separate ablation found that surfacing ranked conflicts instead of collapsing them improved F1 by 0.340 and reduced successful attacks from 22 to 7 of 122 poisoned items.

Sources: [Multi-Agent Memory Inconsistency v1](https://arxiv.org/abs/2611.22245v1), [Surfacing Disagreement Beats Resolving It v1](https://arxiv.org/abs/2611.22461v1)

Implementability score: 0.82

### Regression-test skills, agents, and MCP tools

GitHub Copilot Evals provides repeatable tasks, explicit run approval, failed-check inspection, and before-and-after comparisons for skills, custom agents, and MCP tools. This is the fastest current route to making capability changes prove themselves.

Source: [GitHub Copilot Evals public preview](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview/)

Implementability score: 0.92

## What to build now

1. Capture time-stamped evidence manifests before outcomes exist.
2. Add cache-aware trajectory accounting to context experiments.
3. Require source-linked claim pairs in worker-to-lead handoffs.
4. Create one owned regression eval for every high-impact skill, agent, or MCP tool.
