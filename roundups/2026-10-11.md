# Daily Agent Research: 2026-10-11

## Scope note

arXiv posted no Sunday announcement batch. Today's papers were submitted October 8 and first listed Friday, October 9. They are the strongest nonduplicate carry-forwards from the newest batch. GitHub's JetBrains control update shipped Saturday, October 10.

## Thesis

The next useful agent control surface is timing. Decide when to inspect, when to reason, when a test has enough evidence, and when a configured tool is allowed to become active.

## Top findings

### 1. Cadence turns runtime review into a feedback controller

Cadence tightens or relaxes monitor intervals based on intervention severity. On 300 SWE-bench Lite tasks, it resolves 76 more mini-swe-agent tasks and 47 more Moatless tasks than vanilla agents. The public MIT repository includes tests, experiment references, a Modal pipeline, and a linked results dataset.

Implementability score: 0.72

Sources: [paper v1](https://arxiv.org/abs/2610.12269v1), [repository](https://github.com/LogAnalysisTech/Cadence), [results dataset](https://huggingface.co/datasets/dengdan1999/Cadence-Experiment-Results)

### 2. TestPrism exposes false confidence from one reference implementation

TestPrism evaluates generated tests against 1,500 valid and 1,500 invalid implementations across 300 tasks. Fourteen coding-agent configurations reach 59.67% against a single reference and only 28.00% under the stricter Joint Success Function.

Implementability score: 0.64

Source: [TestPrism paper v1](https://arxiv.org/abs/2610.12289v1)

### 3. RACE routes reasoning at each turn

RACE trains agents to reuse earlier reasoning until it stops supporting later reference actions. Across four benchmarks, it stays within 1.40 performance points of standard SFT plus GRPO while cutting reasoning tokens by 32.3% to 80.2%, depending on the benchmark.

The named public repository is empty, and the method requires SFT plus reinforcement learning. Treat the architecture as promising and artifact-not-ready.

Implementability score: 0.42

Sources: [RACE paper v1](https://arxiv.org/abs/2610.12061v1), [currently empty repository](https://github.com/HututuAI/RACE)

### 4. GitHub adds an explicit MCP startup control

Copilot for JetBrains can now disable automatic MCP server startup for Copilot and Claude. Enterprise administrators can also set a default agent model, although users retain the model picker. The MCP setting is an immediate capability-activation control; the model setting is fleet guidance rather than hard enforcement.

Implementability score: 0.96

Source: [GitHub release](https://github.blog/changelog/2026-10-10-new-controls-and-chat-improvements-in-copilot-for-jetbrains)

## What is implementable now

1. Disable automatic MCP startup where configured servers are not required for every session.
2. Add installed, configured, started, authorized, and invoked states to MCP session receipts.
3. Grade critical generated tests against several valid and invalid implementations.
4. Add monitor severity and next-inspection interval to coding-agent traces.
5. Run adaptive monitoring in shadow mode before allowing replacement interventions.
6. Measure reasoning tokens per turn before attempting adaptive-reasoning training.

## Evidence status

Cadence has a populated MIT repository and published result artifacts, but reproducing it requires provider and Modal operations. TestPrism is paper-only. RACE links to an empty repository with no default branch. GitHub's MCP startup control is shipping in Copilot for JetBrains.
