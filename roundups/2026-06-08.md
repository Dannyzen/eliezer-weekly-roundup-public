# Daily AI and Agent Research Scan: 2026-06-08

Today’s strongest pattern is measurement at the control surface. Skills, repository search, and sabotage monitoring are only useful when the harness can prove what evidence, procedure, and cross-step intent shaped the run.

## Top findings

### 1. Declarative skills help only when retrieval is already good
- Category: [AgenticAI](../AgenticAI/2026-06-08/reasoning.md#declarative-skills-help-only-when-retrieval-is-already-good)
- Durable topic: [Skills as Control](../AgenticAI/skills-as-control/skills-as-control.md)
- Core source: https://arxiv.org/abs/2606.06923v1
- Why it matters: skill files can reduce procedural/orchestration errors, but they cannot recover evidence that retrieval never supplied.
- Implementable now: test no-skill, thin-skill, full-skill, and imperative-state-machine variants under identical retrieval-quality tiers.
- Implementability score: 0.84

### 2. Repository exploration should be scored before patch success
- Category: [AgenticAI](../AgenticAI/2026-06-08/reasoning.md#repository-exploration-should-be-scored-before-patch-success)
- Durable topic: [Agentic Search and Retrieval](../AgenticAI/agentic-search/agentic-search.md)
- Core sources: https://arxiv.org/abs/2606.07297v1, https://github.com/Qiushao-E/SWE-Explore-Bench
- Why it matters: coding-agent patch success hides whether the agent found the right files, decisive lines, and smallest sufficient evidence set.
- Implementable now: add fixed-line-budget repository-exploration evals with coverage, ranking, and context-efficiency metrics.
- Implementability score: 0.80

### 3. Agent skills are now runtime-verified supply-chain dependencies
- Category: [Strategy](../Strategy/2026-06-08/sovereignty.md#agent-skills-are-now-runtime-verified-supply-chain-dependencies)
- Durable topics: [Agent Gateway Governance](../Strategy/agent-gateway-governance/agent-gateway-governance.md), [Skills as Control](../AgenticAI/skills-as-control/skills-as-control.md)
- Core sources: https://arxiv.org/abs/2606.07131v1, https://github.com/lxyeternal/MalSkillBench
- Why it matters: a skill is simultaneously prose, code, and authority hint. Scanning only code or only prompt text misses mixed instruction-code attacks.
- Implementable now: require skill manifests, loaded-body hashes, static prose/code checks, runtime sandbox verification for high-risk skills, and trace binding from skill to side effects.
- Implementability score: 0.78

### 4. Sabotage monitors need cross-step evidence accumulation
- Category: [Strategy](../Strategy/2026-06-08/sovereignty.md#sabotage-monitors-need-cross-step-evidence-accumulation)
- Durable topics: [Runtime Governance](../Strategy/runtime-governance/runtime-governance.md), [Trajectory-Aware Evaluation](../AgenticAI/trajectory-aware-evaluation/trajectory-aware-evaluation.md)
- Core source: https://arxiv.org/abs/2606.07054v1
- Why it matters: malicious objectives can be distributed across individually benign actions. Per-window and final-output checks miss that temporal structure.
- Implementable now: add triage-inspect-judge monitors over typed traces with accumulated evidence ledgers and cited-step verdicts.
- Implementability score: 0.66

## Signals

- Highest implementability today: declarative skills under measured retrieval quality at 0.84. The first version is mostly skill design plus eval discipline.
- Lowest implementability today: TRACE-style sabotage monitoring at 0.66. The monitor shape is clear, but production use needs typed traces, fixtures, calibration, and human-reviewed false-positive behavior.
- Best immediate build target: a skills-and-search eval harness that logs retrieval quality, loaded skill hash, decisive evidence lines, and verifier outcome before letting a coding agent edit.
- Noise filter: Socratic-SWE, DuMate-DeepResearch, and AARRI-Bench are worth tracking, but today’s durable repo update favors smaller control-surface primitives with clearer implementation paths.
