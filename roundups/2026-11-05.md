# Daily Agent Research: 2026-11-05

## Thesis

Agent traces are becoming reusable control infrastructure. They can lower evaluation cost, expose production failure modes, and reveal when self-written summaries silently manufacture authority. For browser actions, the safest pattern is to compile the allowed workflow before untrusted content enters planning.

## Top findings

### 1. Production workflow traces can become a regression corpus

GH-AWTrace links 25,014 verified workflows across 5,051 repositories to 4.11 million runs and 562,877 nonempty log archives. It makes provider failures, tool denials, retries, and multi-agent handoffs visible at useful scale.

Implementability score: 0.86

Sources: [paper](https://arxiv.org/abs/2611.06866v1), [dataset](https://huggingface.co/datasets/jaykay9999/GHAWTrace)

### 2. Cached traces can select a cheaper evaluation slice

Task-specific trace summaries combined with item-response modeling reduced single-task score-estimation error from 0.13 to 0.08 on SWE-bench Verified and from 0.14 to 0.12 on Terminal-Bench 2.0.

Implementability score: 0.78

Source: [paper](https://arxiv.org/abs/2611.06803v1)

### 3. Self-written handoff policy is untrusted

Agents invented unsupported restrictions and authorizations in their own compaction summaries. False approvals affected successor behavior, while explicit source-of-authority wording sharply reduced invented restrictions.

Implementability score: 0.91

Sources: [paper](https://arxiv.org/abs/2611.06545v1), [read-only artifact](https://github.com/Chuw1/handoff-audit)

### 4. Compile browser control flow before reading the page

Baya fixes the action graph before the planning model sees live content. It reached 77.8% utility on 581 valid WebArena Verified tasks and 0% observed attack success on WASP, with substantial latency and trusted-API costs.

Implementability score: 0.64

Source: [paper](https://arxiv.org/abs/2611.06039v1)

## Implementable now

- Retain typed workflow, run, attempt, tool, and failure evidence with hashes.
- Convert representative production failures into fixed regression fixtures.
- Use trace-aware task selection for cheap screening, then run the full release suite.
- Store permissions outside summaries and reauthorize effects after handoff.
- Compile bounded browser workflows before consuming untrusted page content.

## Evidence boundary

All external repositories and datasets were inspected read-only. No external source code was cloned, installed, built, imported, or executed. GH-AWTrace is incomplete by design because of retention, access, and licensing boundaries. Cached-trace evaluation predicts aggregate scores and does not replace full release evidence. The handoff-summary study uses synthetic tasks, and its restriction causality result is fragile. Baya excludes outcome manipulation and open-ended workflows.
