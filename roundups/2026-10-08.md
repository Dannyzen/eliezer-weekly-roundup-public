# Daily Agent Research Roundup: 2026-10-08

## Thesis

Agent autonomy needs four external contracts: time control, selective delegation, skill admission, and source-bound memory. Prompt instructions alone do not make these behaviors reliable.

## Top findings

### 1. AgentTime makes runtime control measurable

Across 222 tasks from 18 benchmark families, duration following varies sharply by model and harness. GPT-6 Astra ended 63% of runs within 5% of the request, GPT-5.6 Sol 39%, and Fable 5.1 4%. Some on-time runs contained explicit sleeping after apparent completion.

Sources: [paper v1](https://arxiv.org/abs/2610.09944v1), [repository](https://github.com/michaelofengenden/agenttimebench), [dataset](https://huggingface.co/datasets/mofengenden/agenttime-transcripts)

Implementability score: 0.90

### 2. Dynamic concurrency should be selective

The study covers 2,124 trajectories across Codex, Claude Code, and Kimi Code. Mean runtime increased in 14 of 15 agent-benchmark combinations. Claude Code lost 24.0 pass-rate points on SWE-bench Verified while gaining 14.3 points on LoopsBench.

Sources: [paper v1](https://arxiv.org/abs/2610.10263v1), [trajectory artifact](https://github.com/schwerli/Concurrency-Failures-Trajectory-Artifact)

Implementability score: 0.86

### 3. Skill admission needs novel paired scenarios

SkillSandbox synthesizes a task and environment around each skill, then compares execution with and without the skill. After 500 downstream tasks, 17% to 32% of skills remained unexercised and 45% to 56% lacked five execution opportunities.

Sources: [paper v1](https://arxiv.org/abs/2610.10088v1), [implementation snapshot](https://anonymous.4open.science/r/skillsandbox-647C/)

Implementability score: 0.74

### 4. Artifact-grounded memory is more auditable than free-floating summaries

ExperienceIndex stores experience against stable artifacts and artifact pairs. Across seven datasets, it reports up to 11.0 answer-quality points gained and up to 50.5% lower online cost.

Source: [paper v1](https://arxiv.org/abs/2610.10091v1)

Implementability score: 0.65

## What is implementable now

1. Add scheduler-owned deadlines, cancellation, and active-versus-idle time accounting.
2. Gate concurrency on decomposability, file ownership, and integration cost.
3. Require paired positive and boundary scenarios before admitting reusable skills.
4. Key learned memory by source ID and version, then test staleness and contradiction before injection.

## Artifact verification

All four immutable v1 papers were read. Public artifacts were inspected read-only. No external repository was cloned, downloaded, installed, built, imported, or executed. The AgentTime GitHub repository is MIT licensed; its transcript dataset is access-gated with upstream restrictions. The concurrency artifact is public but reports no license. SkillSandbox is an anonymous 4open.science snapshot. ExperienceIndex links no public implementation repository from its primary paper page.
