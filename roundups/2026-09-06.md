# Daily Agent Research - 2026-09-06

## Thesis

A parsable success is not an honest result. Sunday has no new arXiv listing; the newest batch is Friday, 4 Sep 2026. The unused Friday papers still change the stack: HTTP 200 with JSON can be an answer to a different question, a shared model name can fail its own reliability gate, and a decision graph can label an unobserved tool timeout as benign.

## Top findings

### 1. HTTP 200 is not a tool-result

SilentProbe audits 721,320 OpenAPI parameters across 2,501 documents: 7.5% declare an enumeration, 15.2% any machine-checkable constraint, 40.1% of documents put a constraint in prose only. Live perturbations: machine-checkable constraints honest in 111/111, prose-only silent in 44/61. Exemplified vocabularies missed 88/88. Downstream loops detect the miss 12% of the time, repair 0%, assert a false negative 41%, invent a figure 12%. Put vocabularies in the schema. Treat `e.g.` as an admission defect.

Implementable now: schema enumerations at tool admission, reject exemplified-only vocabs, log silent-failure separately from HTTP success.

Implementability score: 0.82

Sources:
- https://arxiv.org/abs/2609.00035v1
- https://github.com/Jasper0122/silentprobe

### 2. A shared model name is not a frozen instrument

Two preregistered observer campaigns never cleared their instrument gates. 52,988 request attempts: same-window Spearman 0.400 vs required 0.90, next-day replay 0.78 vs required 0.99, execution records at ceiling. Waiting did not help. Four providers share the floor. Self-hosting failed again under concurrent load.

Implementable now: freeze instrument gates before task gates; report the miss instead of a leaderboard score.

Implementability score: 0.58

Source: https://arxiv.org/abs/2609.04198v1

### 3. Graph structure is not a replay contract

DNative-Twin records typed trajectories, then shows graph-only reconstruction cannot see unobserved tool state. Unresolved-divergence recall moved from 0 to 0.667 with replay-contract state and to 1.0 with verification results (300 injected instances). All 40 unobserved tool-timeout cases were labelled benign without the contract.

Implementable now: put timeouts and verifier verdicts in the replay contract; score unresolved divergence; never default missing tool state to benign.

Implementability score: 0.45

Source: https://arxiv.org/abs/2609.03787v1
