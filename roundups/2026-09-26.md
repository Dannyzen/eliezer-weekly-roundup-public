## Findings

### 1. Compile skills into replay-checked state machines

HEXIS compiles SKILL.md into an extended finite state machine so the runtime owns control flow while the model reasons inside a state. Across four benchmarks and four executors, it beats Skill + ReAct by 16.1 percentage points on average, and Qwen3.8-27B execution tokens fall 38.4 to 88.9 percent. No paper-owned public compiler resolved.

Analysis: [AgenticAI](../AgenticAI/2026-09-26/reasoning.md#compile-skills-into-explicit-state-machines)
Source: [HEXIS](https://arxiv.org/abs/2609.30123v1)
Implementability score: 0.62

### 2. Bind approval to the transitive effect closure

Approval laundering is the record-coverage failure after Loopjacking: the human approves a truthful command while npm hooks, generated files, or MCP network calls execute outside that record. Across 111 approval-object pairs, residual records fall from 40 to 13 with decision-time metadata; source-backed predictions on 17 holdout workflows reach 0.926 recall and 0.941 precision. GitHub proof of presence adds a live IdP challenge for high-impact enterprise actions.

Analysis: [Strategy](../Strategy/2026-09-26/sovereignty.md#bind-approval-to-the-transitive-effect-closure)
Sources: [approval laundering](https://arxiv.org/abs/2609.28586v1), [proof of presence](https://github.blog/changelog/2026-09-24-require-proof-of-presence-for-high-impact-actions)
Implementability score: 0.78

### 3. Keep specification sign-off outside the acting model

On SkillsBench, seven models satisfy only 79.6 to 86.4 percent of 509 source-grounded directions while claiming completion 28.7 to 37.9 points above official pass rates. SpecHarness compiles visible specs into versioned obligations and lets only qualified evidence establish required state.

Analysis: [Strategy](../Strategy/2026-09-26/sovereignty.md#keep-specification-sign-off-outside-the-acting-model)
Source: [Who Holds the Pen?](https://arxiv.org/abs/2609.29921v1)
Implementability score: 0.72

### 4. Scope memory to the family that certified it, and inventory endpoint credentials

Scoped-ORC raises hidden trajectory utility from 0.713 to 0.816 versus global memory and records 0 of 63 harmful accepts. Separately, GitGuardian maps Cursor, Claude Code, and Copilot credential trails that repository scanners never see: 24,008 unique secrets in public MCP configs, 2,117 valid, and a 3.2 percent Claude Code-assisted leak rate versus a 1.5 percent baseline.

Analysis: [AgenticAI](../AgenticAI/2026-09-26/reasoning.md#scope-memory-to-the-family-that-certified-it), [Strategy](../Strategy/2026-09-26/sovereignty.md#inventory-endpoint-credentials-that-repository-scanners-never-see)
Sources: [Scope Before You Persist](https://arxiv.org/abs/2609.29144v1), [GitGuardian endpoint credentials](https://blog.gitguardian.com/ai-coding-agents-credential-security/)
Implementability scores: 0.70 and 0.88
