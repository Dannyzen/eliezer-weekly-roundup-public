# Daily Agent Research: 2026-11-22

## Thesis

Long-horizon agents need explicit state transitions. Compaction, memory selection, durable waits, and organizational retrieval each need a testable boundary with retained identity and replay evidence.

## Top findings

### 1. Compaction needs task-resumption tests

CompAct-Bench resumes a fixed executor from a compaction boundary across 200 tasks. Every retained task passed three pre-compaction runs, but average post-compaction success fell to 56.7%, with a best result of 68.5%.

Implement now: fixed-boundary replay, final-task grading, typed unresolved state, and separate omission versus false-completion analysis.

Implementability score: 0.72

Source: https://arxiv.org/abs/2611.25673v1

### 2. Memory dosage is model-specific

A deployment study found that DeepSeek-V3.2 improved as its guideline set grew to 191, while gpt-oss-120b did better with about 29 selected guidelines than with all 199. Selection needs preserved provenance and held-out evaluation.

Implement now: source-linked support counts, model-specific dose curves, fixed-scaffold comparisons, and separate development versus held-out selection.

Implementability score: 0.86

Sources: https://arxiv.org/abs/2611.26361v1 and https://github.com/AgentToolkit/altk-evolve

### 3. Durable waits can release active capacity

Cloudflare Agents SDK v0.34.0 lets Pi tools park for a human response, deadline, or another session signal while the Durable Object hibernates and holds no invocation.

Implement now: persisted park records, idempotent signals, durable resume history, and timeout, cancellation, and reauthorization tests.

Implementability score: 0.85

Source: https://developers.cloudflare.com/changelog/post/2026-11-20-pi-harness-pi-1-6/

### 4. Retrieval permissions belong before model context

Diderot v1.0.0 applies event scopes and caller permissions before vector results reach the model, then returns cited answers over Slack, HTTP, and MCP.

Implement now: source ACLs, request-bound principal identity, pre-context filtering, citation receipts, and rebuildable vector projections.

Implementability score: 0.78

Sources: https://github.com/bluesky-social/diderot and https://github.com/bluesky-social/diderot/releases/tag/v1.0.0
