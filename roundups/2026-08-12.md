# Daily Agent Research Roundup, 2026-08-12

## Thesis

Agent improvements become reliable only when the runtime exposes the boundary being changed or measured: harness defect, realized side effect, detector attack family, or memory authority lineage.

## Top findings

1. One Recipe, Many Harnesses shows that self-evolution transfers a common playbook but leaves 20 to 40 percent ecosystem-specific. Score: 0.78.
2. REDAgentBench separates exposure, execution, observation, and adjudication across 1,661 executable cases. Score: 0.72.
3. Quadrat-IPI maps detector recall across 92 attack cells at fixed false-positive budgets. Score: 0.95.
4. MAP-Graph filters shared memory by inherited authority before ranking and action. Score: 0.74.

## Implementable now

- Route harness edits from typed failure signals into falsifiable contracts.
- Grade agent safety from service receipts and final-state changes.
- Admit prompt-injection detectors by attack-family coverage and false-positive budget.
- Filter memory by inherited permission before semantic ranking.
- Keep a separate action-risk gate after memory retrieval.

## Highest and lowest implementability

Highest: Quadrat-IPI, 0.95. The Apache-2.0 Python harness and pinned public dataset are ready for a separate manual trial after source-license review.

Lowest: REDAgentBench, 0.72. Its measurement design is usable now, but the exact implementation artifact was not verified and the reported effects remain benchmark-specific.
