# Daily Agent Research Roundup: 2026-09-17

## Thesis

The useful control surface moved below the model turn. Tool progress should inform the serving runtime, interface meaning should be machine-readable, observed evidence should be treated as adversarial input, and policy should be evaluated over the whole execution.

## Freshness note

The four selected papers were first listed by arXiv on Thursday, 17 September 2026 and submitted as v1 on Wednesday, 16 September 2026 UTC. Primary abstract pages and PDFs were verified. GitHub and Hugging Face artifacts were inspected read-only. No external repository code was cloned or executed.

## Top findings

### 1. Adversarial task evidence needs paired evaluation

AgentLSD evaluates six models on 11 web CTF challenges and reports 3,061 trap trials. Clean agents captured 41 percent of flags. Deceptive evidence added about 20 turns and 2,000 reasoning tokens even when the final flag was recovered.

Primary: https://arxiv.org/abs/2609.19140v1
Artifact: https://github.com/Golim/agent-lsd
Implementability score: 0.88

### 2. Tool progress can improve serving decisions

Explicit tool progress was several times to an order of magnitude more accurate than pre-call duration predictors at cache-decision points. Small engine hints reduced post-tool p90 TTFT by 20.7 percent with HBM and 20.8 percent with HBM plus DRAM against LRU.

Primary: https://arxiv.org/abs/2609.18849v1
Progress contract: https://modelcontextprotocol.io/specification/2025-06-18/basic/utilities/progress
Implementability score: 0.72

### 3. Agent-friendly interfaces should declare shared meaning

Affora separates visual design from the controls, names, relationships, and state available to a machine reader. Three controlled studies support semantic component guidance and executable checks. The primary comparison improved completion by about 23 percentage points over baseline.

Primary: https://arxiv.org/abs/2609.19125v1
Implementability score: 0.78

### 4. Step-level compliance does not compose

A workflow can pass every local guardrail and still violate authority, threshold, cumulative, or context-dependent policy. The runtime must evaluate the complete trace and recompute guarded quantities from raw provenance.

Primary: https://arxiv.org/abs/2609.18820v1
Implementability score: 0.64

## Implementable now

- Add non-instructional evidence traps to existing agent evaluations.
- Emit monotonic tool progress outside model context and replay cache decisions offline.
- Add executable checks for accessible control identity, state, error recovery, and terminal success.
- Encode cumulative policies as deterministic trace predicates over raw events.

## Scope and evidence boundary

AgentLSD has a populated MIT repository, but it was not executed. The tool-progress paper links standards and public traces but no paper-specific implementation repository. Affora and the compositional-policy paper expose no dedicated public artifact on their primary pages. Scores reflect transferability and engineering burden, not independent reproduction.
