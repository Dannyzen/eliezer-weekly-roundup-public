# Daily Agent Research Roundup, 2026-10-27

## Thesis

Agent reliability is a property of the deployed loop. Today’s strongest findings replace three weak shortcuts: model-only evaluation, final-success grading for asynchronous work, and gain-only skill retirement. GitHub's assisted permissions release adds a fourth lesson: probabilistic classification can reduce friction only inside deterministic policy.

## Top findings

### Cross model and harness evaluation

A 52,168-trajectory study across six benchmarks found harness rankings changed by model and task. Release gates should identify the exact model-harness pair and report valid completion and resource use alongside task success.

Source: [When Agents Fail](https://arxiv.org/abs/2610.32483v1)

Implementability score: 0.90

### Event contracts for delayed subagent results

Async-RBench's 200 tasks show asynchronous delivery reduced average task success from 29.7% to 26.0%. Typed result relations and minimal invalidation are more promising than rebuilding the full plan after every arrival.

Source: [Async-RBench](https://arxiv.org/abs/2610.32429v1)

Artifact: [pope8zdt/Async-RBench](https://github.com/pope8zdt/Async-RBench)

Implementability score: 0.82

### Per-model, reversible skill retirement

Near-zero skill gain conflates internalized and uncovered capabilities. Retirement should require reproducible unaided capability and remain reversible per model.

Source: [Beyond Gain](https://arxiv.org/abs/2610.32322v1)

Artifact: [SkillCorpus lifecycle](https://github.com/EverMind-AI/SkillCorpus/tree/main/skillcorpus/lifecycle)

Implementability score: 0.78

### Assisted permissions inside a policy ceiling

GitHub now lets an LLM auto-pass requests classified as clearly safe, with enterprise controls over Assisted and Allow All. Deterministic denials, exact-effect receipts, and manual fallback remain necessary because public accuracy evidence is absent.

Source: [GitHub release](https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available)

Implementability score: 0.84

## Actionable cut

1. Cross the actual model and harness candidates on identical fixtures.
2. Add typed arrival contracts and minimal invalidation to asynchronous handoffs.
3. Replace gain-only skill deletion with per-model, reversible capability certificates.
4. Permit assisted approvals only below deterministic policy ceilings.

Highest implementability: 0.90, model-harness pair evaluation.

Lowest implementability: 0.78, reliable skill retirement, because cross-task reliability and multi-model evidence remain material.
