# Daily Agent Research Roundup: 2026-11-10

The strongest new signal is a three-gate agent stack: certify evidence sufficiency, evaluate orchestration under one budget, then optimize cost through a reversible harness layer. Shared writable state sits beside those gates as an authority-bearing communication channel.

## Top findings

### 1. Correct answers can come from insufficient histories

Two readers gave concrete answers on 196 and 182 of 203 certified-insufficient trajectory prefixes. They still matched dozens of hidden references. Final-answer accuracy therefore cannot establish that visible memory or history supports the answer.

Implementability score: 0.86

Analysis: [AgenticAI](../AgenticAI/2026-11-10/reasoning.md#1-grade-evidence-sufficiency-before-answer-accuracy)

Source: [Correct Answers from Insufficient Histories](https://arxiv.org/abs/2611.11840v1)

### 2. Orchestration quality is measurable apart from worker strength

WorkflowArena provides 145 long-horizon tasks across 8 domains, records executable delegation, charges planning and execution to one budget, and includes fixed-executor transfer tests. The strongest full system resolved only 36.95 percent on average.

Implementability score: 0.74

Analysis: [AgenticAI](../AgenticAI/2026-11-10/reasoning.md#2-measure-orchestration-as-its-own-capability)

Sources: [paper](https://arxiv.org/abs/2611.12856v1), [repository](https://github.com/Einsia/WorkflowArena)

### 3. Harness interposition is the right layer for cost control

Agency proposes a common layer over context, tools, and environments, with proof-of-concept techniques reporting up to 35 percent cost reduction. The public paper supports the architecture, but no public Agency implementation resolved.

Implementability score: 0.62

Analysis: [AgenticAI](../AgenticAI/2026-11-10/reasoning.md#3-put-cost-optimization-in-a-harness-interposition-layer)

Source: [System Optimizations for Cost-Efficient Agent Harnesses](https://arxiv.org/abs/2611.12122v1)

### 4. Shared memory coordinates agents even without collaboration prompts

A locked replication showed that a shared writable store can become an implicit message bus. Removing a single workspace-recheck instruction reduced one model's coordination from 50 of 50 worlds to 1 of 50 in both implementations.

Implementability score: 0.88

Analysis: [Strategy](../Strategy/2026-11-10/sovereignty.md#1-govern-shared-memory-as-an-implicit-message-bus)

Sources: [paper](https://arxiv.org/abs/2611.12412v1), [replication package](https://doi.org/10.5281/zenodo.23965306)

## What to use now

1. Add deterministic insufficiency witnesses and abstention grading to memory and trajectory evaluations.
2. Score workflow authors against fixed workers under one planning-plus-execution budget.
3. Put cost transforms behind an interposition layer with cost, success, and failure-shape gates.
4. Isolate agent workspaces by default and treat cross-agent reads as communication events.

## Signal and noise

- Strong signal: controlled evidence-sufficiency witnesses, executable workflows, fixed-executor transfer, two-implementation replication, and public benchmark or replication artifacts.
- Qualified signal: the Agency architecture and reported savings, because no public implementation resolved and the maximum reduction is workload-dependent.
- Noise rejected: same-name repositories unrelated to the papers, secondary summaries used in place of primary sources, and unverified artifact claims.

## Implementability range

Highest: 0.88 for explicit shared-memory authority controls.

Lowest: 0.62 for harness interposition cost optimization without a public Agency implementation.
