# Daily AI Agent Research Roundup — 2026-06-03

## Thesis

Today’s scan says the agent stack is getting stricter at the exact places where demos usually stay loose: skill authority, memory retention, multi-agent dispatch, and MCP data access. The durable pattern is permissioned runtime state. Reusable context is useful only when the system can prove what loaded it, what it was allowed to influence, what it changed, and what evidence justified the change.

## Deep Dive Wednesday selection

Winner: agent gateways are becoming the identity-bound MCP data plane.

This beat the other strong findings because every other layer eventually crosses this boundary. Skills, memory, multi-agent coding queues, storage, SaaS, GitHub, and admin tools all become real effects at the gateway. The durable product question is not "how many MCP servers can the agent see?" It is "which principal delegated which attenuated capability to which agent/session, over which data boundary, with what evidence?"

## Top findings

### 1. SkillGuard makes skills permission-bearing artifacts

SkillGuard turns the skill-security conversation from “scan the markdown” to “enforce skill-specific authority at runtime.” Its dual-plane model separates context influence from action side effects, which is the missing control for third-party skill ecosystems.

Implementable now:
- add skill manifests with context, tool, file, network, memory-write, and approval scopes;
- record loaded body and manifest hashes;
- deny behavior that exceeds declared skill authority;
- bind tool calls and memory writes to the skill that influenced them.

Implementability score: 0.78

Source:
- https://arxiv.org/abs/2606.03024v1

### 2. DMF argues memory pruning should be deterministic and auditable

DMF rejects write-time LLM summarization as the default memory primitive. Its exact scoring formula is less important than the architecture lesson: memory admission, decay, pruning, and provenance should be reproducible enough to replay and cheap enough to run continuously.

Implementable now:
- preserve raw episodes;
- compute deterministic retention scores;
- attach score components and provenance to memory objects;
- make decay, pruning, and supersession replayable from stored events.

Implementability score: 0.80

Source:
- https://arxiv.org/abs/2606.03463v1

### 3. SPOQ pushes multi-agent coding toward dependency queues and validation gates

SPOQ is a useful antidote to broadcast-style multi-agent chat. It uses dependency-wave dispatch, planning validation, code validation, human-as-agent participation, and tiered model roles. AgentLens supplies the eval warning: a passing coding-agent run can still be a lucky pass with blind retries, missing verification, or disordered process.

Implementable now:
- represent coding work as a dependency DAG;
- dispatch only ready waves;
- validate plans before execution and artifacts before merge;
- score process defects separately from final tests.

Implementability score: 0.66

Sources:
- https://arxiv.org/abs/2606.03115v1
- https://arxiv.org/abs/2605.12925v3

### 4. MCP storage access needs gateway-owned identity and exfiltration policy

Google’s GCS MCP server makes object storage agent-addressable. AWS’s AgentCore Gateway posts show the surrounding production shape: fine-grained access control, user-bound OAuth flow, centralized credentials, observability, and exfiltration controls. MCP is becoming an enterprise data plane, not a sidecar.

Implementable now:
- put storage and enterprise MCP servers behind a gateway;
- bind every request to user, agent, client, server, session, and delegated authority;
- scope tools by bucket, prefix, data class, workflow, and action;
- log selected tools, denied tools, object paths, auth claims, and final effects.

Implementability score: 0.74

Sources:

- https://aws.amazon.com/blogs/machine-learning/building-a-secure-auth-code-flow-setup-using-agentcore-gateway-with-mcp-clients/

## What to do with this

Short-term build moves:
- Add skill authority manifests and loaded-skill hash traces.
- Move memory retention from hidden summarization to replayable scoring plus raw evidence preservation.
- Treat multi-agent coding as a dependency DAG with validation gates, not a chat room.
- Treat every MCP server touching storage or enterprise systems as a gateway-governed data-plane endpoint.
