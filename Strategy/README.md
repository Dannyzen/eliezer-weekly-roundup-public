# Strategy

Control-plane research for authority, identity, provenance, gateways, approvals, privacy, and sovereign infrastructure.

## Latest structured update: 2026-11-12

### Admit memory updates as tested hypotheses

Summary: FGSE keeps candidate lessons in temporary state, tests transfer, falsification, and archived regressions, then commits, refines, or rejects them. Episode success becomes evidence for a proposal rather than authority to change durable memory.

Analysis: [Daily strategy](2026-11-12/sovereignty.md#1-admit-memory-updates-as-tested-hypotheses)

Durable topic: [Agent self-improvement governance](agent-self-improvement-governance/agent-self-improvement-governance.md)

Core source: [FGSE paper v1](https://arxiv.org/abs/2611.14326v1)

Implementable now:
- quarantined candidate lessons
- typed preconditions and expected effects
- transfer, counterexample, and regression probes
- version-bound promotion receipts
- explicit commit, refine, and reject outcomes

Implementability score: 0.74

### Let agents compose interfaces from application-owned capabilities

Summary: A2UI 1.0 is a stable Apache-2.0 protocol for declarative agent-generated interfaces. Host applications render registered native components and expose scoped functions, creating a testable boundary between model-generated representation and application authority.

Analysis: [Daily strategy](2026-11-12/sovereignty.md#2-let-agents-compose-interfaces-from-application-owned-capabilities)

Core sources: [Google announcement](https://developers.googleblog.com/a2ui-10-build-delightful-fast-reliable-agentic-experiences/), [repository](https://github.com/a2ui-project/a2ui), [documentation](https://a2ui.org/)

Implementable now:
- read-only cards and forms
- versioned component and function catalogs
- schema and conformance validation
- exact-effect confirmation views
- invocation and outcome receipts

Implementability score: 0.91

## Current strategic model

1. Persistent changes begin as quarantined proposals.
2. Promotion requires transfer, falsification, and regression evidence.
3. Visible interfaces should use application-owned components and functions.
4. Rendered confirmation must bind to a stored exact effect.
5. Protocol conformance and action authorization remain separate gates.
6. Receipts preserve what was proposed, shown, approved, invoked, and observed.
