# Daily AI and Agent Research Roundup - 2026-08-06

## Daily thesis

Names are not authority. Skills, tools, memory, and coding-agent routers need verified local evidence before side effects or frontier spend.

## Top findings

### Skill use needs trigger, compliance, and boundary scores

Skill-Use evaluates progressive disclosure over 79 real skills and 177 sandbox tasks. It separates whether the agent finds the skill, follows it, and stays inside its forbidden-operation boundary.

Source: https://arxiv.org/abs/2608.04828v1
Artifact: https://github.com/JinyiHan99/Skill-Use-Bench
Implementability: 0.76

### Canary tools diagnose why tool selection failed

Canary Tools plants six trap types into MCP-style catalogs and turns a wrong-tool outcome into a susceptibility profile. Across 8,640 runs, canary susceptibility spans roughly 0.010 to 0.378 across model tiers.

Source: https://arxiv.org/abs/2608.04719v1
Implementability: 0.60

### SafeCommit blocks side effects under unresolved memory worlds

SafeCommit allows external actions only when a conformal certificate says the action is safe in every retained world. In the authors' synthetic study, unsafe commitment falls from about 41.2 percent single-world action to about 2.6 percent with certification plus targeted probes.

Sources:
- https://arxiv.org/abs/2608.04289v1
- https://github.com/akewarmayur/SafeCommit
Implementability: 0.71

### SuperScout spends frontier fixers only after a verified scout

SuperScout scouts the repository with a 7B searcher, sandbox-verifies reproduction claims, strips false claims, then routes among frontier fixers. On SWE-bench Pro Python-266 it matches the best solo solve rate at about one fifth the matched cost per solve.

Sources:
- https://arxiv.org/abs/2608.04804v1
- https://github.com/TransformerOptimus/superscout
- https://huggingface.co/SuperAGI/SuperScout-7B
Implementability: 0.80

## What to implement now

1. Score Hermes skills on trigger, compliance, and boundary under name-first disclosure.
2. Add schema-derived canary tools beside high-risk MCP or gateway tools.
3. Require world-set certificates or targeted probes before memory-grounded side effects.
4. Put a scout-and-verify stage in front of expensive coding-agent routing.

## Signal versus noise

- Strongest ready artifact: SuperScout, with gate code, frozen router, receipts, and model card.
- Strongest skill-control method: Skill-Use's three-facet progressive disclosure score.
- Strongest commitment rule: SafeCommit's certify-or-probe-or-fallback controller.
- Weakest reproducibility: Canary Tools has a clear taxonomy but no verified public generator in this scan.
- Watchlist, not top finding: Argus is a broad long-horizon runtime report with strong claims, but no paper-owned public implementation was verified here.
