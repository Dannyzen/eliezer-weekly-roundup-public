JetBrains released a public Kotlin coding-agent benchmark with 105 tasks across eight open-source Kotlin repositories. Each task includes base commit, issue instruction, gold solution, regression tests, and containerized validation. This is immediately useful as a model for domain-specific agent replay packs.

### 2. MCP approvals need view-to-bytes fidelity

The Unicode TAG-block MCP paper shows that tool metadata can look benign in an approval dialog while hiding model-visible payload bytes. The fix is practical: canonicalize, scan, hash, and compare the approval view against the exact bytes that reach model context.

### 3. StateFuse makes multi-agent memory conflict-preserving

StateFuse is a lightweight Python library and paper for deterministic, conflict-preserving agent memory built around immutable operations, explicit conflicts, correction handles, and deterministic projections. The key lesson is to preserve disagreement rather than flatten multi-agent memory into last-write-wins state.

### 4. Context-to-Execution Integrity separates evidence from authority

CXI frames protected tool fields as execution sinks that require typed releases from writable context. A README, CI log, issue body, memory, or tool result can be useful evidence without being allowed to fill a privileged argument or trigger a side effect.

## What is implementable now

- Build a small internal SWE-bench-style replay pack for one Danny-owned repository or language surface.
- Add MCP metadata scans for invisible Unicode, TAG-block characters, bidi controls, zero-width characters, control bytes, and metadata drift after approval.
- Represent multi-agent memory writes as immutable claim operations with explicit conflict objects and correction handles.
- Mark protected sink fields on privileged tools and require typed releases before untrusted context can populate them.
