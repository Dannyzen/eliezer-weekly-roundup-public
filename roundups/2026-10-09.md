# Daily Agent Research Roundup: 2026-10-09

## Thesis

The strongest new work moves agent control earlier: intervene during trajectories, detect required actions before completion, resolve skill conflicts at first read, and gate state changes with compiled policy.

## Top findings

### 1. First-read skill routing prevents silent policy loss

Across 6,368 runs and 169,294 tool calls, a similar co-installed skill displaced the intended skill in one in five runs without lowering task completion. When the wrong skill was opened first, more than one third of exclusive core functions were lost. A pre-tool first-read hook restored fidelity.

Sources: [paper v1](https://arxiv.org/abs/2610.11647v1), [replication package](https://github.com/ltroin/conflict)

Implementability score: 0.90

### 2. Completion safety needs positive obligations

ObligationBench contains 240 expert-validated trajectories. The best of 14 evaluated models reached 48.97% recall and 10.00% exact match, while the trained ObligationGuard reached 57.52% recall and 21.67% exact match. The practical lesson is to grade cleanup, verification, rollback, and handoff as required terminal actions.

Sources: [paper v1](https://arxiv.org/abs/2610.11773v1), [public repository](https://github.com/THU-Agent/ObligationGuard)

Implementability score: 0.78

### 3. Streaming trajectory structure can support early intervention

OnTrack monitors partial agent traces at about one millisecond per step. On SWE-bench trajectories, it improved early failing-versus-success ranking by 0.057 AUROC and saved about 18% of failing-run compute under an abort policy. Five of six interrupted runs were headed toward failure, so the intervention precision is promising and preliminary.

Source: [paper v1](https://arxiv.org/abs/2610.12375v1)

Implementability score: 0.62

### 4. Written policy can compile into deterministic tool gates

NOMOS statically checks compiled rules against tool schemas, then enforces them without an online LLM. On tau2-bench, violations among state-changing calls fell from 66.3% to 2.6% in airline and from 30.8% to 6.9% in retail. Public artifacts expose rules and reports, while the compiler and runtime gate remain proprietary.

Sources: [paper v1](https://arxiv.org/abs/2610.11030v1), [artifact repository](https://github.com/iamupd/NOMOS), [Zenodo record](https://zenodo.org/records/22123420)

Implementability score: 0.58

## What is implementable now

1. Detect overlapping skills and intercept the first skill read.
2. Add explicit cleanup, verification, rollback, and handoff obligations to completion gates.
3. Run streaming trajectory monitoring in shadow mode before allowing automatic pause or abort.
4. Compile one narrow policy into typed tool rules, validate against schemas, and replay against known-good traces.

## Evidence and artifact status

All four immutable v1 papers and their full HTML were inspected. Three public artifact repositories were inspected read-only through GitHub metadata and raw README files. No external repository was cloned, downloaded, installed, built, imported, or executed.

ObligationGuard and the skill-conflict replication package have populated public branches but no GitHub-detected license. NOMOS publishes artifacts under CC BY-NC 4.0 and withholds the compiler and runtime gate. OnTrack links no public implementation artifact, and its abort precision comes from six interventions.
