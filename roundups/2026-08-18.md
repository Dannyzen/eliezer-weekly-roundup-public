## Thesis

Reliable agent systems need explicit runtime state for facts, coordination, authority, and execution boundaries.

## Top findings

### 1. Coding context should be measured at edit time

Across 154 closed-book migration trials, no model completed the task. Front-loading required facts lifted 299 of 300 matched trials to at least 9 of 12 requirements. A renamed real-library migration drove 66 of 70 trials across seven models to the same partial result.

Implementability score: 0.90

Source:
- https://arxiv.org/abs/2608.16630v1

### 2. Multi-agent coordination is directly observable

A temporal-network instrument captured messages, reads, and writes across 1,902 graded runs plus 244 sealed replication runs. Shared files cut output tokens by about 42% at eight agents on message-heavy work, while naming a coordinator produced no structural hub.

Implementability score: 0.88

Sources:
- https://arxiv.org/abs/2608.16801v1
- https://github.com/giuseppedestefanis/when-agents-coordinate

### 3. Delegation authority must narrow at every hop

The Agentic Principal Chain checks six authorization conditions against accumulated session state. Across 3,154 instances, it blocked all 544 InjecAgent data-stealing cases and reduced AgentDojo exfiltration from a 75% to 100% range down to 0% across four domains, with measurable utility cost.

Implementability score: 0.76

Source:
- https://arxiv.org/abs/2608.15888v1

### 4. OpenAI Agents SDK v0.21.1 adds practical run boundaries

The release adds model-call timeouts, run-scoped sandbox directories, optional Docker network disablement, Modal resource controls, and fixes for exact approvals and cleanup after failures.

Implementability score: 0.95

Source:
- https://github.com/openai/openai-agents-python/releases/tag/v0.21.1

## What is implementable now

- Attach versioned required facts to edit-intent events and validate them before writes.
- Emit agent, message, file-read, and file-write edges into a per-run coordination graph.
- Prototype delegation envelopes that attenuate scope and budget at each hop.
- Pin OpenAI Agents SDK v0.21.1 in an isolated branch and test deadlines, network-off sandboxes, exact approvals, and failure cleanup.

## Current implication

Final success hides the mechanisms that make an agent governable. The runtime should expose what facts supported an edit, how a team coordinated, what authority remained at each hop, and which resources each run could touch.
