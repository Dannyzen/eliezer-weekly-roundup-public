# Daily Synthesis: 2026-05-22

Today’s strongest signal: agent systems are becoming replayable control surfaces. The best new sources are not hype about more autonomy. They are about event-sourced state, interface-level harness repair, realistic eval worlds, and hard authentication boundaries for MCP.

## Top findings

### 1. The agent log should become the state substrate
- Category: [AgenticAI](../AgenticAI/2026-05-22/reasoning.md#activegraph-makes-the-event-log-the-agent-state)
- Durable topic: [Event-Sourced Agent Runtime](../AgenticAI/event-sourced-agent-runtime/event-sourced-agent-runtime.md)
- Core source: https://arxiv.org/abs/2605.21997
- Supporting sources: https://activegraph.ai/ and https://github.com/yoheinakajima/activegraph
- Why it matters: ActiveGraph treats the append-only event log as the source of truth and projects working graph state from it. That gives agents replay, fork/diff, and lineage that transcript-plus-memory systems do not provide.
- Implementable now: start with append-only model/tool/object/policy events, project task/evidence/artifact graphs, and add replay for one workflow.
- Implementability score: 0.84

### 2. Harness repair should target the interface, not only the model
- Category: [AgenticAI](../AgenticAI/2026-05-22/reasoning.md#life-harness-says-fix-the-interface-before-the-model)
- Durable topic: [Agent Harness Architecture](../AgenticAI/agent-harness-architecture/agent-harness-architecture.md)
- Core source: https://arxiv.org/abs/2605.22166
- Why it matters: Life-Harness argues that many deterministic-agent failures come from environment contracts, action realization, procedural skills, and trajectory regulation. Those are harness problems before they are model problems.
- Implementable now: mine failed traces for recurring interface errors, convert them into versioned harness interventions, and test transfer across models.
- Implementability score: 0.66

### 3. Agent eval now needs realistic worlds plus trace/data-quality audits
- Category: [AgenticAI](../AgenticAI/2026-05-22/reasoning.md#terminalworld-agentic-clear-and-synae-turn-eval-into-a-trace-and-data-quality-stack)
- Durable topic: [Trajectory-Aware Evaluation](../AgenticAI/trajectory-aware-evaluation/trajectory-aware-evaluation.md)
- Core sources: https://arxiv.org/abs/2605.22535, https://arxiv.org/abs/2605.22608, https://arxiv.org/abs/2605.22564
- Supporting sources: https://github.com/EuniAI/TerminalWorld, https://huggingface.co/datasets/EuniAI/TerminalWorld, https://github.com/wsqwsq/SynAE
- Why it matters: TerminalWorld uses in-the-wild terminal recordings; Agentic CLEAR evaluates system/trace/node behavior; SynAE audits synthetic tool-call data. Together they move eval from pass/fail theater to evidence infrastructure.
- Implementable now: build small verified terminal/workflow subsets, preserve traces, label node-level failures, and audit synthetic traces for validity, fidelity, diversity, and downstream ranking.
- Implementability score: 0.78

### 4. Remote MCP auth is already a production-grade failure mode
- Category: [Strategy](../Strategy/2026-05-22/sovereignty.md#remote-mcp-authentication-is-failing-at-the-client-registration-boundary)
- Durable topic: [Agent Gateway Governance](../Strategy/agent-gateway-governance/agent-gateway-governance.md)
- Core source: https://arxiv.org/abs/2605.22333
- Supporting source: https://arxiv.org/abs/2605.22568
- Why it matters: the MCP auth study reports 7,973 live remote MCP servers, 40.55% with no authentication, and severe flaws across tested OAuth-enabled servers. MCP discovery is not an auth boundary.
- Implementable now: require auth on all non-public MCP servers, gate dynamic client registration, enforce scoped OAuth/OIDC, pin redirects, test MCP auth flows, and put remote MCP access behind a logging gateway.
- Implementability score: 0.82

## Highest and lowest implementability today

- Highest: ActiveGraph/event-sourced runtime at 0.84. A first useful version only needs append-only events, graph projections, replay, and lineage discipline.
- Lowest: Life-Harness at 0.66. The pattern is actionable, but robust trajectory mining and transferable harness intervention design need architecture and evaluation maturity.

## Actionable moves

1. Add an append-only event table to one agent workflow and project claims, evidence, artifacts, and policy decisions from it.
2. Require harness patches to cite failed traces and declare expected fixes/regressions.
3. Build a 20-task internal terminal/workflow eval from real recurring operations before trusting broad benchmark scores.
4. Audit synthetic agent traces for validity, fidelity, diversity, and downstream ranking before using them for regression or training.
5. Treat every remote MCP endpoint as untrusted until authentication, dynamic registration, redirect behavior, scopes, token handling, and audit evidence are verified.
