# Deep Dive Wednesday and Daily Agent Research, 2026-10-28

## Thesis

Agent reliability needs stronger evidence at five boundaries: decision state, current truth, inherited work state, generated tests, and workload identity. Retrieved facts, static labels, prose handoffs, passing tests, and borrowed human credentials all hide operational failure.

## Deep Dive Wednesday

### Memory needs a decision-state compiler

SciValidityBench is the week's strongest finding. It turns distributed event history into source-linked governing state, then grades whether a model uses that state to choose a legally valid action. Across four model families, compiled state improved valid decision-making by 9.2 to 18.8 percentage points over a generic Event Graph. Retrieval alone did not reproduce the gain.

The durable pattern is broader than scientific memory: preserve evidence, compile the conditions that govern its use, define legal actions, test one-variable counterfactuals, and require abstention when oracle-required state is missing. A valid decision still needs a separate authority and effect gate before execution.

Implementability score: 0.76

Deep dive: [Decision-State Compilation for Agent Memory](../AgenticAI/decision-state-compilation/decision-state-compilation.md)

Sources: https://arxiv.org/abs/2610.34767v1 and https://github.com/SciValidityBench/SciValidityBench

## Top findings

### 1. Live benchmarks should execute current truth

LiveSearch freezes questions but recomputes gold answers through typed professional-data calls and deterministic extraction. Seventy percent of served questions changed gold value across three days.

Implementability score: 0.84

Source: https://arxiv.org/abs/2610.37166v1

### 2. Agent handoffs need state-continuity tests

HSC-Bench uses 1,039 takeover tasks to separate repository evidence recovery from continuation of conversational, tool, and file-work state. Structured state improved recovery for every tested receiver and continuation for most.

Implementability score: 0.86

Source: https://arxiv.org/abs/2610.36523v1

### 3. Passing generated tests are weak evidence

Req2Test-Bench reports 82.8% passing tests for the best configuration but only 33.8% behavioral adequacy under mutation kill-completeness. Its advertised GitHub and Hugging Face artifacts did not resolve publicly during this scan.

Implementability score: 0.80

Source: https://arxiv.org/abs/2610.36584v1

### 4. Autonomous services need workload-owned identity

GitHub Copilot SDK now supports organization-installed GitHub Apps with short-lived installation tokens, organization attribution, model policy, budgets, and independent revocation.

Implementability score: 0.90

Source: https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication/

## What is implementable now

- encode mutable benchmark answers as deterministic source programs;
- make handoffs carry decisions, effects, constraints, file state, and verification status;
- add mutation-based behavioral adequacy to generated-test gates;
- use workload identities with short-lived tokens and explicit revocation;
- preserve per-item and per-workload receipts instead of relying on aggregate dashboards.

## Evidence status

All four findings were verified from primary sources dated or submitted October 27, 2026 and first listed or published within the scan window. External repositories were inspected read-only only. No external source was cloned, installed, built, imported, or executed. NotebookLM remained disabled and its manifest was untouched.
