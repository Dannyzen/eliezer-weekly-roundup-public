# Daily Synthesis: 2026-05-16

Today’s signal is practical and architectural: the agent stack is moving from “better model plus tools” to governed runtime design. The strongest sources all pressure the same layers: retrieval in the actual harness, visual evidence in memory, lineage-gated profile state, and OS-style permission boundaries for skills and MCP servers.

## Top findings

### 1. Retrieval quality depends on the harness, not just the retrieval model
- Category: [AgenticAI](../AgenticAI/2026-05-16/reasoning.md#harness-shape-now-changes-retrieval-quality-grep-beat-vector-search-in-agent-loops)
- Durable topic: [Agentic Search and Retrieval](../AgenticAI/agentic-search/agentic-search.md)
- Core source: https://arxiv.org/abs/2605.15184
- Why it matters: exact search, vector retrieval, inline outputs, file-backed outputs, and provider-native CLI harnesses produce different outcomes on the same memory/search task. Retrieval has to be evaluated in the full tool loop.
- Implementable now: add grep/ripgrep baselines, compare inline vs file-backed result handoff, log search/read/citation paths, and test retrieval under irrelevant-history distraction.
- Implementability score: 0.88

### 2. Multimodal memory needs visual evidence, not caption residue
- Category: [AgenticAI](../AgenticAI/2026-05-16/reasoning.md#visual-memory-evaluations-need-pixel-evidence-and-temporal-state-not-captioned-summaries)
- Core source: https://arxiv.org/abs/2605.15128
- Why it matters: GUI and browser agents need to remember the exact visual state that justified an action. Caption-only memory loses pixel-level details and temporal changes.
- Implementable now: preserve selected screenshots/crops, tag visual evidence by granularity, link visual memories to post-action verification, and test cases where captions are insufficient.
- Implementability score: 0.64

### 3. Memory is now an authorization input
- Category: [Strategy](../Strategy/2026-05-16/sovereignty.md#agent-memory-needs-lineage-gates-before-it-can-become-authority)
- Core sources: https://arxiv.org/abs/2605.14421, https://arxiv.org/abs/2605.14454, https://github.blog/changelog/2026-05-15-copilot-memory-supports-user-preferences-for-pro-pro-users/
- Why it matters: persistent and cross-repository memory can influence future action. MemLineage argues for provenance and sensitive-action gates; LiSA argues for conservative adaptation from feedback; Copilot Memory shows user-level preferences are becoming product state.
- Implementable now: attach trust metadata to memories, separate recall from action justification, gate sensitive actions influenced by inferred or external memory, and expose review/delete controls.
- Implementability score: 0.74

### 4. Agent security is becoming OS-style permissioning plus semantic skill scanning
- Category: [Strategy](../Strategy/2026-05-16/sovereignty.md#agent-security-is-converging-on-os-permissions-and-semantic-skill-scanning)
- Core sources: https://arxiv.org/abs/2605.14932, https://arxiv.org/abs/2605.14859, https://arxiv.org/abs/2605.14460, https://github.com/snyk/agent-scan
- Why it matters: models do not reliably infer least privilege, skills can be malicious without code payloads, and MCP discovery itself can start processes. Runtime security has to enforce resource boundaries below the prompt.
- Implementable now: generate and audit file-level policies, classify tool and skill authority, scan skills semantically, and run untrusted MCP scans in disposable sandboxes.
- Implementability score: 0.66

## Highest and lowest implementability today

- Highest: harness-shaped retrieval baselines at 0.88. This is ordinary engineering: add exact search, compare output handoff styles, and trace search/read/citation behavior.
- Lowest: visual memory evidence at 0.64. The idea is clear, but production-quality screenshot/crop storage, region metadata, temporal visual linking, and visual-necessity evals require more infrastructure.

## Actionable moves

1. Add a grep/ripgrep baseline to any agent memory or repo-search eval before introducing vector retrieval.
2. Treat tool-output presentation as a parameter: inline snippets and file-backed artifacts should be evaluated separately.
3. Preserve visual evidence for GUI/browser agents when the action depends on exact UI state.
4. Add memory provenance and trust tiers before letting durable memories influence shell, file, credential, cloud, or preference-changing actions.
5. Treat skills and MCP configs as supply-chain inputs: scan semantically, sandbox discovery, and log authority decisions.
