# Daily Agent Research: 2026-10-04

## Thesis

Reliable agents need deterministic boundaries around effects. Score terminal state instead of confident prose, fit the harness to the model's real limits, preserve authority lineage across skill handoffs, and require every sensitive tool call to justify itself against the original request.

## Freshness note

There is no new Sunday arXiv listing. The newest category batch is Friday, October 2. This roundup combines a fresh October 3 implementation release with three strong, non-duplicate papers from that Friday batch.

## Top findings

### 1. ThinkingBox makes persistent state the oracle

The newly released OpenEnv environment evaluates 507 stateful workflows through executable backend checks, with 20 repeats per task. The strongest reported model falls from 65.36% pass@1 to 25.25% pass^20. Use terminal-state contracts, repeated trials, and failure snapshots for consequential workflows.

Sources: [implementation article](https://huggingface.co/blog/microsoft/thinkingbox), [paper v4](https://arxiv.org/abs/2608.19741v4), [OpenEnv environment](https://github.com/huggingface/OpenEnv/tree/main/envs/thinkingbox_env)

Implementability score: 0.88

### 2. Mingbird treats harness fit as part of model capability

Mingbird pairs small Ollama models with strict prefill budgets, task re-read completion gates, and loop detection. Its public Apache-2.0 repository and v1.9.2 release are usable now, but the reported gains come from a self-built benchmark, one machine, and mostly single-trial scoring.

Sources: [paper v1](https://arxiv.org/abs/2610.02001v1), [repository](https://github.com/Mingbird/Mingbird-agent), [release](https://github.com/Mingbird/Mingbird-agent/releases/tag/v1.9.2)

Implementability score: 0.82

### 3. Skill chains can launder false approval

APEX induced attacker-selected actions in 512 of 690 attempts by carrying a false approval claim through agent-written handoff artifacts. Prompt-only defense cut attack success but sharply reduced benign utility. Preserve skill origin, forbid derived authority, and test composed skill graphs.

Sources: [paper v1](https://arxiv.org/abs/2610.01564v1), [repository](https://github.com/Minakamiii/Chaining_Skills_to_Hijack_LLM_Agents)

Implementability score: 0.68

### 4. Tool calls need request-bound necessity checks

OverAct finds proactive over-authorization across seven models and eight privacy-sensitive domains. Its SelfAudit method reduces privacy-oriented excess by 43% through explicit pre-dispatch filtering. Measure excess access separately from task success.

Source: [paper v1](https://arxiv.org/abs/2610.01508v1)

Implementability score: 0.76

## What to implement now

1. Add terminal-state predicates and repeated trials to one stateful agent journey.
2. Add origin labels and exact approval grants to skill handoff artifacts.
3. Add request-grounded justification and filtering before privacy-sensitive calls.
4. Benchmark one small local model with strict prefill, finish, and loop controls before expanding the local fleet.
