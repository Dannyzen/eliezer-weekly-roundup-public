# Daily roundup, 2026-06-28

## Bottom line

Today's scan strengthens one thesis: agent systems are moving from trusting generated artifacts to governing boundary objects.

The actionable stack shape is:

1. external agent contributions cross trust boundaries as knowledge packages, not merge candidates;
2. memory systems retire stale facts with validity ledgers, not vector similarity guesses;
3. skills need runtime reference monitors over multi-step traces;
4. prompt-injection defenses need adaptive evaluation, not fixed benchmark comfort.

## Top findings

### 1. Knowledge-based pull requests make external code evidence, not authority

Category: AgenticAI
Analysis: [AgenticAI reasoning](../AgenticAI/2026-06-28/reasoning.md#knowledge-based-pull-requests-make-external-code-evidence-not-authority)
Core source: https://arxiv.org/abs/2606.26721v1
Implementability score: 0.72

KPR separates knowledge acceptance from code acceptance. External code, tests, and cleaned traces become a provenance-bearing knowledge package. A project-owned inner trusted coding agent regenerates candidate code under repository policy, tests, and conventions.

### 2. Temporal validity turns memory updates into ledger operations

Category: AgenticAI
Analysis: [AgenticAI reasoning](../AgenticAI/2026-06-28/reasoning.md#temporal-validity-turns-memory-updates-into-ledger-operations)
Core source: https://arxiv.org/abs/2606.26511v1
Implementability score: 0.83

MemStrata's central lesson is that stale facts are write-path failures. Contradictions can be embedding-nearer than duplicates, so active facts need valid-time state, deterministic supersession, and retired-value lineage.

### 3. Skill specifications need runtime reference monitors

Category: Strategy
Analysis: [Strategy sovereignty](../Strategy/2026-06-28/sovereignty.md#skill-specifications-need-runtime-reference-monitors)
Core source: https://arxiv.org/abs/2606.26524v1
Implementability score: 0.64

VIGIL turns skill documentation into trace-time enforcement. The monitor checks event order, argument constraints, temporal dependencies, and value flow, catching violations that single-call filters and final-output checks miss.

### 4. Prompt-injection defenses need adaptive out-of-band evaluation

Category: Strategy
Analysis: [Strategy sovereignty](../Strategy/2026-06-28/sovereignty.md#prompt-injection-defenses-need-adaptive-out-of-band-evaluation)
Core source: https://arxiv.org/abs/2606.26479v1
Implementability score: 0.69

The field is right to move prompt-injection defense outside the model, but static benchmark success is not enough. Reference monitors, capability systems, and taint policies need defense-aware adaptive attacks in the regression suite.

## What is implementable now

- Require structured evidence packages for high-context external agent contributions before internal regeneration.
- Add valid-from, valid-until, superseded-by, source event, and writer principal fields to structured memories.
- Wrap one high-risk skill with a finite-trace policy monitor over events and artifact IDs.
- Add adaptive prompt-injection cases to gateway and tool-use security tests.

## Implementability range today

Highest score: 0.83, temporal validity for retrieval memory.
Lowest score: 0.64, runtime reference monitors for skill specifications.
