# Daily Agent Research - 2026-09-21

## Thesis

Reliable agents need a binding between evidence and effects: approval must name the exact action released, payment policy must run at the commit boundary, computer-use benchmarks must verify post-action outcomes, and generated training tasks must remain traceable to executable reference behavior.

## Top findings

### 1. Bind every approval to the exact released action

Loopjacking shows how a valid approval can authorize a different operation after representation loss or mutable-state substitution. Canonical rendering plus an exact use-time comparison blocked the tested attacks.

Analysis: [Strategy](../Strategy/2026-09-21/sovereignty.md#bind-approval-to-one-canonical-action-at-use-time)
Sources:
- https://arxiv.org/abs/2609.21081v1
- https://github.com/adithyan-ak/loopjacking
Implementability score: 0.96

### 2. Enforce payment policy outside the model

APort Vault recorded 140 forbidden-recipient transfers in 76,842 model-only evaluations and zero in 69,297 evaluations behind a deterministic pre-action policy layer. The layer still executed 25,370 payments.

Analysis: [Strategy](../Strategy/2026-09-21/sovereignty.md#put-deterministic-payment-policy-after-planning-and-before-transfer)
Sources:
- https://arxiv.org/abs/2609.22076v1
- https://huggingface.co/datasets/aporthq/vault-benchmark-v1
Implementability score: 0.93

### 3. Grade computer-use agents on post-action outcomes

RecreationWorld provides 250 cross-platform tasks with reference-grounded programmatic and visual assertions. Its leading model reached 58.1 percent overall while passing every programmatic test on only 2.8 percent of tasks, exposing the gap between static resemblance and working behavior.

Analysis: [AgenticAI](../AgenticAI/2026-09-21/reasoning.md#verify-hybrid-computer-use-agents-with-action-conditioned-outcome-tests)
Sources:
- https://arxiv.org/abs/2609.22000v1
- https://github.com/QwenLM/RecreationWorld
- https://huggingface.co/datasets/Qwen/RecreationBench
Implementability score: 0.68

### 4. Compile training tasks from executable behavior

CodeMidas turns existing source behavior into specifications, tests, filtered tasks, and reinforcement-learning environments. It reports 5,545 tasks from 3,185 codebases and gains across five coding benchmarks, but no public implementation artifact resolved from the primary paper surface.

Analysis: [AgenticAI](../AgenticAI/2026-09-21/reasoning.md#derive-executable-training-environments-from-behavior-not-ticket-history)
Source: https://arxiv.org/abs/2609.22068v1
Implementability score: 0.46

## What is implementable now

1. Bind every approval to a canonical action manifest and compare it again at use time.
2. Put typed payment policy immediately before the transfer API call.
3. Add action-conditioned programmatic and visual assertions to browser and desktop agent tests.
4. Build a small behavior-to-test task compiler with provenance before attempting RL-scale generation.
