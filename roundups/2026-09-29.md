# Daily Agent Research Roundup - 2026-09-29

## Thesis

Runtime controls need typed evidence about what was delivered, what changed, and whether intervention helped. A stop count or a tool name is not enough.

## Top findings

### 1. Security evals need payload-delivery receipts and argument-level scoring

An audited indirect prompt-injection harness changed measured attack success from 21.7% to 1.2% after correcting payload delivery and tool-argument scoring.

Source: [Silent Failures in Agentic Security Evaluation](https://arxiv.org/abs/2609.32691v1)
Implementability: 0.94

### 2. Deterministic governance needs signed intervention utility

Maat found 35 false alarms among 94 governed halts. DebateLedger found that a freeze prevented 29 harmful collapses while losing 108 useful corrections. Validators should be graded on net outcomes, not stop counts.

Sources: [Maat](https://arxiv.org/abs/2609.34017v1), [Measuring Collapse and Correction in Homogeneous-Panel LLM Debate](https://arxiv.org/abs/2609.35279v1)
Implementability: 0.86

### 3. Long-horizon memory should expose typed execution state and raw evidence on demand

FlowState separates compact typed state from referenced raw observations. The paper reports higher task performance with roughly 40% lower token use than a full-context baseline.

Source: [FlowState](https://arxiv.org/abs/2609.34565v1)
Implementability: 0.74

## What to implement now

1. Add machine-checkable input-delivery receipts and exact argument/effect predicates to security and tool-use evals.
2. Add a signed intervention ledger to validators, freezes, and escalation rules.
3. Prototype typed execution state with links back to immutable tool observations.
