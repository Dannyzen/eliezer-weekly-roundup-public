# Daily Roundup - 2026-07-01

Thesis: the agentic stack is moving from generic tool access to governed work surfaces. Today's strongest findings turn memory, execution, skills, and inter-agent coordination into explicit artifacts that can be traced, tested, or governed.

## Top findings

### 1. ECHO makes selective memory traceable

Category: AgenticAI
Source: https://arxiv.org/abs/2606.31650v1

ECHO links bounded context with RL credit assignment. It compresses completed turns into source-indexed memory records, reconstructs bounded contexts by selecting records, and routes outcome credit back to the selected evidence. The abstract reports 43.4% held-out BrowseComp-Plus accuracy versus GRPO at 28.9% and SUPO at 36.1%.

Implementability score: 0.74

### 2. CubeSandbox makes sandbox policy part of the agent runtime

Category: AgenticAI
Source: https://github.com/TencentCloud/CubeSandbox
v0.4 changelog: https://github.com/TencentCloud/CubeSandbox/blob/master/docs/changelog/v0.4.0.md
Security proxy guide: https://github.com/TencentCloud/CubeSandbox/blob/master/docs/guide/security-proxy.md

CubeSandbox is an implementable sandbox substrate for code agents: KVM and RustVMM isolation, E2B SDK compatibility, snapshots, templates, and a v0.4 CubeEgress proxy for credential injection, domain filtering, and egress audit logs. The useful pattern is runtime-owned network and secret policy, not prompt-owned safety.

Implementability score: 0.86

### 3. agents-cli packages agent lifecycle expertise as skills plus commands

Category: AgenticAI
Source: https://github.com/google/agents-cli
Docs: https://google.github.io/agents-cli/guide/getting-started/
Release: https://github.com/google/agents-cli/releases/tag/v0.6.1

Google's agents-cli gives coding assistants installable skills and deterministic commands for ADK agent development: scaffold, eval, grade, analyze, optimize, deploy, publish, and observe. It is a concrete example of skills-as-control moving into vendor tooling.

Implementability score: 0.88

### 4. Agent interop protocols do not govern communities

Category: Strategy
Source: https://arxiv.org/abs/2606.31498v1

The governance-gaps paper argues that MCP, A2A, ACP, ANP, and ERC-8004 handle connection and task coordination, but not governed communities. Membership, deliberation, voting, dissent preservation, human escalation, and audit/replay need a layer above current protocols.

Implementability score: 0.48

## What is implementable now

- Add source IDs to memory records and log which records are selected into each bounded context.
- Compare full history, rolling summaries, selected turn memory, and no-memory variants on local tasks.
- Evaluate CubeSandbox on a disposable KVM host as an E2B-compatible worker backend with egress rules enabled.
- Test agents-cli on a throwaway ADK project and compare agent builds with and without lifecycle skills.
- Define an agent assembly manifest: members, roles, scopes, voting or approval rights, dissent logging, escalation, and replay bundle.

## Scores

Highest implementability today: 0.88, agents-cli.
Lowest implementability today: 0.48, agent community governance above interop protocols.
