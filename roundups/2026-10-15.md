# Daily Agent Research Roundup: 2026-10-15

## Thesis

Independent evidence must exist at every authority boundary. Reports need recoverability tests, runtime monitors need real interposition points, skills need capability manifests, and MCP gateways need to stay beside the systems they govern.

## Top findings

### 1. Agent reports omit recoverable task state

CTXGAP found a 40.7-point gap between report-only and full-context task-state recovery across 37 coding tasks and 4,799 valid probes. Successful fixes did not close the gap.

Implementability score: 0.82

Sources: [paper](https://arxiv.org/abs/2610.20003v1), [benchmark repository](https://github.com/Kaguraaaaaa/Ctxgap)

### 2. Runtime verification needs a shared event contract and explicit effect boundaries

AgenticRV separates adapters, projections, monitor verdicts, and deterministic reactions across LangGraph, MCP, and A2A. Its strongest lesson is operational: observation does not become prevention unless the adapter can retain the operation before release.

Implementability score: 0.76

Sources: [paper](https://arxiv.org/abs/2610.19818v1), [implementation](https://github.com/AngeloFerrando/agentic-rv)

### 3. Skill security should profile capability, not only maliciousness

A 6,309-listing study found elevated capability in seven of ten skills and widespread understatement in frontmatter declarations. Install-time governance needs whole-bundle capability evidence and drift controls.

Implementability score: 0.70

Sources: [paper](https://arxiv.org/abs/2610.19264v1), [SkilLock](https://github.com/skills-lock/skil-lock)

### 4. Apigee hybrid turns existing API governance into an in-cluster MCP boundary

Apigee hybrid 1.17.0 can expose approved OpenAPI operations as MCP tools while request traffic, authorization, and tracing remain inside the customer's Kubernetes cluster.

Implementability score: 0.68

Sources: [announcement](https://developers.googleblog.com/en/announcing-mcp-support-in-apigee-hybrid-agentic-tools-that-run-in-your-own-cluster/), [architecture documentation](https://docs.cloud.google.com/apigee/docs/api-platform/apigee-mcp/apigee-mcp-overview)

## What is implementable now

- Add task-state probes to report and handoff quality gates.
- Normalize tool and delegation events before selecting monitor technology.
- Lock skill capability surfaces and block unexplained drift.
- Put MCP discovery and calls behind the same gateway controls as the source APIs.

## Watchlist, not promoted

- [Doc2Harness](https://arxiv.org/abs/2610.20344v1) is a strong benchmark design signal, with 328 black-box cases and positive controls, but the scan did not find a clearly exposed benchmark repository from the project page.
- [HydraFusion Max](https://github.blog/changelog/2026-10-14-hydrafusion-updates-and-new-max-option/) is a useful orchestration signal, but the release remains in research preview and publishes no comparative evaluation numbers.

## Evidence status

The arXiv papers were read at immutable v1 URLs and verified against their October 15 category listings. Public artifacts were inspected through GitHub metadata, trees, and README pages only. The Google announcement and product documentation were read directly. Hugging Face's latest feed entries did not outrank the selected control-plane findings. No external code was cloned or executed.
