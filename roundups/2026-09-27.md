No new arXiv listing today. Category pages still show Friday, 25 September 2026 as the newest announcement batch. This note covers leftover Friday papers the weekly synthesis and Saturday leftover scan did not promote, plus Friday GitHub product evidence that was still sitting in the changelog.

## Findings

### 1. Grade governance with behavior gates

SWE-Prometheus gives a coding agent a pinned repository and no issue. Credit requires paired evidence, clean-environment probes, and characterization tests that must stay green. Mean NGI on the public 22-task subset ranges from 0.0568 to 0.5760; behavior breakage ranges from 0% to 23%. A template that only adds CI and docs scores 0.272 NGI and improves environment and dependency security on none of a frozen ten-repository batch.

Analysis: [AgenticAI](../AgenticAI/2026-09-27/reasoning.md#grade-governance-with-behavior-gates)
Sources: [SWE-Prometheus](https://arxiv.org/abs/2609.29465v1), [public tasks](https://github.com/CosmosMind-ai/SWE-Prometheus)
Implementability score: 0.80

### 2. Treat leftover context as a secret store

PrivDrift seeds a secret, drifts the dialogue, then probes. Across three models and 1,000 dialogues, hybrid leakage stays between 38.7% and 54.6%. Extra drift inside the tested window does not reliably help. Topic change is not erasure.

Analysis: [Strategy](../Strategy/2026-09-27/sovereignty.md#treat-leftover-context-as-a-secret-store)
Source: [PrivDrift](https://arxiv.org/abs/2609.30094v1)
Implementability score: 0.74

### 3. Bound shared agent memory before it teaches the next fixer

Agentic autofix now reads Copilot Memory and writes the fix pattern back. Repository facts are citation-checked against the current branch and can teach code review and the cloud agent. The same Friday changelog adds an in-product validator for `copilot/managed-settings.json`.

Analysis: [Strategy](../Strategy/2026-09-27/sovereignty.md#bound-shared-agent-memory-before-it-teaches-the-next-fixer)
Sources: [autofix changelog](https://github.blog/changelog/2026-09-25-agentic-autofix-now-uses-copilot-memory/), [Copilot Memory docs](https://docs.github.com/en/copilot/concepts/agents/copilot-memory)
Implementability score: 0.86

### 4. Delegate GUI actions to a typed executor

Jev-Mobile keeps a VLM on local goals and lets a typed executor pick live accessibility-tree actions. AndroidWorld success is 0.79 versus 0.84 for step-wise VLM, with 32.7% less time and 73.4% less model API cost on successful trajectories. No public repo resolved.

Analysis: [AgenticAI](../AgenticAI/2026-09-27/reasoning.md#delegate-gui-actions-to-a-typed-executor)
Source: [Jev-Mobile](https://arxiv.org/abs/2609.30186v1)
Implementability score: 0.46

## What is implementable now

1. Add characterization tests as a behavior gate on any "improve the repo" agent run, and drop broken runs from the mean.
2. Vault secrets at disclosure and add post-drift extraction probes to session evals.
3. Review Copilot Memory repository facts the way you review custom instructions, and validate managed-settings JSON after every policy commit.
4. Keep GUI executors on live accessibility candidates; do not spend a frontier VLM call on every tap.
