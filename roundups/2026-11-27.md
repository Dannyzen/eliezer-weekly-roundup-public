# Daily AI and Agent Research Roundup: 2026-11-27

## Daily thesis

The strongest new work makes agent quality auditable before deployment: remove unnecessary patch blocks under tests, trace memory failures to the stage that lost evidence, validate security paths through execution, and prove a workload is routeable before adding a model router.

## Top findings

1. **Patch minimality needs replay, not line counting.** Delta Residue Attribution tests whether each final patch block is behaviorally necessary. Implementability: 0.78. [Source](https://arxiv.org/abs/2611.34875v1)
2. **Memory harnesses should optimize from stage-level failure evidence.** HoMe traces whether evidence was never written, overwritten, or missed by retrieval, then evaluates bounded candidate changes. Implementability: 0.72. [Source](https://arxiv.org/abs/2611.34624v1)
3. **Agent security audits need executable reachability proof.** AgentLens converts component and guardrail graphs into validated multi-turn attack paths. Implementability: 0.67. [Source](https://arxiv.org/abs/2611.34380v1)
4. **Routing starts with routeability.** RAP tests whether a model portfolio has usable prompt-level complementarity before router results are interpreted. Implementability: 0.76. [Source](https://arxiv.org/abs/2611.34825v1)

## What is implementable now

- Add step-to-diff attribution and block-removal replay to coding-agent review pipelines.
- Trace memory failures across write, supersession, retrieval, context delivery, and answer stages.
- Build a component and authority graph before designing agent security scenarios.
- Calculate router headroom, tied-best distributions, regret, and simple baselines before training a selector.
