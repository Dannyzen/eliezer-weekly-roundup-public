# Daily Agent Research Roundup, 2026-07-29

## Verdict

The best new work moves reliability out of model narration and into explicit artifacts: specifications that survive trace and replay checks, harnesses that must beat a static baseline, and state handles governed above a stateless protocol.

## Top findings

### 1. Specula closes the formal-specification loop

Specula uses agents to generate TLA+ models and invariants, but accepts them only through model checking, trace validation, and code-level replay. The authors report 249 bugs across 48 systems, including 207 new bugs; 89 were reported, 68 confirmed, and 24 fixed.

Sources: [paper](https://arxiv.org/abs/2607.25333v1), [Apache-2.0 repository](https://github.com/specula-org/Specula)
Implementability score: 0.78

### 2. Static harness optimization beats cold-start online learning

Across the released 729-configuration study, a DSPy-optimized static baseline matched or beat contextual-bandit and REINFORCE controllers across reported domains and models, usually with fewer tokens. The action is to optimize a reviewed static harness first, then demand held-out and cost evidence before enabling online adaptation.

Sources: [paper](https://arxiv.org/abs/2607.25415v1), [research repository](https://github.com/dpaul0501/context-optimization-rl)
Implementability score: 0.65

### 3. Stable MCP makes application state explicit

MCP 2026-07-28 removes protocol sessions and initialization. Stateful workflows now use explicit handles, while required operation headers, scoped caching, trace context, and conformance tests make gateways easier to operate and audit.

Sources: [stable specification](https://modelcontextprotocol.io/specification/2026-07-28), [changelog](https://modelcontextprotocol.io/specification/2026-07-28/changelog), [stable release](https://github.com/modelcontextprotocol/modelcontextprotocol/releases/tag/2026-07-28)
Implementability score: 0.90

## What is implementable now

- pilot Specula read-only against one narrow concurrent subsystem, with trace validation and code-level replay required before triage;
- add a DSPy static optimization baseline and reward decomposition before considering online harness learning;
- inventory MCP session assumptions and introduce typed, scoped, expiring application handles;
- run conformance and mixed-version fixtures before migrating remote MCP services.

## Highest and lowest implementability

Highest: MCP 2026-07-28 migration controls, 0.90.
Lowest: constrained harness optimization, 0.65, because the method is practical but the released repository has no declared license and online adaptation did not beat the static baseline.
