# Daily Roundup: 2026-11-16

## The signal

The agentic stack is becoming an evidence-bearing state machine. Harness updates, setup recovery, safe planning, and memory deletion all need explicit structure that can be replayed or verified.

## Top findings

### Harnesses can evolve as executable programs

ModHarness-RL learns compression and steering programs over typed trajectory state. On CodeSearch it improves over a fixed harness by 14 to 24 percent, with candidate programs executed and replayed before admission.

Sources: [paper v1](https://arxiv.org/abs/2611.18533v1), [project page](https://zlhe0.github.io/ModHarness-RL/)

Implementability score: 0.62

### Semantic checkpoints make coding-agent setup recoverable

HerAgent checkpoints validated functional blocks, repairs from known-good state, relocates root causes to earlier blocks, and replays the final setup in a clean container. Reported setup success rises from 52.0 to 85.0 percent on Installamatic-Bench.

Sources: [paper v1](https://arxiv.org/abs/2611.18443v1), [repository](https://github.com/BeeuniLab/pheragent)

Implementability score: 0.84

### Verified plans can recover after blocked actions

Soteria verifies tool contracts, progress, and policy compliance before execution, then enforces each call at runtime. Across 207 tasks it reports 100 percent conformance and 1.7 times the average task success of the best baselines.

Sources: [paper v1](https://arxiv.org/abs/2611.17880v1), [NeurIPS session](https://nips.cc/virtual/2026/loc/atlanta/session/176366)

Implementability score: 0.68

### Forgetting must erase the derivation closure

LinEra captures every source seen by the memory writer and binds descendant keys to that lineage. In its largest-model test, per-object or epoch keys exposed 67 of 71 forgotten secrets; LinEra exposed none.

Sources: [paper v1](https://arxiv.org/abs/2611.18133v1), [repository](https://github.com/yulliwasameur/linera)

Implementability score: 0.58

## What to build now

1. Store trajectories as typed blocks and replay harness changes before promotion.
2. Split environment setup into validated semantic blocks with clean rollback points.
3. Add pre-execution plan checks and runtime call enforcement for high-impact workflows.
4. Capture memory lineage at write time and test deletion against derived memories and backups.
