# Deep Dive Wednesday - 2026-09-02

## Thesis

Loaded skills are delayed-authority objects. Install-time vetting remains necessary. It is no longer sufficient. After a skill is in runtime context, a later user task can make leaking, approval bypass, or data staging look useful. The runtime needs a task-conditioned guard with explicit consult-before-action responsibility, then a hard broker that can still deny the effect.

## Deep Dive Wednesday: defense as skill

The week's strongest finding is Defense-as-Skill. SkillSonar is an installable Markdown guard that sits beside untrusted task skills, checks proposed actions against the current user task, and returns allow, replan, or confirmation. On Claude Code with GLM-5, N = 10, it cuts in-distribution attack success from 0.482 to 0.104 and out-of-distribution attack success from 0.606 to 0.115, while keeping more utility than Claude Code's AcceptEdits permission preset. Adding an allowlist to AcceptEdits collapses protection. The guard is still instruction-following, so it complements sandboxes and permission brokers rather than replacing them.

## Why this beat the rest of the week

- CIPR already showed that user invocation activates poisoned repositories. That is in the 2026-09-01 notes. It does not cover skills that wait for a later task.
- LoopArena separates controllers from workers. Useful for loop engineering, not skill authority.
- Salesforce TraceLab's live trace model extends June TraceLab work and is labeled descriptive because the benchmark was co-developed with the system.
- HarnessDev, Harness-of-Harness, and CordisBench improve harness creation and lifecycle reasoning. Growing the harness without a task-conditioned guard increases the skill attack surface.

## What is implementable now

- Add a Hermes guard skill with an explicit consult-before-action instruction.
- Bind sensitive actions to proposed effect, skill id, user task, and `{allow, replan, confirm}`.
- Keep sandbox and permission denial as the last word.
- Add delayed-harm fixtures that pass install review.
- Add an allowlist-regression fixture.
- Measure attack success, benign utility, confirmation count, and token cost.

Do not wait for a public SkillSonar repo. None resolved in this scan. Do not treat https://github.com/pinchbench/skill as the paper's artifact; that is PinchBench.
