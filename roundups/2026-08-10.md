# Daily Agent Research Roundup, 2026-08-10

The Monday arXiv listing is live. All four selected v1 papers were submitted on Friday, 2026-08-07 and first listed on Monday, 2026-08-10. Hugging Face, GitHub Trending, and current web-release surfaces were checked; none displaced the selected primary-source findings.

## Thesis

Agent reliability now needs explicit lifecycle controls: inject failures before production, detect drift during execution, trace influence across persistent carriers, and revoke stale memory without deleting its audit history.

## Top findings

1. AgentChaos injects runtime LLM-response faults at the shared HTTP boundary. Across 65 configurations, pass@1 fell by up to 50 percentage points and current fault diagnosis stayed below 56 percent. Score: 0.90.
2. LivePlan uses deterministic trajectory rules to trigger bounded LLM advice only when coding-agent drift appears. It improves issue resolution by 9.9 percent on average and up to 15.2 percent at low added cost. Score: 0.83.
3. HarnessSafe traces 328 cases across seven persistent-carrier families through a seven-stage lifecycle, exposing where delayed influence is actually contained. Score: 0.72.
4. TEPA makes memory validity explicit and revocable. Under full reversal it scores 0.950 versus 0.210 for append-only and last-write-wins memory. Score: 0.88.

## Implementable now

- add test-only crash, omission, and value fault injection at the LLM HTTP boundary;
- detect skipped validation, repeated failures, plan drift, and stagnation before asking an advisor model;
- represent carrier lineage from untrusted entry through persistence, trigger, policy decision, and effect receipt;
- give memory objects active, superseded, revoked, quarantined, and re-promoted states;
- preserve artifact, model, harness, policy, tool-schema, and environment identity in every evaluation receipt.
