# Daily Agent Research Roundup, 2026-07-28

## Verdict

Today's batch replaces free-floating context with state-bound evidence. Memory must reach the decision, containment must be visible across the trace, test results must name the code state they certify, and untrusted inspection should happen in a restricted child trajectory.

## Top findings

### 1. InMind exposes a query-conditioned memory blind spot

Across 125 expert-verified tasks, six memory systems reach at most 14.4 percent on indirect application while direct recall reaches up to 100 percent. The populated benchmark repository is ready for read-only inspection and later reproduction.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-28/reasoning.md#query-conditioned-memory-misses-facts-that-require-world-knowledge)
Sources: [paper](https://arxiv.org/abs/2607.24368v1), [repository](https://github.com/imlrz/InMind), [project](https://keep-it-inmind.github.io/)
Implementability score: 0.82

### 2. ContainmentBench separates final safety from trace behavior and utility

In 600 matched active-tainted pairs, two policies both produce zero committed harm, yet 73.5 percent differ in trajectory or utility. Taint-only completion is 0.1642 versus 0.8567 for a trusted ledger and 0.9233 for a strong tool-boundary baseline.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-28/reasoning.md#endpoint-security-scores-hide-containment-and-utility-failures)
Source: [paper](https://arxiv.org/abs/2607.23999v1)
Implementability score: 0.68

### 3. Typed revision contracts bind verifier evidence to code state

Across 900 three-revision trajectories, more revision raised ever-correct while lowering current correctness. In a controlled replication, stale traces harmed 34 of 135 correct starts versus 4 of 135 with current traces.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-28/reasoning.md#coding-agent-evidence-must-be-bound-to-the-exact-code-state)
Source: [paper](https://arxiv.org/abs/2607.24604v1)
Implementability score: 0.72

### 4. APPA proposes taint confinement in engine-owned child trajectories

APPA proposes prospective acquisition checks, restricted child branches for sensitive reads, and checked returns or atomic one-call rulings. It reports attack success falling from 31 to 50 percent to 0 to 7 percent across four models.

Analysis: [Strategy sovereignty](../Strategy/2026-07-28/sovereignty.md#taint-confinement-needs-engine-owned-branches-and-checked-return)
Source: [paper](https://arxiv.org/abs/2607.24625v1)
Implementability score: 0.52
