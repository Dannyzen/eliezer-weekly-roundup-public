# Daily Agent Research Roundup, 2026-08-14

## Thesis

Final success is not enough evidence. The strongest work today shows that agent systems need separate proof for command-path fidelity, process quality, property preservation, and authorized change.

## Top findings

1. **QuoteBench isolates command-path failure.** On 56 exact-state Bash tasks, one added parser damages the same replies by 55.4 to 73.2 percentage points. Contract-conditioned generation can compensate enough to hide that damage in matched scores. Score: 0.92. Sources: https://arxiv.org/abs/2608.13547v1 and https://github.com/LeonardNJU/quoteBench
2. **Long-horizon R&D agents need process metrics.** Seven frontier models, 36 tasks, and 756 rollouts show that reliability separates systems more than peak performance, experience can help or mislead, and harnesses mainly change stability. Score: 0.70. Source: https://arxiv.org/abs/2608.13417v1
3. **Iterative repair can regress previously passing security properties.** Across 5,968 IaC timelines, the conservative strict regression rate is 3.3 percent of scenarios. Regression transitions carry 2.6 times more churn and 4.9 times more strict-mode check volatility. Score: 0.88. Source: https://arxiv.org/abs/2608.13404v1
4. **CAPRI separates proof acceptance from repair authority.** Six of 144 Isabelle-accepted candidates modified protected text. An independent edit contract catches the false successes, while a proof-body-only interface removes observed violations at a cost of two repairs in 36. Score: 0.84. Source: https://arxiv.org/abs/2608.13459v1

## What is implementable now

- Add fixed-reply replay across shell, SSH, container, and CI wrappers.
- Trace framing, execution, feedback control, recovery, and best-state retention separately.
- Promote every passing check into a preservation obligation for the next repair iteration.
- Accept automated changes only when outcome validity and change authorization both pass.
- Bind release decisions to exact diffs, contract versions, validator vectors, and final-state receipts.

## Classification

- AgenticAI: command-path evaluation, deterministic process metrics, trajectory reliability, and per-property regression tracking.
- Strategy: conjunctive acceptance, independent edit contracts, path-aware approval, and monotonic property authority.

## Scope and caveats

No external repository was cloned, installed, built, imported, or executed. Paper PDFs were downloaded only as documents and inspected with `pdftotext`. QuoteBench’s public repository and project page were inspected read-only. The other three papers did not yield an exact verified public implementation artifact during this scan. All four papers were submitted on August 13 and first listed by arXiv on August 14.
