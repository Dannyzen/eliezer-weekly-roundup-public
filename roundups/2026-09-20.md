# Daily Agent Research - 2026-09-20

## Thesis

Agent reliability needs four cheap control surfaces before more autonomy: resolve tool calls against a closed world, use calibrated subsets for repeated A/B decisions, measure harness utility per token, and test memory against future updates rather than current recall alone.

## Top findings

### 1. Resolve before you authorize

A tool-policy gate cannot reject a fabricated name or undeclared signature if the call never resolved to a known contract. The study measured 322 genuine hallucinations across ten hosted models and another 154 on a merged MCP surface. Put registry membership and signature validation before authorization.

Analysis: [Strategy](../Strategy/2026-09-20/sovereignty.md#run-a-closed-world-resolver-before-policy-gates)
Source: https://arxiv.org/abs/2609.19425v1
Implementability score: 0.94

### 2. Replace ad hoc smoke tasks with a calibrated A/B set

Only 22 of 113 DeepSWE tasks reliably tracked full-benchmark performance under the study's correlation threshold. DeltaSelect turns a declared budget into a fixed, provenance-preserving task set for repeated baseline-versus-candidate decisions.

Analysis: [AgenticAI](../AgenticAI/2026-09-20/reasoning.md#use-correlated-task-sets-for-cheap-coding-agent-ab-tests)
Sources:
- https://arxiv.org/abs/2609.19607v1
- https://agent-layer.dev/deltaselect
- https://github.com/conn-castle/agent-layer
Implementability score: 0.88

### 3. Measure useful work per token

SoL-Pi reports comparable 51-task EdgeBench performance while reducing recorded token traffic by 44.7% to 49.0% and API cost by about one third. The durable pattern is component-level utility, cost, and regression measurement, not blind recursive self-improvement.

Analysis: [AgenticAI](../AgenticAI/2026-09-20/reasoning.md#treat-token-efficiency-as-a-measured-harness-outcome)
Sources:
- https://arxiv.org/abs/2609.20519v1
- https://github.com/NVlabs/SoL-Pi
Implementability score: 0.80

### 4. Test memory for tomorrow's update

A compressed memory can answer correctly now while erasing the distinction needed after a shared future update. Paired-history tests, identifier renaming, tombstone deletion, and late-reference replay expose this hidden loss.

Analysis: [AgenticAI](../AgenticAI/2026-09-20/reasoning.md#audit-compressed-memory-against-future-updates)
Source: https://arxiv.org/abs/2609.20045v1
Implementability score: 0.66

## What is implementable now

1. Add closed-world name and signature resolution before existing tool-policy gates.
2. Freeze a budgeted, calibrated task set for every repeated coding-agent change.
3. Record task success, token traffic, cost, and latency for each harness component.
4. Add paired-history future-update fixtures to memory regression suites.
