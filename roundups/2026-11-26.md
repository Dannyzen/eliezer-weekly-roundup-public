# Daily AI and Agent Research Roundup: 2026-11-26

## Daily thesis

The strongest signal today is that reliable improvement needs explicit evidence objects at every layer: replay fixtures for production failures, typed context edits, verification certificates, and claim-level training targets.

## Top findings

1. **Sports Agent operationalizes continuous evolution.** Production failures become diagnosed, replayable inputs to separate model and harness loops, with audit and regression gates. Implementability: 0.72. [Source](https://arxiv.org/abs/2611.33700v1)
2. **Model-managed context becomes a runtime interface.** Typed context operations plus KV-cache-aware serving improved accuracy or reduced token and prefill cost in several reported settings. Implementability: 0.76. [Source](https://arxiv.org/abs/2611.34147v1)
3. **Agent-as-a-Verifier emits evidence certificates.** Acceptance contracts, obligations, checks, and evidence replace an opaque scalar score as the release artifact. Implementability: 0.74. [Source](https://arxiv.org/abs/2611.34132v1)
4. **Operator answers need claim-level verification before training.** Supported claims become reward targets; unsupported claims become knowledge or tool gaps. Implementability: 0.68. [Source](https://arxiv.org/abs/2611.34341v1)

## What is implementable now

- Turn recurring production failures into versioned replay fixtures before editing prompts or skills.
- Add typed context inspection and compaction operations with token, latency, cache, and outcome telemetry.
- Compile acceptance criteria into explicit verification obligations and preserve the evidence behind each verdict.
- Audit human answers claim by claim before using them as supervised or reinforcement-learning targets.

## Evidence boundary

All four papers were submitted on 2026-11-25 and first listed by arXiv on 2026-11-26. General-Verifier and Mainplane were inspected through GitHub metadata, README, and repository trees only. No external source was cloned, installed, built, imported, or executed.
