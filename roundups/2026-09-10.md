# Daily Agent Research Roundup - 2026-09-10

## Thesis

The agentic stack needs a preflight-to-proof chain. Detect missing implementation decisions before code generation, preserve history while gating which memory can influence a query, isolate automated repairs on reviewable branches, and authenticate both trajectory ownership and local integrity.

## Top findings

### 1. IdeaAMBIG turns underspecification into an executable preflight

The 660-instance benchmark shows that models are much better at asking a useful question after a defect is identified than at locating the defect themselves. The best real-world defect recovery rate was 9.6%; clarification success reached 80.6% with the defect supplied. The actionable pattern is a fail-closed codification-readiness gate before planning or coding.

Implementability score: 0.84

Sources: [paper](https://arxiv.org/abs/2609.10539v1), [repository](https://github.com/Yiling-Ma/IdeaAMBIG)

### 2. RD-Forget separates retained history from answer-time authority

The paper's training-free design keeps source observations, suppresses superseded facts only for current-state use, and re-admits them for historical questions. Across five suites and four models, fact-consolidation gains over the stronger baseline ranged from 11 to 26 points.

Implementability score: 0.68

Source: [paper](https://arxiv.org/abs/2609.10263v1)

### 3. GitHub now offers branch-isolated bulk agentic remediation

GitHub Code Quality can assign up to 25 findings to Copilot, which works on a branch, validates changes, and opens a pull request. This is useful now where Code Quality is enabled, but independent acceptance and review remain necessary.

Implementability score: 0.92

Source: [GitHub changelog](https://github.blog/changelog/2026-09-09-remediate-code-quality-findings-with-agentic-autofix/)

### 4. TrajMark splits trajectory ownership from tamper localization

The method combines a robust owner channel with fragile local seals. It reports exact owner recovery on all clean evaluated batches, 95.5% to 100% detection under eligible single-site attacks, and 95.8% protocol-region localization under random single-action corruption. The design is promising, but no reusable paper-owned implementation resolved.

Implementability score: 0.46

Source: [paper](https://arxiv.org/abs/2609.10416v1)

## What is implementable now

- Add ready, blocked, and clarification-required outcomes to specification preflight.
- Preserve source memory and build query-conditioned evidence views instead of deleting superseded facts.
- Pilot GitHub's branch-isolated remediation on low-risk Code Quality findings.
- Add signed chunk roots and local commitments to trajectory receipts before experimenting with behavioral watermarks.

## Signal separated from noise

- GitHub's agentic-autofix announcement is a September 9 product release.
- Discovery Certification Protocol and the Double Measurement Confound were first listed September 10 but submitted September 7 and 6, so they were not promoted into the strict rolling-window top four.
