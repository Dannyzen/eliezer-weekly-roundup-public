# Daily Agent Research: 2026-11-13

## Top findings

### 1. Delegation loses when it distorts the question or drops evidence

Lost in Delegation found no consistent accuracy benefit from delegated generative search and larger failures on post-cutoff facts. The useful control is an evidence contract across the handoff, not more worker agents.

Source: [Lost in Delegation](https://arxiv.org/abs/2611.16526v1)

Implementability score: 0.83

### 2. Tool agents need state-paired action tests

StateAlign trains against paired states that change whether an agent should call, ask, retrieve, decline, continue, or stop. The public artifacts make the method inspectable, though reproducing the RL results requires substantial infrastructure.

Sources: [StateAlign](https://arxiv.org/abs/2611.16304v1), [repository](https://github.com/ZhexiLu/StateAlign)

Implementability score: 0.63

### 3. Memory benchmarks should score operational effects

AstroMemBench turns domain hazards into 2,240 deterministic history-dependent scenarios. Its reusable contribution is the Scenario-Challenge-Capability design method and matched testing across context, retrieval, and persistent memory.

Sources: [AstroMemBench](https://arxiv.org/abs/2611.16590v1), [repository](https://github.com/flyingView/AstroMemBench-v1)

Implementability score: 0.82

### 4. Memory architecture can be searched as a costed program

MAPE evolves whole memory programs behind stable lifecycle interfaces. Its strongest transferable result is that joint accuracy-cost search produced cheaper, more selective designs than accuracy-only optimization.

Sources: [MAPE](https://arxiv.org/abs/2611.17068v1), [repository](https://github.com/ash-ding/MAPE)

Implementability score: 0.58

## What to use now

- evidence-bearing delegation contracts with explicit retrieval failures
- paired task-state fixtures for every tool action boundary
- deterministic memory scenarios derived from operational hazards
- fixed memory lifecycle interfaces with accuracy and cost scored together

## Signal and noise

All four papers were submitted November 12 and first listed November 13. Three have populated public repositories verified read-only. No external source code was cloned, installed, built, imported, or executed.
