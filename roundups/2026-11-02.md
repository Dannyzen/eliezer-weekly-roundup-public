# Daily Agent Research Roundup: 2026-11-02

## Scope

The Monday arXiv listing is live. These four v1 papers were submitted October 30 and first listed November 2. External repositories were inspected read-only only.

## 1. Recovery needs evidence, not blind retries

Ambiguous tool outcomes require explicit committed, pending, partial, failed, and unresolved states. In an authored 185-record workload, planning assistance produced 30 certified safe completions in 58 paired episodes versus 9 of 58 for evidence prompting.

Action now: persist dispatch and settlement events, query authoritative state, make retries idempotent, and preserve handoff or unknown as valid outcomes.

Implementability score: 0.83

Source: https://arxiv.org/abs/2610.41453v1

## 2. Authorization must survive interface changes

GUI, CLI, API, script, and MCP routes can reach the same effect with different defaults and security context. Normalize the effect, bind the grant to one route and state snapshot, recheck at commit, and require a matching sink receipt.

Action now: inventory alternate routes and add bypass, stale-state, and default-value mutants to release tests.

Implementability score: 0.64

Source: https://arxiv.org/abs/2610.41397v1

## 3. Tool traces are behavioral side channels

PrivacyTrace reports 26.25% profile-inference success from tool-call traces versus 17.97% from priors across 1,000 synthetic profiles and 4,000 trajectories. Arguments, returned results, and cross-session linkage carry the strongest evidence.

Action now: minimize payload logging, isolate trace stores, restrict joins, shorten retention, and audit exports for attribute inference.

Implementability score: 0.78

Sources:
- https://arxiv.org/abs/2610.41885v1
- https://github.com/AI45Lab/PrivacyTrace

## 4. Memory quality is correction plus retention

KEEPER isolates self-consistency bias: recursive summaries can preserve contradicted claims because each update reads prior memory. Task success alone cannot prove correction or retention.

Action now: test contradiction, recurrence, omission, and valid-information retention against source-linked claims. Keep canonical events outside rewritten summaries.

Implementability score: 0.55

Source: https://arxiv.org/abs/2610.41482v1

## Daily thesis

The runtime needs two boundaries: evidence before recovery, and authorization before effect. Keep canonical events for proof, compile only the minimum memory and telemetry needed for the next decision, and treat durable traces as sensitive.
