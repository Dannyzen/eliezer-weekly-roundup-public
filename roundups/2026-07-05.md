# Daily Roundup, 2026-07-05

Today's scan found four strong items. The shared thesis is selective evidence before autonomy: memory influence, reasoning budget, test evolution, and skill composition need explicit gates before the platform grants more authority.

## Top findings

### 1. Memory systems need failure-mode tests, not only recall tests

MemSyco-Bench evaluates memory-induced sycophancy across objective facts, contextual scope, evidence conflicts, valid memory selection, and personalization. A-TMA adds ghost-state control: current, historical, and transition facts must be labeled and evaluated separately across bank maintenance, retrieval, and answer-time resolution.

### 2. Reasoning budgets should be routed before extra tools

A 90-run coding-agent study found that browser-based testing raised cost by 42 to 68 percent without improving functional score or first-try reliability. Raising reasoning effort from High to xHigh lifted first-try perfect runs from 28 percent to 89 percent and reduced corrective prompts about fivefold.

### 3. Live test co-evolution benchmarks expose coding-agent regressions

TestEvo-Bench evaluates whether agents update tests with code, using 746 test-generation tasks and 509 test-update tasks from 152 Java projects. Prompt Coverage Adequacy adds a complementary metric: prompt-level requirement coverage can uncover more faults than traditional code coverage when guiding test generation.

### 4. Skill composition needs fuzzing before marketplace admission

SkillFuzz shows that individually benign skills can compose into implicit intents. It treats skill compositions as the unit under test, extracts skill contracts, searches risky co-activations, and uses plan differences against a skill-free baseline before execution-time validation.

## What is implementable now

- Add MemSyco-Bench style memory tests where the correct behavior is to ignore, scope, or override a recalled memory.
- Add state-role fields to memory packets: current, superseded, historical, transition, conflicting, and personalization-only.
- Route reasoning effort deliberately before adding broad browser, shell, or network tool access.
- Mine internal code-plus-test evolution fixtures and score test generation and test update separately.
- Add skill composition fuzzing before production admission, then detonate only the highest-risk compositions.

## Working conclusion

The daily thesis is selective evidence before autonomy. The next serious agent stack will not just remember more, use more tools, run more tests, or load more skills. It will prove when each state object is allowed to matter.
