# Daily Synthesis: 2026-05-24

Today’s strongest signal: agent systems are becoming runtime infrastructure. The winning surfaces are not bigger prompts; they are terminal-coded browsers, compiled skill/API/MCP interfaces, schedulable tool waits, and stateful eval packages.

## Top findings

### 1. Browser agents are becoming terminal-coded workspaces
- Category: [AgenticAI](../AgenticAI/2026-05-24/reasoning.md#browser-agents-are-becoming-terminal-coded-workspaces)
- Durable topic: [GUI-Tool Path Orchestration](../AgenticAI/gui-tool-path-orchestration/gui-tool-path-orchestration.md)
- Core sources: https://www.microsoft.com/en-us/research/articles/webwright-a-terminal-is-all-you-need-for-web-agents/, https://github.com/microsoft/Webwright
- Why it matters: Webwright treats the browser as something a coding agent controls through scripts, screenshots, logs, and fresh-run validation. The persistent artifact is a rerunnable script, not a fragile click transcript.
- Implementable now: add Playwright-script mode to browser-agent evals, require scripts/logs/screenshots/final assertions, and promote repeated wins into reviewed local tools.
- Implementability score: 0.78

### 2. Skills are becoming API and MCP compilation units
- Category: [AgenticAI](../AgenticAI/2026-05-24/reasoning.md#skills-are-becoming-api-and-mcp-compilation-units)
- Durable topic: [Skills as Control](../AgenticAI/skills-as-control/skills-as-control.md)
- Core sources: https://arxiv.org/abs/2605.22733, https://github.com/edwinjosechittilappilly/harnessapi, https://github.com/unbrowse-ai/unbrowse, https://github.com/colbymchenry/codegraph
- Why it matters: skill folders, MCP tools, HTTP APIs, browser API paths, and local code graphs are converging into one compiled substrate. That reduces drift and gives agents typed, permissionable surfaces instead of more prompt text.
- Implementable now: make typed schemas the source of truth, expose high-value skills through HTTP and MCP, review API-captured browser flows before reuse, and add local code-graph indexes for large repos.
- Implementability score: 0.72

### 3. Tool wait time is becoming schedulable compute
- Category: [AgenticAI](../AgenticAI/2026-05-24/reasoning.md#tool-wait-time-is-becoming-schedulable-compute)
- Durable topic: [Agentic Search and Retrieval](../AgenticAI/agentic-search/agentic-search.md)
- Core sources: https://arxiv.org/abs/2605.21965, https://arxiv.org/abs/2605.22154, https://github.com/mehrdadsaberi/spechop
- Why it matters: multi-hop agents waste wall-clock time waiting on search, retrieval, browsers, and code execution. SpecHop and IdleSpec show that idle time can be used for reversible speculation, prefetching, and recovery planning.
- Implementable now: measure tool-wait time, start with read-only speculation, keep speculative branches out of memory until verified, and log commits/rollbacks/cost.
- Implementability score: 0.46

### 4. Workflow eval is moving from final answers to stateful work products
- Category: [AgenticAI](../AgenticAI/2026-05-24/reasoning.md#workflow-eval-is-moving-from-final-answers-to-stateful-work-products)
- Durable topics: [Trajectory-Aware Evaluation](../AgenticAI/trajectory-aware-evaluation/trajectory-aware-evaluation.md), [Agentic Search and Retrieval](../AgenticAI/agentic-search/agentic-search.md)
- Core sources: https://arxiv.org/abs/2605.22219, https://arxiv.org/abs/2605.22664, https://arxiv.org/abs/2605.22608, https://arxiv.org/abs/2605.22564, https://github.com/TIGER-AI-Lab/ClawBench, https://github.com/camel-ai/GBQA
- Why it matters: agents fail by setting the wrong retrieval state, producing unreviewable spreadsheets, skipping verifier evidence, or hiding process defects behind a plausible final answer.
- Implementable now: preserve state snapshots, grade formulas/data lineage/modifiability, add system/trace/node labels, and audit synthetic traces before using them as eval data.
- Implementability score: 0.62

## Actionable moves

1. Add a “browser task as script” lane to browser-agent testing.
2. Start new production skills from typed schemas and expose them through both HTTP and MCP where useful.
3. Instrument tool-wait time. Only speculate on reversible read-only branches until branch logging is solid.
4. Treat eval outputs as evidence packages: trace, state, artifacts, verifier result, cost, and failure taxonomy.
5. Add retrieval-state checks to research agents; “found the right site” is not enough.
