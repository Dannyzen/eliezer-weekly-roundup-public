# Daily Agent Research Roundup: 2026-09-18

## Thesis

The harness is becoming a testable control plane. Components should be selected by measured conditions, incidents should become selective replay fixtures, traces should aggregate into semantic profiles, and persistent skill edits should pass reversible release gates.

## Freshness note

Three selected papers were submitted on 17 September 2026 and first listed on 18 September. AgentPProf was submitted on 14 September but first listed in today's cs.AI batch, so it is current by listing date but outside a strict trailing 48-hour submission window. Primary papers and linked repositories were inspected read-only. No external code was cloned or executed.

## Top findings

### 1. Select harness components by model and budget

A 176-setting controlled study found that context management, planning, and action-space choices have conditional value. Deterministic elision before summarization is the strongest general efficiency pattern. Recoverable elision adds machinery with no measured accuracy gain in this study.

Primary: https://arxiv.org/abs/2609.20804v1
Implementability score: 0.84

### 2. Convert incidents into cut-point replay tests

Chronicle records nondeterministic boundaries and runs only selected boundaries live against new code. On six incidents, full replay made zero model calls and stayed bit-stable across 20 runs. Selective replay caught every unsafe-action mutant; fully stubbing the trajectory caught none.

Primary: https://arxiv.org/abs/2609.20625v1
Artifact: https://github.com/theagentplane/chronicle
Implementability score: 0.93

### 3. Profile stable task intent across many runs

AgentPProf turns local agent traces into pprof-compatible semantic stacks. It reached 0.764 B3 F1 against human segmentation, improved localization ranking across three benchmarks, and exposed cross-run token hotspots that ordinary timelines hide.

Primary: https://arxiv.org/abs/2609.20301v1
Artifact: https://github.com/eunomia-bpf/agentsight
Implementability score: 0.80

### 4. Gate skill mutations with localized tests and rollback

SkillAA separates skill applicability, procedure, exclusion, and dependency objects. It routes failures to a specific edit or NO_PATCH, retests affected cases, rolls back harmful atomic groups, and commits only a net-positive merged graph.

Primary: https://arxiv.org/abs/2609.20455v1
Artifact: https://github.com/Ziqiao-Shang/SkillAA
Implementability score: 0.62

## Implementable now

- Run a small harness ablation instead of adopting every scaffold.
- Turn one known production failure into a selective replay fixture.
- Generate semantic token and failure profiles across local agent sessions.
- Require stable object IDs, affected-case tests, and rollback for skill updates.

## Scope and evidence boundary

Chronicle and AgentPProf have mature public implementation surfaces. SkillAA has code, configurations, tests, and verification scripts but no license or releases. The harness study exposes no paper-specific implementation repository. Scores reflect transferability, artifact readiness, and engineering burden, not independent reproduction.
