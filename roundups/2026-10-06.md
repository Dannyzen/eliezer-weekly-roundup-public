# Daily Agent Research Roundup: 2026-10-06

## Thesis

Reliable agent systems need inspectable behavior, executable local policy, hard tenant boundaries, and visible control adoption. Each finding today converts a soft assumption into a state that can be checked.

## Top findings

### 1. Evidence graphs make consequential agent behavior reviewable

AgentMonBench and EBG connect flagged decisions to source-linked behaviors and evidence instead of asking reviewers to reconstruct long trajectories from raw context. The public code and dataset make the evaluation surface available now.

Implementability score: 0.82

Sources:
- https://arxiv.org/abs/2610.06406v1
- https://github.com/zhk-lab/EBG
- https://huggingface.co/datasets/ZhaoHongKang/AgentMonBench

### 2. Repository policy needs executable trajectory checks

SWE-CC compiles 823 policies from 12 repositories into deterministic checkers and evaluates 500 contribution tasks. Functionally correct patches still violated 43.1% of applicable policies, and 50.3% of violations occurred before the final artifact.

Implementability score: 0.90

Sources:
- https://arxiv.org/abs/2610.06193v1
- https://github.com/dangtruong01/swe-cc-arxiv

### 3. Shared memory needs a hard ownership gate

MemLeak shows that semantic similarity can cross tenant boundaries during ordinary retrieval. Hard post-retrieval ownership checks restored the reported clean baseline with roughly 1.4 milliseconds of overhead per query.

Implementability score: 0.93

Source:
- https://arxiv.org/abs/2610.04195v1

### 4. GitHub now exposes AI Scan adoption by repository

Organization and enterprise security overviews now report effective AI Scan enablement, support enabled and not-enabled filters, and include the field in coverage CSV exports.

Implementability score: 0.97

Source:
- https://github.blog/changelog/2026-10-06-code-scanning-ai-scan-enablement-status-in-security-overview

## What to implement now

1. Put a deterministic owner and tenant check after vector retrieval and before prompt assembly.
2. Compile high-value repository policies into checkers that inspect trajectories and final artifacts.
3. Preserve source-linked evidence objects for consequential agent decisions.
4. Export AI Scan enablement and reconcile it against the intended repository fleet.
