# Daily Agent Research Roundup, 2026-07-31

## Verdict

Today's batch replaces three informal assumptions with testable harness objects: teammate awareness becomes a message channel, coding tasks become executable lifecycles, and trajectory reward becomes a judge audit. AISPA adds the governance counterpart: system prompts need assurance and provenance, not trust by position.

## Top findings

### 1. AgentRadio makes mid-run correction asynchronous

Four agents with passive awareness resolved 62.1 percent of 124 SWE-Atlas QnA tasks, versus 32.3 percent for one agent and 37.9 percent for compute-matched best-of-six sampling. The public Apache-2.0 artifact contains adapters, prompts, data, and verifier code.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-31/reasoning.md#agentradio-adds-passive-awareness-to-concurrent-agent-work)
Sources: [paper](https://arxiv.org/abs/2607.28430v1), [repository](https://github.com/Coral-Protocol/AgentRadio)
Implementability score: 0.84

### 2. AISPA turns system prompts into assurance artifacts

Across 88 commercial products, only about 24 percent covered all eight user-protection dimensions and roughly 40 percent contained at least one problematic instruction. The expanded public corpus is useful for discovery, but removes reviewer-source fields and does not guarantee prompt authenticity or freshness.

Analysis: [Strategy sovereignty](../Strategy/2026-07-31/sovereignty.md#aispa-makes-system-prompts-auditable-governance-artifacts)
Sources: [paper](https://arxiv.org/abs/2607.28617v1), [index](https://systempromptindex.com/), [repository](https://github.com/XiangningLin/SystemPromptIndex)
Implementability score: 0.80

### 3. Change2Task rebuilds real tasks on modern code

The method finalized 900 paired tasks from 1,130 eligible historical changes and produced 29.2 percent more verified tasks than a pull-request mirror baseline on a matched candidate set. The lifecycle pattern is concrete, but no paper-owned public implementation artifact resolved.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-31/reasoning.md#change2task-reconstructs-executable-tasks-on-healthy-modern-code)
Source: [paper](https://arxiv.org/abs/2607.28591v1)
Implementability score: 0.68

### 4. OSReward audits model judges for false success

Across 1,019 human-gold trajectories and 27 VLM judges, the hard-set mean fell to 52 percent and false success dominated errors. The protocol is immediately useful, but the advertised code and data artifacts were missing or empty at scan time.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-31/reasoning.md#osreward-audits-the-judge-before-trusting-trajectory-reward)
Sources: [paper](https://arxiv.org/abs/2607.28609v1), [project](https://os-copilot.github.io/OSReward-Home/)
Implementability score: 0.60

## What is implementable now

1. Add scoped append-only inboxes that workers drain between tool steps, then ablate them against blocking handoffs and compute-matched sampling.
2. Put system prompts under version control with provenance, span-level assurance review, behavioral tests, and approval invalidation on semantic change.
3. Pilot pull-request reversal on one healthy modern repository with pass-fail-pass targets and protected regressions.
4. Build a small human-gold trajectory set and track true-failure recall before trusting any model judge.

- Lowest: OSReward, 0.60, because its advertised public artifacts had not landed.
