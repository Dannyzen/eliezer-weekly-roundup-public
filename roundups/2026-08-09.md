# Daily Agent Research Roundup, 2026-08-09

No new arXiv listing appears on Sunday. This scan uses non-duplicate findings from the Friday, 2026-08-07 listing batch, plus official Hugging Face, GitHub Changelog, and GitHub Trending checks. The feed and trending lanes did not beat the selected papers on novelty and evidence.

## Thesis

The agentic stack needs explicit interfaces at four hidden boundaries: document access, scaffold planning, skill admission, and trajectory risk.

## Top findings

1. READ replaces dense top-k retrieval with deterministic search, structure, and bounded reads. It reached 58.8 percent on 51 verified financial-report questions versus 35.3 percent for tuned dense retrieval, while not significantly beating BM25. Score: 0.88.
2. DCAS shows that fine-tuning can install scaffold-specific planning conventions. A 576-trajectory planning dataset improved unseen-scaffold SWE-bench performance by 3.4 points on OpenCode and 7.0 points on mini-swe-agent. Score: 0.72.
3. Malicious skill files exploited Gemini CLI in 95.5 to 96.1 percent of tested runs and Qwen Code in 71.6 to 74.0 percent under auto-approved delegated execution. Score: 0.84.
4. DreamGuard compresses trajectory risk into a recurrent runtime state and reports 25-millisecond guardrail calls, 96.3 percent pre-hazard intervention recall, and 72.92 percent online safety with 90.38 percent utility. Score: 0.52.

## Implementable now

- expose read-only `search`, `list`, `outline`, and bounded `read` tools before adding dense retrieval;
- bind coding-agent scores to model, planner, scaffold, protocol, tool schema, and version;
- admit skills by exact artifact identity, capability manifest, static review, sandbox detonation, and runtime policy;
- maintain compact trajectory-risk state outside the acting model, but keep deterministic policy as final authority.
