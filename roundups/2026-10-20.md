# Daily Agent Research Roundup - 2026-10-20

## Thesis

Today's strongest signal is that evidence integrity must survive the whole path from tool execution to context assembly, review, and external effect. Correct computation is insufficient when retrieval substitutes another output, compression drops a qualifier, delivery misses integration obligations, or approval is not bound to the connection that acts.

## Top findings

### 1. Retrieved tool output can reduce accuracy after correct computation

Same Simulation, Different Evidence replayed 11,007 deterministic simulator calls and isolated an evidence-substitution failure. Naming the authoritative output recovered 6.3 to 7.9 accuracy points across three GPT models.

Action now: label authoritative outputs and trace build, exposure, and closure separately.

Implementability score: 0.88

Source: https://arxiv.org/abs/2610.26836v1

### 2. Context compression needs direct evidence-recall gates

KEEP-Bench provides 4,102 proposition-level cases for parallel, conditional, and minority evidence. Strong models preserved every required proposition in only 61.6 to 66.8 percent of cases.

Action now: run evidence preservation tests alongside token, latency, cost, and task metrics.

Implementability score: 0.76

Sources:
- https://arxiv.org/abs/2610.26827v1
- https://github.com/PlusLabNLP/KEEP-Bench
- https://huggingface.co/datasets/uclanlp/KEEP-Bench

### 3. Coding-agent acceptance must grade complete PRD delivery

PACE uses 43 mature-repository tasks and 750 expert-audited Code Points. The best complete-delivery rate was 14.0 percent, with missing integration and incomplete implementation as the main failures.

Action now: freeze atomic acceptance obligations and separate component, integration, and complete-delivery scores.

Implementability score: 0.62

Source: https://arxiv.org/abs/2610.26394v1

Artifact caveat: the paper's named GitHub repository did not resolve during this scan.

### 4. Agent egress approval can be bound to one kernel-held connection

Connection Escrow parks outbound TCP connections before packets leave, then releases only on a signed, unexpired, single-use verdict bound to socket and destination. The prototype passed 36 adversarial checks and gated 600 connections on single-node Kubernetes.

Action now: evaluate kernel-held egress for privileged agent pods where proxies and SDK hooks are insufficient.

Implementability score: 0.58

Sources:
- https://arxiv.org/abs/2610.26501v1
- https://github.com/45h0kg/benign-attach-gateway

## What is implementable now

1. Add authoritative-output labels and evidence-path stages to deterministic tool traces.
2. Add proposition-level evidence preservation tests to context-compaction evaluations.
3. Compile PRDs into auditable Code Points before coding-agent execution.
4. Spike one fail-closed, identity-bound egress gate in an isolated Linux lab before considering production use.

## Signal and caveats

- All four papers were first listed by arXiv on 2026-10-20 and submitted on 2026-10-19.
- KEEP-Bench and Connection Escrow have populated public artifacts inspected read-only.
- PACE names an unresolved repository, so exact reproduction is currently blocked.
- Connection Escrow is a promising prototype with meaningful Linux, privilege, protocol, and scale limits.
- No external repository code was cloned or executed.
