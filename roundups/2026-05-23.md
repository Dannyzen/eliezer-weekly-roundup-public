## Top findings

### 1. Source-level self-evolution needs replay-gated code promotion
- Category: [AgenticAI](../AgenticAI/2026-05-23/reasoning.md#source-level-self-evolution-has-to-be-a-replay-gated-code-promotion-loop)
- Durable topic: [Agent Harness Architecture](../AgenticAI/agent-harness-architecture/agent-harness-architecture.md)
- Core source: https://arxiv.org/abs/2605.22794v1
- Why it matters: MOSS says prompt, skill, memory, and workflow mutation cannot fix structural failures in routing, hook ordering, state invariants, or dispatch. If agents modify source, the right primitive is not self-editing freedom; it is failure-batch replay, isolated candidate images, predicted-effect manifests, consent gates, health probes, and rollback.
- Implementable now: build replay suites, version harness/source components, require patch manifests, test candidate containers, and block promotion without evidence.
- Implementability score: 0.58

### 2. Workflow control is becoming a placement decision: graph, prompt, gateway, code, or weights
- Category: [AgenticAI](../AgenticAI/2026-05-23/reasoning.md#workflow-control-is-splitting-between-graph-serving-and-weight-compilation)
- Durable topic: [Agent Harness Architecture](../AgenticAI/agent-harness-architecture/agent-harness-architecture.md)
- Core sources: https://arxiv.org/abs/2605.22566v1, https://arxiv.org/abs/2605.22502v1
- Why it matters: GraphFlow externalizes workflows into a reusable graph substrate with KV-cache-aware serving. The workflow-compilation paper pushes stable procedures into small model weights to cut cost and context exposure. These are not contradictions; they define a placement problem.
- Implementable now: benchmark prompt-only, graph-orchestrated, and fine-tuned variants for one stable procedural workflow; track cost, latency, memory, failures, and auditability.
- Implementability score: 0.54

### 3. KV-cache sharing is a hidden data boundary
- Category: [Strategy](../Strategy/2026-05-23/sovereignty.md#kv-cache-sharing-creates-an-opaque-data-boundary)
- Durable topic: [Agent Network Containment](../Strategy/agent-network-containment/agent-network-containment.md)
- Core source: https://arxiv.org/abs/2605.22786v1
- Why it matters: LCGuard shows that multi-agent latent communication can leak sensitive information through shared KV caches even when no explicit text disclosure occurs. Text DLP does not cover latent state transfer.
- Implementable now: treat KV caches, embeddings, summaries, and compressed memory as governed data artifacts; require provenance, sensitivity labels, retention rules, and leakage tests before cross-principal sharing.
- Implementability score: 0.42

### 4. Agent security needs whole-run evasion tests and MCP client telemetry
- Category: [Strategy](../Strategy/2026-05-23/sovereignty.md#agent-security-needs-stateful-evasion-tests-plus-live-mcp-client-inventory)
- Durable topics: [Agent Network Containment](../Strategy/agent-network-containment/agent-network-containment.md), [Agent Gateway Governance](../Strategy/agent-gateway-governance/agent-gateway-governance.md)
- Core sources: https://arxiv.org/abs/2605.22321v1, https://github.com/antgroup/Agent3Sigma-Stage, https://huggingface.co/datasets/evalstate/mcp-clients
- Why it matters: A3S-Bench attacks agents through temporal, spatial, and semantic evasion. The MCP clients dataset shows live client capabilities vary across UI, elicitation, roots, sampling, tasks, and experimental auth. Gateway policy needs both stateful trace inspection and client-capability inventory.
- Implementable now: run evasion suites, label trace influence paths, scan external artifacts, inventory MCP clients, and gate high-risk client capabilities by identity and policy.
- Implementability score: 0.74
