# Daily Agent Research - 2026-09-22

## Thesis

Execution evidence is becoming reusable infrastructure: traces can cut regression cost, future actions can grade memory, and optimized harnesses can compile training data. External effects still need a separately certified policy boundary.

## Top findings

### 1. Select small regression sets from agent trajectories

A 10 percent trajectory-aware SWE-agent subset cut measured token use from 3.44 billion to 345 million while keeping median resolve-rate estimation error below 5 percent. The public artifact includes selectors, standardized traces, results, and a reproduction entrypoint.

Analysis: [AgenticAI](../AgenticAI/2026-09-22/reasoning.md#select-regression-tasks-from-prior-trajectories-not-convenient-examples)
Sources:
- https://arxiv.org/abs/2609.24928v1
- https://github.com/SAILResearch/swe-agent-subset-selection
Implementability score: 0.88

### 2. Grade memory on future effects and operational cost

DolphinBench releases 600 action tasks across three long synthetic histories, exact tool-effect graders, and official accuracy, cost, and latency results. The highest official configuration reached 70.7 percent, and memory-system rank changed across models and harnesses.

Analysis: [AgenticAI](../AgenticAI/2026-09-22/reasoning.md#evaluate-memory-by-future-effects-cost-and-latency)
Sources:
- https://arxiv.org/abs/2609.24971v1
- https://github.com/mem0ai/dolphinbench
- https://dolphinbench.ai/
Implementability score: 0.82

### 3. Use optimized harnesses as training-time teachers

Harness-Zero reviews student actions under specialized harness guidance, fine-tunes the accepted trajectories, then removes the teacher at deployment. Reported macro-average success rose from 23.3 percent to 44.3 percent, with a populated Apache-2.0 artifact.

Analysis: [AgenticAI](../AgenticAI/2026-09-22/reasoning.md#distill-harness-behavior-into-the-model-before-deployment)
Sources:
- https://arxiv.org/abs/2609.24974v1
- https://github.com/metaevo-ai/harness-zero
Implementability score: 0.52

### 4. Let models draft policy, then certify and freeze it

ActGov maps candidate tool actions and context into a finite policy record, verifies the policy bundle offline with Z3, and makes runtime action decisions deterministically. It reduced attack success sharply on AgentDojo and AgentDyn, but clean utility fell in some settings and cross-environment transfer was poor.

Analysis: [Strategy](../Strategy/2026-09-22/sovereignty.md#let-models-propose-policy-then-certify-and-freeze-it-before-effects)
Source: https://arxiv.org/abs/2609.24446v1
Implementability score: 0.48

## What is implementable now

1. Build a trace-selected regression subset and calibrate it against periodic full runs.
2. Add future-effect memory fixtures with paired history and no-history certification.
3. Use strong harness review to create training data only after a held-out pilot proves the gain.
4. Compile reviewed policy into a frozen deterministic pre-action check, and report utility beside security.
