# Daily Agent Research Roundup: 2026-11-11

Today's signal is inspectable state: memory lessons need source trajectories, long runs need persistent private workspaces, finished deliverables need artifact-level grading, and personal-agent actions need policy outside the prompt.

## Top findings

### 1. Evidence-linked memory beats detached lessons

WikiTrace links each reusable insight to a compilation and raw trajectory. Across five benchmarks and eight suites, it averaged 90.2 versus 87.0 for identical insights without source access, while reducing memory Regression from 6.5 percent to 4.5 percent.

Implementability score: 0.88

Analysis: [AgenticAI](../AgenticAI/2026-11-11/reasoning.md#1-link-every-reusable-lesson-to-its-source-trajectory)

Sources: [paper](https://arxiv.org/abs/2611.14320v1), [repository](https://github.com/yukyeongleee/wikitrace)

### 2. File operations are a transferable memory interface

CAMG-II keeps an episode-private workspace across context replacement. CAMP-II trains policies to use ordinary files as memory; its 9B policy outscored a 35B comparison model on Terminal-Bench 2.1 and SWE-Bench Pro V2.

Implementability score: 0.46

Analysis: [AgenticAI](../AgenticAI/2026-11-11/reasoning.md#2-treat-a-persistent-workspace-as-the-models-memory-interface)

Source: [paper](https://arxiv.org/abs/2611.14009v1)

### 3. Visual knowledge work needs deliverable-level grading

MKA uses 200 private professional tasks, about 70 rubric checks per task, a common open-source harness, and a grader that renders files and inspects formulas. Ten public tasks expose the format for local adaptation.

Implementability score: 0.82

Analysis: [AgenticAI](../AgenticAI/2026-11-11/reasoning.md#3-grade-the-rendered-deliverable-not-the-chat-transcript)

Sources: [Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/multimodal-knowledge-agent-benchmark/), [methodology](https://artificialanalysis.ai/articles/google-deepmind-multimodal-knowledge-agent), [public sample](https://huggingface.co/datasets/google/multimodal-knowledge-agent), [Stirrup](https://github.com/ArtificialAnalysis/Stirrup)

### 4. Local personal agents still need an external policy layer

Nod packages a local workspace, browser container, vault, server-side action checks, approvals, and receipts. Its own safety results also show the limit: a smaller model allowed eight unsafe actions in 240 policy decisions.

Implementability score: 0.76

Analysis: [Strategy](../Strategy/2026-11-11/sovereignty.md#1-put-personal-agent-policy-outside-the-prompt)

Sources: [announcement](https://blog.n8n.io/meet-nod/), [repository](https://github.com/n8n-io/nod)

## What to use now

1. Store memory items with source trajectory IDs, outcomes, hashes, and read-only evidence links.
2. Preserve private per-run workspaces across context replacement while keeping hidden verifiers outside them.
3. Grade rendered PDFs, decks, spreadsheets, and images under one pinned harness and rubric.
4. Enforce mutation policy and secret handling outside the model, then retain effect receipts.

## Signal and noise

- Strong signal: WikiTrace's same-insight comparison, external benchmark transfer for file memory, MKA's common harness and rubric-level deliverable checks, and populated read-only repositories.
- Qualified signal: Nod's architecture and vendor-run benchmark, because the safety classifier still depends on model judgment and the results are not independent.
- Architecture-heavy signal: CAMP-II training, because it needs asynchronous on-policy distillation and has no resolved public implementation artifact.
- Noise rejected: secondary launch summaries, same-name repositories, and product claims without first-party methodology.

## Implementability range

Highest: 0.88 for evidence-linked memory with source descent.

Lowest: 0.46 for training models to use persistent file memory through on-policy distillation.
