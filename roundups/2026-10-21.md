# Daily Agent Research Roundup - 2026-10-21

## Thesis

The strongest signal today is that the control plane must reason over workflow state, not isolated context windows or tool calls. Efficient traces need phase-aware evidence retention. Correct agents need executable business rules. Safe persistent agents need delayed-trigger controls and cross-execution authorization.

## Top findings

### 1. TraceLite makes trace reduction an evidence-lifecycle problem

TraceLite preserved SWE-bench Verified resolution while cutting average input tokens 33.05% and API cost 21.30%. The reusable pattern is to keep recent and authoritative evidence in high fidelity, compact redundant history, and expire payloads only after their phase ends.

Implementability score: 0.84

Sources: [paper](https://arxiv.org/abs/2610.28612v1), [repository](https://github.com/xjywhu/TraceLite)

### 2. AgenTest turns implicit business rules into full-trajectory tests

AgenTest mined 551 Given-When-Then specifications and found 89 and 121 violated rules with two models. About 60% of bug-triggering runs were invisible from final state alone. The practical control is a workflow oracle over messages, tool calls, identities, and state changes.

Implementability score: 0.72

Source: [paper](https://arxiv.org/abs/2610.28116v1)

### 3. CarryoverBench shows that memory and schedules are delayed attack channels

Across 101 tasks and five models, planted payloads did not measurably decay over five trigger rounds. Hermes reduced latent-channel attack success but did not eliminate it. Persistent writes and scheduled jobs need origin labels, admission gates, revocation, and fresh authority checks.

Implementability score: 0.78

Sources: [paper](https://arxiv.org/abs/2610.28425v1), [repository](https://github.com/igloomatics/CarryoverBench)

### 4. Per-action authorization cannot enforce every workflow policy

Relational purpose and consent failures can be invisible in each isolated execution. Local Allow, Global Deny proves that some violations require comparison across executions or a willingness to accept false alarms. Workflow history is part of the authorization input.

Implementability score: 0.56

Sources: [paper](https://arxiv.org/abs/2610.27620v1), [empty advertised repository](https://github.com/anmolpandey299/al-synth)

## What is implementable now

1. Shadow a phase-aware trace reducer against a full-trace control.
2. Convert one high-value business workflow into reviewed Given-When-Then rules with trace-level assertions.
3. Add planting and delayed-trigger cases to persistent-memory and scheduled-task security tests.
4. Store purpose, principal, and prior-effect projections for one cross-execution policy fixture.
