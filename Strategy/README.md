## Latest Structured Update: 2026-09-18

### Gate persistent skill changes like code changes

Summary: SkillAA gives skill components stable graph addresses, routes failures to the smallest editable object, and uses affected-case regression checks plus epoch-level commit and rollback. Persistent agent learning needs evidence-bearing mutation control, not blind document rewriting.

## Current implication

A persistent skill is executable policy. Admit and mutate it through versioned objects, localized evidence, regression gates, atomic rollback, and a separate commit decision.
