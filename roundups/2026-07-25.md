# Daily Agent Research Roundup, 2026-07-25

No new Saturday arXiv batch landed. The strongest Friday carry-forwards converge on one practical rule: runtime claims need independent proof at the action, artifact, model, and lifecycle boundaries.

## Top findings

### 1. GuardianAgentBench moves safety below the prompt

Across 580 scenarios, six models, and three production frameworks, the strongest configuration reaches 74.8 percent overall accuracy. Structural LlamaIndex guardrails recover 19.9 percent of failures at a reported 0.5 percent false-positive rate and outperform the tested system-prompt baseline across all six models.

Category: AgenticAI
Implementability: **0.72**
Source:
- https://arxiv.org/abs/2607.20982v1

### 2. RRBench makes local coding agents measurable on governed data work

RRBench evaluates 20 longitudinal data-preparation tasks that create 102 variables. Open-weight 31B to 35B models reach up to 87.9 percent average task completion. The MIT repository includes deterministic table comparison, reference R scripts, tests, and local Ollama or Hugging Face adapters.

Category: AgenticAI
Implementability: **0.84**
Sources:
- https://arxiv.org/abs/2607.21482v1
- https://github.com/UCL-ARC/RRBench

### 3. IRIS audits which model a gateway actually served

IRIS uses text-only random-generation probes to detect whole-stream model substitution and fractional routing dilution. It reports 0.99 AUROC on a Qwen3 ladder and 0.85 mean power for 30 percent dilution on qualified OpenRouter pairs. The artifact ships 147,070 response records, analysis code, manifests, and precomputed results under noncommercial licenses.

Category: Strategy
Implementability: **0.78**
Sources:
- https://arxiv.org/abs/2607.20860v1
- https://github.com/Photen/IRIS-audit

### 4. NemoClaw makes lifecycle authority an explicit runtime contract

NemoClaw v0.0.95 distinguishes NemoClaw-owned from externally supervised OpenShell gateways and prevents recovery or uninstall from mutating the wrong supervisor's listener. It also adds atomic SQLite restore, immutable image checks, exact artifact verification, and executed-run E2E evidence.

Category: Strategy
Implementability: **0.90**
Sources:
- https://docs.nvidia.com/nemoclaw/user-guide/openclaw/release-notes/2026/7/24
- https://github.com/NVIDIA/NemoClaw
