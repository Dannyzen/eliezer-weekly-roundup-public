# Daily Agent Research, 2026-10-30

## Thesis

Agent reliability breaks where observations become authority without an independent gate. Grade the whole tool trajectory, treat runtime feedback as untrusted data, require proof for inter-agent claims, and bound identity plus metadata at the gateway.

## Top findings

### 1. Grade executable prefixes, not only final success

Prefix Executability evaluates every tool-call prefix against schemas, state preconditions, and data dependencies. The study uses two stratified 200-example samples plus all 164 Airline and Retail base tasks in tau3-bench, and finds that terminal-success rankings can diverge from trajectory executability.

Implementability score: 0.86

Source: https://arxiv.org/abs/2610.40444v1

### 2. Treat runtime feedback as an untrusted boundary

CARI embeds malicious instructions in legitimate peer-controlled runtime feedback. Across four languages and five models, it succeeded in 2,845 of 3,000 trials, then transferred to Codex and Claude Code at 61.3% and 58.7% attack success.

Implementability score: 0.76

Source: https://arxiv.org/abs/2610.38799v1

### 3. Carry proof with inter-agent claims

PCM makes claims verifiable from an independently written append-only log. On 926 messages containing 712 lies, it accepted 10 stale-evidence lies, while plain A2A accepted all 712. The MIT repository publishes the specification, vectors, and reference path.

Implementability score: 0.72

Sources: https://arxiv.org/abs/2610.39109v1 and https://github.com/Cygnux-Labs/PCM-protocol

### 4. Bound gateway identity and discovery data

MCP Gateway Registry 1.35.0 adds Keycloak on-behalf-of token exchange with audience checks, caps registrant metadata, makes model-facing metadata opt-in, strips reserved backend headers, and removes unhealthy or unsafe resources from routing.

Implementability score: 0.92

Source: https://github.com/agentic-community/mcp-gateway-registry/releases/tag/1.35.0

## What is implementable now

- score first-error depth, prefix survival, and recovery for tool trajectories;
- quarantine instructions from logs, API errors, test output, and CI feedback;
- authorize effects independently from diagnostic content;
- attach typed claims to source-owned event proofs;
- validate delegated-token audience and project only named metadata fields into model context.
