# Daily Agent Research - 2026-09-03

## Thesis

Declared interfaces are not authority. A skill can keep the user's task and still change the policy. A remote MCP call can keep OAuth and still run on the wrong workload. An eval run can keep the official verifier and still waste the tail of a trajectory whose ending is already obvious.

## Top findings

### 1. Skills can steal the decision without breaking the task

SkillShift preserves declared functionality and valid outputs while steering shopping and dependency choices. PSR rises to 81.33% in shopping and 63.33% in Python dependencies at 100% valid-output rate. Static skill scanners that catch direct injection miss this stealth pair. Audit skills as frozen policies with paired selection fixtures, not as Markdown packages.

Implementable now: frozen candidate-set fixtures, PSR and valid-output metrics, direct-injection positive controls, scanner-plus-behavior release gates.

Implementability score: 0.72

Source: https://arxiv.org/abs/2609.02564v1

### 2. Remote tool OAuth is not execution-time trust

ACLE-MCP treats post-authorization workload substitution, stale appraisal, sender reuse, and undeclared downstreams as first-class failures. A short-lived, sender-constrained capability lease is consumed by an Execution Gate immediately before protected tool logic. In the local simulation, OAuth-only and connect-time attestation block none of six misuse families; full ACLE-MCP blocks the evaluated set at +25.7% p95 latency.

Implementable now: split connect-time auth from invocation admission; bind workload id, freshness, operation, and object bounds; consume the lease in a non-bypassable gate.

Implementability score: 0.48

Source: https://arxiv.org/abs/2609.02690v1

### 3. Stop paying for the rest of an already-decided eval run

EarlyEval trains cheap success and failure predictors over trajectory prefixes and halts when either crosses a calibrated threshold. Across SWE-bench Verified, TerminalBench, and Toolathlon it reports 13% to 26% fewer steps and up to 44.1% / 29.4% fewer input / output tokens, with about 1 to 2 point resolve-rate movement.

Implementable now: prefix-feature logs, leave-one-agent-out predictors, thresholded early stop for eval only, report delta Pass@1 beside tokens saved.

Implementability score: 0.70

Sources:

- https://arxiv.org/abs/2609.02783v1
- https://github.com/inphotoo/earlyeval

### 4. Co-evolve the harness from trajectories, then teach the policy to use it

SafeEvolve turns on-policy traces into bounded prompt and SkillBank edits, then uses harness-use SFT plus GRPO. On Qwen3.5-4B, AgentDojo ASR falls from 2.37% to 0.79% while clean utility rises from 59.79% to 61.86%. Take the reversible harness-admission loop. Do not unsupervised-evolve from live attacks.

Implementable now: named harness components, paired safety/utility gates, JSONL evolution logs. Defer the full RL loop.

Implementability score: 0.50

Sources:

- https://arxiv.org/abs/2609.02786v1
- https://github.com/MaoPopovich/SafeEvolve
