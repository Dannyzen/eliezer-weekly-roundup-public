# Daily Agent Research Roundup: 2026-11-20

## The signal

The agent control plane is moving below prompts and visible tool calls. Capacity depends on resources held during model waits. Memory safety depends on causal effects in the live trajectory. Runtime policy depends on observed system effects. Delegated authority depends on every effect a signed capability can enable.

## Top findings

### 1. Close waiting sessions before buying more capacity

Held While Waiting found that agent environments are reserved for seconds of model wait and often 15 extra idle minutes, while framework work is measured in milliseconds. Explicit client close is the immediate fix. Multiplexing is the platform-level fix.

Sources: https://arxiv.org/abs/2611.26480v1 and https://github.com/MEKHALA/agent-runtime-capacity

Implementability score: 0.82

### 2. Attribute memory failures with offline counterfactual replay

DriftGuard neutralizes one retrieved memory at a time in repeated offline trajectory branches, learns the causal labels, and applies a cheaper online guard. It materially reduced attack success across three memory-poisoning families, but training and benchmark integration are substantial.

Sources: https://arxiv.org/abs/2611.25583v1 and https://anonymous.4open.science/r/DriftGuard-7F0B

Implementability score: 0.63

### 3. Enforce stateful policy over sandbox-observed effects

Tether infers conservative semantic actions from system calls and carries security labels across multiple agent steps. It blocked every in-scope adversarial trajectory in two coding-agent benchmarks, with reported benign false-positive rates from 2.3% to 5.0%.

Source: https://arxiv.org/abs/2611.25599v1

Implementability score: 0.62

### 4. Check the full authority envelope before signing

Authority closure evaluates every transfer sequence enabled by a wallet object, rather than trusting matched display fields or one simulated payment. In the reported corpus, 265 violating objects passed field, expiry, and address checks.

Source: https://arxiv.org/abs/2611.24989v1

Implementability score: 0.68

## What to implement now

- Close every agent session on terminal success, failure, and cancellation paths.
- Add held-environment seconds and idle-retention time to runtime telemetry.
- Preserve pre-action checkpoints and memory lineage so counterfactual replay is possible.
- Dry-run risky actions in disposable sandboxes and authorize observed effects.
- Define grants as reachable effect sets, including retries, periods, and downstream code.

## Signal and limitations

All four papers were first listed on 20 November 2026. Only the runtime-capacity and DriftGuard artifacts were publicly qualified in this scan. Tether has no verified public implementation. The authority-closure paper links upstream protocol repositories, but its checker harness was not public on the verified surfaces. No external code was executed.
