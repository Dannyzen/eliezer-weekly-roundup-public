# Daily Agent Research Roundup - 2026-08-16

## Scope

There is no Sunday arXiv listing. This update uses one August 15 stable SDK release and three non-duplicate Friday carry-forwards submitted August 13 and listed August 14. Blogwatcher was unavailable, so official feeds and release APIs were checked directly. Hugging Face and GitHub Trending were treated as discovery signals only. No external source code was cloned or executed.

## Thesis

Tests must own the evidence path, not only the endpoint.

## Top findings

### 1. OpenAI Agents SDK v0.21.0 makes runtime controls deterministically testable

Public provider-neutral test utilities now cover Agent, Sandbox, Realtime, and Voice workflows. The release also isolates interruption state, recursive approvals, MCP lifecycle snapshots, and sandbox policy state.

Implementability score: 1.00

Source:
- https://github.com/openai/openai-agents-python/releases/tag/v0.21.0

### 2. Labels Are Not Endpoints exposes treatment leakage in agent-security graders

The audit reconstructed 10,200 rows into 180 model-bound requests and corrected 58 historical positive labels after proving the grader used treatment metadata. The evidence repository is populated and Apache-2.0 licensed.

Implementability score: 0.92

Sources:
- https://arxiv.org/abs/2608.12880v1
- https://github.com/rana-m-ahmed/ResearchWork-on-Mcp-Privilege-Aggregation

### 3. Vero evaluates proof and implementation at repository scale

Vero packages 43 multi-module Lean 4 repositories, 743 scored APIs, and 2,705 scored specifications. The strongest agent solved 27 of 43 instances, while machine-checked defect appeals separate benchmark flaws from agent failure.

Implementability score: 0.88

Sources:
- https://arxiv.org/abs/2608.13522v1
- https://github.com/sunblaze-ucb/vero

### 4. ATOBench reconstructs verification after a target observation lies

Across 450 episodes in 225 matched pairs, the benchmark aligns native and transformed runs at first contact, then traces recovery evidence into the final report. The methodology is strong, but the public repository currently contains only a README.

Implementability score: 0.62

Sources:
- https://arxiv.org/abs/2608.12996v1
- https://github.com/daxtar2/ATOBench

## What is implementable now

- Add one provider-independent interruption, approval, MCP, and sandbox fixture using OpenAI Agents SDK v0.21.0.
- Add treatment-invariance checks to security graders.
- Pilot one Vero instance for a repository where proof is worth the setup cost.
- Build safe native-versus-transformed observation tests in a local mock harness, but do not depend on the current ATOBench repository.

## Current implication

The strongest common control is an evidence-bearing test identity: exact input, state, intervention, behavior, verifier, and final claim. Without that chain, a green result is only a label.
