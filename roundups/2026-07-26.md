# Daily Agent Research Roundup, 2026-07-26

As of the 2026-07-26 12:18 UTC publication cutoff, arXiv's newest relevant category heading remained Friday, 2026-07-24. Three non-duplicate carry-forwards sharpen one distinction: issue systems can supply realistic work and useful review evidence, but neither issue text nor agent confidence should authorize side effects.

## Top findings

### 1. WorkBuddy Bench isolates realistic work from grader authority

WorkBuddy Bench packages 260 tasks across Code, Web, Office, and Security. It separates the agent-visible workspace from post-episode grading and requires baseline and oracle admission checks. The artifacts are substantial, but a custom Tencent license says the benchmark is not intended for EU use.

Category: AgenticAI
Implementability: **0.74**
Sources:
- https://arxiv.org/abs/2607.20911v1
- https://github.com/Tencent/workbuddy-bench
- https://huggingface.co/datasets/tencent/workbuddy-bench

### 2. IssueTrojanBench turns malicious issues into a regression gate

Across 4,176 experiments, malicious issue artifacts caused 2,776 exploit executions, or 66.5 percent. Five delivery vectors, PDF, website, source-code comments, issue comments, and issue bodies, each reached 72.2 percent success, while alt text reached 16.7 percent. Prompt boundary markers did not provide meaningful protection. The artifact contains generators, payloads, and evaluation scripts.

Category: Strategy
Implementability: **0.82**
Sources:
- https://arxiv.org/abs/2607.20759v1
- https://doi.org/10.5281/zenodo.19245678

### 3. GitHub adds issue confidence, rationale, and optional approvals

GitHub's public preview can attach confidence and rationale to issue metadata changes and hold suggestions for review. GitHub explicitly says this is not a server-side security boundary. Use it for review routing, then enforce authority with least-privilege tools and server-side policy.

Category: Strategy
Implementability: **0.86**
Sources:
- https://github.blog/changelog/2026-07-23-agent-automation-controls-in-github-issues-in-public-preview/
- https://docs.github.com/copilot/concepts/agents/cloud-agent/about-automations
