# Friday Synthesis - Week Ending 2026-10-23

## Weekly thesis

The week's research converges on one architecture rule: preserve evidence lineage, then grant authority at the moment of effect. Agent failures this week were less about weak prompting than about control surfaces hidden inside compaction, memory, tool processes, harness budgets, and runtime adapters.

A credible agent stack now needs four linked planes:
1. typed evidence that survives retrieval and compaction;
2. deterministic harness records that separate model failure from budget and workflow failure;
3. runtime routing and recovery based on observed state;
4. effect-bound authorization plus replayable receipts.

## Strongest findings

### 1. Context transformations are security and correctness boundaries

Compaction Laundering measured 87% to 100% forged-approval persistence in five flattening harnesses and 0% in four role-typed harnesses. KEEP-Bench found complete required-evidence preservation in only 61.6% to 66.8% of cases for its strongest tested models. Same Simulation, Different Evidence showed agents can compute the right result and answer from a substituted source.

Decision: preserve typed roles, source IDs, authoritative-output identity, and proposition-level evidence before optimizing context length.

Implementability score: 0.91

Sources:
- https://arxiv.org/abs/2610.29869v1
- https://arxiv.org/abs/2610.26827v1
- https://arxiv.org/abs/2610.26836v1

### 2. Benchmark scores need harness attribution

ToolBottleneckBench showed that raising a completion cap sixteenfold removed most of one apparent large-menu penalty. FDE-Gym showed that even fact discovery does not guarantee customer delivery, with the best configuration resolving 14 of 95 tasks.

Decision: freeze budgets, record the first unmet obligation, and grade integration, incidents, and customer outcome separately from component success.

Implementability score: 0.86

Sources:
- https://arxiv.org/abs/2610.21098v1
- https://github.com/zichuanxu/tool-bottleneck-bench
- https://arxiv.org/abs/2610.22350v1
- https://github.com/deeplethe/fde-gym

### 3. Persistent state is delayed execution authority

CarryoverBench found that planted payloads re-fired across later sessions without measurable decay over five rounds. Hermes reduced the attack rate but did not remove it. ProPerMem showed the utility mirror: evidence retrieval, intervention timing, and silence are separate problems.

Decision: persist evidence with origin, purpose, trust, expiry, and revocation. Reauthorize when it resurfaces and again before an effect.

Implementability score: 0.78 for reauthorization controls, 0.45 for reliable proactive-memory timing.

Sources:
- https://arxiv.org/abs/2610.28425v1
- https://github.com/igloomatics/CarryoverBench
- https://arxiv.org/abs/2610.22671v1

### 4. Declared tools need enforcement below the process

A scan of 21,097 MCP servers found 787 filesystem-capability signals among 4,806 triaged non-filesystem servers and dynamically confirmed 150 vulnerable instances under tested policies. Tool schemas describe intended calls, while operating-system authority determines actual reach.

Decision: put catalog selection behind a gateway and filesystem, credential, process, and network authority behind sandbox or host enforcement.

Implementability score: 0.86

Sources:
- https://arxiv.org/abs/2610.22301v1
- https://arxiv.org/abs/2610.23707v1

### 5. Runtime events should support deterministic replay

AgentTriage used one canonical event contract across five runtimes and captured all 159 applicable executions. Its claims bind to event evidence and abstain when mandatory observations are missing. The same terminal-state contract can grade delivery or train repeatability without trusting completion prose.

Decision: normalize ingress, intent, result, effect, and policy-decision events. Preserve native versus synthesized identity and version the adapters.

Implementability score: 0.84

Sources:
- https://arxiv.org/abs/2610.30738v1
- https://github.com/AsnGs/agenttriage-open-source
- https://huggingface.co/blog/microsoft/thinkingbox-training

### 6. Execution routing should remain reversible

Adaptive Skill Granularity treats macro skills, primitive tools, and macro-to-micro recovery as runtime modes. LEASH escalates models during computer-use trajectories. PAUSE adds one planning checkpoint before the first durable code edit.

Decision: route from observed state, verify postconditions, and retain a bounded recovery path before applying learned routing.

Implementability score: 0.78

Sources:
- https://arxiv.org/abs/2610.31461v1
- https://github.com/Jayceon-3/Adaptive-Skill-Agent
- https://arxiv.org/abs/2610.22280v1
- https://arxiv.org/abs/2610.29870v1

## What is implementable now

1. Preserve message roles, source IDs, and authoritative-output identity through compaction.
2. Add direct evidence-recall fixtures alongside token, latency, and task metrics.
3. Record first-failure class, harness budget, terminal state, and customer outcome.
4. Add origin, purpose, expiry, and revocation to persistent writes.
5. Reauthorize scheduled and memory-derived effects against current policy.
6. Run local tool servers under exact roots, dedicated identities, and denied ambient credentials.
7. Normalize source ingress, tool intent, tool result, and terminal effect into replayable events.
8. Add macro postconditions, primitive fallbacks, and one planning gate before the first durable edit.

## Implementability range

Highest: 0.91 for typed provenance and direct evidence-preservation gates. The fixes are local to serializers, context builders, and test fixtures.

Lowest: 0.45 for reliable proactive-memory timing. Trigger windows and cooldowns are implementable, while retrieval, interruption value, silence, and current authority remain jointly unsolved.

## Strategic observation

The provocative question is whether an agent should ever be allowed to convert memory, a summary, or a tool description directly into executable authority. This week's evidence says no. Every transformation should preserve lineage, and every high-impact effect should require a current grant tied to the exact action.
