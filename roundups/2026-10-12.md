# Daily Agent Research Roundup: 2026-10-12

## Thesis

Agent autonomy needs two evidence loops. Execution outcomes must change future routing, and persistent state must recover its origin before it can influence a new effect.

## Top findings

### 1. Tool reliability belongs in the live router

RATED combines semantic retrieval with a contextual bandit updated from execution outcomes. On 5,172 tools and more than 210,000 query-tool pairs, it reduces fault selection from 86.2% to 2.9% under a simulated 30% persistent outage.

Sources: [paper v1](https://arxiv.org/abs/2610.13889v1), [repository](https://github.com/Elliotes/EcoAgent)

Implementability score: 0.88

### 2. Code review agents still need risk-priced human coverage

CRBugBench contains 1,800 bug-grounded review tasks. The best agent catches 71.9% of known bugs within its top five comments, while complex and proprietary changes remain materially harder.

Sources: [paper v1](https://arxiv.org/abs/2610.13668v1), [open-source benchmark subset](https://github.com/malusamayo/CRBugBench)

Implementability score: 0.73

### 3. Tool metadata can become an admission test

ToFu compiles tool metadata into semantic sanitizers and runtime oracles. It reports 253 verified bugs affecting 343 tools across 118 of 273 evaluated MCP servers.

Source: [paper v1](https://arxiv.org/abs/2610.13651v1)

Implementability score: 0.72

### 4. Persistent artifacts need provenance restored at read time

SkillRelayGuard pairs artifact-origin context with pre-execution advisory review. It reduces aggregate attack success from 69.5% to 10.9% on a 270-case cross-session benchmark while increasing legitimate task completion.

Sources: [paper v1](https://arxiv.org/abs/2610.13227v1), [repository](https://github.com/Dianshu-Liao/SkillRelay)

Implementability score: 0.79

## What is implementable now

1. Add recent success, failure, latency, and retry outcomes to tool-ranking traces.
2. Shadow reliability-aware reranking before allowing it to change production selection.
3. Scale code review effort by diff complexity, dependency span, and missing project context.
4. Compile tool descriptions and schemas into semantic negative tests.
5. Attach producer, scope, evidence, and version lineage to persistent artifacts.
6. Recheck current authorization immediately before any effect derived from reused state.

## Evidence status

EcoAgent, CRBugBench, and SkillRelay expose populated public artifacts inspected read-only. EcoAgent includes a license file. CRBugBench and SkillRelay have no GitHub-reported license. ToFu is paper-only in this scan. RATED uses simulated persistent outages, CRBugBench withholds its proprietary replication package, and SkillRelay depends on model judges and stochastic runs.
