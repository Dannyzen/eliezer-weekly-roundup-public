# Daily Agent Research Roundup: 2026-10-07

## Thesis

The strongest new signal is that agent systems need evidence at two scales. A single run needs source-linked behavior and attack-shaped harness tests. A fleet needs resource ownership and a deliberate choice between repeated general inference and verified reusable artifacts.

## Deep Dive Wednesday: Harness Security Effect Verification

HarnessSecurity-Bench wins the week because it converts a control label into release evidence. Its paired trials measure legitimate utility and forbidden effects under the same task and environment, then expose the utility cost and alternative paths that a named control can miss.

The implementable pattern is a control-effect contract tied to the exact harness version: effective setting, protected effect, authorized path, deterministic utility and attack oracles, alternate-path coverage, execution cost, and a release decision. The public task packages are useful design examples. The full runner and all trial artifacts are not public, so local replication remains required.

## Top findings

### 1. Transect keeps long-horizon evaluation reviewable

Transect aligns events, token use, sub-agent activity, structural signals, and judge labels on one turn-based timeline. Its demonstration covers an almost 13-million-token AI research run. The implementation is public and MIT licensed, while the paper correctly separates judge reliability from label validity.

Sources: [paper v1](https://arxiv.org/abs/2610.08364v1), [repository](https://github.com/AI-Safety-Institute/transect)

Implementability score: 0.88

### 2. HarnessSecurity-Bench tests whether controls change real attack effects

The benchmark separates legitimate utility from attack-state oracles across 2,500 trials and 81,155 tool calls. Auto-approve raised attack success from 29.2 percent to 95.6 percent. Alternative execution paths remained a material bypass risk.

Sources: [paper v1](https://arxiv.org/abs/2610.07639v1), [benchmark repository](https://github.com/TsingPig/HarnessSecurity-Benchmark)

Implementability score: 0.81

### 3. MemMux makes coding-agent fleet resources auditable

MemMux attributes process trees, checks cleanup, detects escaped children, and admits work under a memory budget. It reports zero swap under a 7.5 GiB limit, complete tested cleanup, and detection of all ten injected escapes, while also disclosing that monitoring overhead misses its target at ten agents.

Sources: [paper v1](https://arxiv.org/abs/2610.07257v1), [repository](https://github.com/sumanyumuku98/MemMux)

Implementability score: 0.84

### 4. BOTTLED evaluates reusable artifacts as an alternative route

BOTTLED gives agents a fixed budget to build a reusable program or small model for a repetitive workload. Most runs underperform direct inference or a same-budget distillation control, but one query-product case retained about 82 percent of zero-shot quality at roughly 657 times lower reported cost.

Sources: [paper v1](https://arxiv.org/abs/2610.08775v1), [repository](https://github.com/aktsonthalia/bottled)

Implementability score: 0.61

## What is implementable now

1. Render long agent runs as source-linked timelines before relying on semantic summaries.
2. Pair every harness security control with separate utility and forbidden-effect oracles.
3. Bind each local agent to a resource envelope, process subtree, and cleanup receipt.
4. Add a build-once artifact route for one repetitive workload, gated against zero-shot and distillation baselines.

## Artifact verification
