# Daily Roundup: 2026-11-15

## The signal

The best new work moves security and scheduling decisions out of model prose and into deterministic runtime boundaries.

## Top findings

### Request-bound writes beat model-written security artifacts

CapLite derives write policy from tool schemas and user-stated values instead of asking the agent model to write its own policy. No attack succeeded in 13,935 attacked AgentDojo episodes, though answer-only injection remains outside its guarantee.

Source: [CapLite v1](https://arxiv.org/abs/2611.17115v1)

Implementability score: 0.78

### Command-level scheduling can recover idle native GPU capacity

Metal Sandbox preserves per-agent workspaces while scheduling accelerator-sensitive commands across Macs. Four M4 nodes showed 1.68 to 2.05 times command-throughput gains; trace replay reduced mean tool wait by 18.8 percent.

Sources: [paper v1](https://arxiv.org/abs/2611.17294v1), [Metal Sandbox repository](https://github.com/WangHaoZhe/metal-sandbox)

Implementability score: 0.66

### Operational telemetry and sensitive content need separate policy

Google Data Cloud separates content-free metrics and traces from opt-in conversation logs in owner-controlled BigQuery tables. Protected source policies can suppress logging without taking down user execution.

Source: [Google Data Cloud announcement](https://cloud.google.com/blog/products/data-analytics/enterprise-ai-agent-observability-with-bigquery-and-looker/)

Implementability score: 0.90

### Middleware is becoming the authority plane

Microsoft Agent Framework Python 1.26.0 adds application-owned context labeling, task-scoped authority guidance, typed responses, and finite sandbox execution budgets.

Source: [Python 1.26.0 release](https://github.com/microsoft/agent-framework/releases/tag/python-1.26.0)

Implementability score: 0.86

## What to build now

1. Mark authority-bearing tool arguments and require request-bound values before every write.
2. Split operational telemetry from transcript and payload logging.
3. Bind task grants, context labels, typed outputs, timeouts, and cancellation into middleware receipts.
4. Schedule scarce native accelerator commands independently from long-lived agent sessions.
