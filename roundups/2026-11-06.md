# Daily Agent Research Roundup: 2026-11-06

## Thesis

Reliable agents need maintained measurement surfaces. Today's strongest findings all expose a hidden dependency behind a headline score: benchmark repairs and resource policy, MCP failure subtype, memory geometry beyond nearest neighbors, or multimodal evidence at the moment of action.

## Top findings

1. **Benchmarks are versioned software.** Terminal-Bench 2.1 found defects in roughly 30 percent of its predecessor, changed accuracy by more than 10 points, and showed that time budgets can erase apparent harness gaps. [Analysis](../AgenticAI/2026-11-06/reasoning.md#1-treat-benchmarks-as-maintained-software) | [Source](https://arxiv.org/abs/2611.08417v1) | Score: 0.92
2. **MCP evaluation needs structural failure classes.** MCPHallu separates Branch Collapse, Unreachable Goal, Tool Misuse, and Context Forgetting; rankings shift sharply across those subtypes. [Analysis](../AgenticAI/2026-11-06/reasoning.md#2-build-mcp-tests-around-structural-failure-triggers) | [Source](https://arxiv.org/abs/2611.07689v1) | Score: 0.84
3. **Memory compression needs near and far fidelity.** LAQ shows that high neighbor fidelity can coexist with theme-level distortion, then adds a global-rank objective without changing the byte budget or query interface. [Analysis](../AgenticAI/2026-11-06/reasoning.md#3-validate-compressed-memory-at-near-and-far-scales) | [Source](https://arxiv.org/abs/2611.08341v1) | Score: 0.68
4. **Multimodal security must be graded by executed effects.** Forged multimodal content increased attack success even as agents performed more verification, so response-level safety metrics are insufficient. [Strategy](../Strategy/2026-11-06/sovereignty.md#1-test-social-engineering-at-the-action-boundary-across-modalities) | [Source](https://arxiv.org/abs/2611.08281v1) | Score: 0.76

## Implement now

- version benchmark tasks, oracles, infrastructure, and resource budgets together;
- add explicit infeasible-goal and confusing-tool fixtures to MCP gates;
- measure global structure before compressing a memory index;
- bind multimodal red-team outcomes to application logs and trusted-channel verification.

## Signal limits

The LAQ implementation is new and needs independent replication. Multimodal-SEA's advertised GitHub repository did not resolve during this scan. MCPHallu retains a bounded judge component. Terminal-Bench's exact defect rate should not be projected onto every benchmark.
