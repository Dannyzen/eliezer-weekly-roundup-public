# Daily AI and Agent Research Scan: 2026-06-11

Today's strongest pattern is evented control. The serious agent stack is turning memory, tests, skills, and governance into runtime objects that can be replayed, probed, and enforced.

## Top findings

### 1. Project memory should be an event log plus a pre-action judge
- Category: [AgenticAI](../AgenticAI/2026-06-11/reasoning.md#project-memory-should-be-an-event-log-plus-a-pre-action-judge)
- Durable topics: [Memory Systems](../AgenticAI/memory-systems/memory-systems.md), [Event-Sourced Agent Runtime](../AgenticAI/event-sourced-agent-runtime/event-sourced-agent-runtime.md)
- Core sources: https://arxiv.org/abs/2606.12329v1, https://github.com/riponcm/projectmem
- Why it matters: PROJECTMEM treats coding-agent memory as an append-only local event log projected into MCP summaries, then adds a deterministic pre-action gate so the agent does not repeat failed fixes or edit known-fragile files blindly.
- Implementable now: log issues, attempts, fixes, decisions, fragile files, and failed attempts as typed events; project compact summaries; gate proposed actions against remembered failures.
- Implementability score: 0.86

### 2. Deterministic layer slices catch regressions that aggregate agent scores hide
- Category: [AgenticAI](../AgenticAI/2026-06-11/reasoning.md#deterministic-layer-slices-catch-regressions-that-aggregate-agent-scores-hide)
- Durable topic: [Agent Harness Architecture](../AgenticAI/agent-harness-architecture/agent-harness-architecture.md)
- Core source: https://arxiv.org/abs/2606.11686v1
- Why it matters: a no-LLM pure suite can test routing, memory, safety, escalation, decomposition, and envelope logic in CI. The paper's key warning is that aggregate pass rates can hide local scaffold failures.
- Implementable now: create per-layer deterministic fixtures, lock baselines, inject controlled regressions, and report aggregate plus layer-local scores.
- Implementability score: 0.91

### 3. Skill security needs targeted runtime probes, not static inspection
- Category: [AgenticAI](../AgenticAI/2026-06-11/reasoning.md#skill-security-needs-targeted-runtime-probes-not-static-inspection), [Strategy](../Strategy/2026-06-11/sovereignty.md#skill-probes-and-deterministic-layer-tests-are-governance-surfaces)
- Durable topics: [Skills as Control](../AgenticAI/skills-as-control/skills-as-control.md), [Runtime Governance](../Strategy/runtime-governance/runtime-governance.md)
- Core sources: https://arxiv.org/abs/2606.11671v1, https://github.com/snyk/agent-scan
- Why it matters: a malicious skill may only activate with local files, persistent state, or a multi-step tool path. Static review misses that class.
- Implementable now: profile each skill's risk interfaces, run targeted sandbox probes, label behavior from traces, and store the verdict with skill hash and allowed scopes.
- Implementability score: 0.80

### 4. Runtime governance needs a five-plane control plane
- Category: [Strategy](../Strategy/2026-06-11/sovereignty.md#runtime-governance-needs-a-five-plane-control-plane-not-per-tool-approvals)
- Durable topic: [Runtime Governance](../Strategy/runtime-governance/runtime-governance.md)
- Core source: https://arxiv.org/abs/2606.12320v1
- Why it matters: agents can convert individually permitted actions into unauthorized workflows. Governance has to adjudicate intent and enforce across reasoning, network, identity, endpoint, and data planes.
- Implementable now: start with composite principals, stop-anywhere mediation, richer verdicts than allow/deny, and one composed evidence record per material action.
- Implementability score: 0.67

## Signals

- Highest implementability today: layer-isolated evaluation at 0.91. The first version is ordinary CI over deterministic scaffold code.
- Lowest implementability today: five-plane runtime governance at 0.67. The architecture is clear, but production enforcement across identity, network, endpoint, data, and reasoning planes needs real platform work.
- Best immediate build target: an evented harness spine for coding agents: append-only project memory, pre-action failure gates, no-LLM layer tests, and targeted skill probes.
