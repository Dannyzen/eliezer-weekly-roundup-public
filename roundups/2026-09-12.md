# Daily Agent Research Roundup: 2026-09-12

## Thesis

The control plane has two neglected preconditions: prove that a tool can actually join the runtime, and preserve the constraints that govern it after context changes. Evaluation then needs lifecycle and clock evidence that the model cannot rewrite.

## Top findings

### 1. Live MCP registries are much less usable than curated samples

Only 48.8 percent of a seeded 400-server npm/stdio sample initialized. Startup failure, not missing credentials, dominated exclusions. Hard schema conformance was strong among survivors, but safety metadata was often missing. Use `mcp-probe` as a read-only-evaluated candidate for a catalog admission gate.

Primary: https://arxiv.org/abs/2609.10962v1
Artifact: https://github.com/itguruhaseeb/mcp-probe
Implementability: 0.91

### 2. Control loss appears when forgotten constraints meet executable opportunity

Across 1,800 trajectories, restoring the original control boundary cut loss of control to zero. In the compaction ablation, preserving constraints also yielded zero while omitting them yielded 87 percent. Keep binding constraints outside free-form summaries and recheck them at tool admission.

Primary: https://arxiv.org/abs/2609.11024v1
Artifact status: public destination exists, but the paper-specific code was not found in the inspected tree.
Implementability: 0.87

### 3. Freshness benchmarks need an event ledger and dual timestamps

ChurnBench separates stale evidence from reasoning errors by resolving gold state at retrieval and evaluation time. The public repository includes the fabric, ledger, harness, data, provenance, and result files. Sweep TTL against entity churn, not cache age alone.

Primary: https://arxiv.org/abs/2609.11515v1
Artifact: https://github.com/vsingh45/churnbench
Implementability: 0.84

### 4. Reward integrity needs infrastructure-side lifecycle evidence

BenchShield combines static phase-aware taint analysis with runtime evidence over 456 adjudicated trajectories from more than 31,000 public runs. The reported runtime detector reaches 96 percent accuracy, but no paper-specific release was found. Implement the lifecycle and evidence model before depending on its exact detector.

Primary: https://arxiv.org/abs/2609.11028v1
Supporting infrastructure: https://github.com/benchflow-ai/benchflow
Implementability: 0.72
