# Daily Agent Research Roundup: 2026-10-13

## Thesis

Reliable agent operations need two explicit layers: structured evidence inside the run, and privacy-scoped proof around the run. Transcripts and passing tests are weak substitutes for either.

## Top findings

### 1. LongHarness makes evidence state explicit

LongHarness separates source-linked evidence, current conclusions, unresolved gaps, and action history. On OfficeQA Pro, removing persistent state or evidence-conclusion coevolution materially reduces exact match.

Action now: add typed evidence records, active or inactive status, open gaps, and citation validation to one long-running harness.

Implementability score: **0.66**

Source: [LongHarness paper v1](https://arxiv.org/abs/2610.13075v1)

Analysis: [AgenticAI](../AgenticAI/2026-10-13/reasoning.md#longharness-separate-evidence-conclusions-and-unresolved-gaps)

### 2. TestSuiteBench shows passing tests can still be weak

Across 165 applications, frontier agents generate mostly valid tests while remaining below 60% mutation score. The MIT-licensed artifact includes code and three public datasets.

Action now: score test validity and requirement-targeted mutant kills separately.

Implementability score: **0.87**

Sources: [paper v1](https://arxiv.org/abs/2610.13065v1), [repository](https://github.com/eth-sri/testsuitebench), [datasets](https://huggingface.co/collections/eth-sri/testsuitebench)

Analysis: [AgenticAI](../AgenticAI/2026-10-13/reasoning.md#testsuitebench-grade-test-adequacy-against-requirement-targeted-mutants)

### 3. X-AgentRed tests harmful compositions across services

X-AgentRed builds a dependency graph from tool preconditions and effects, then uses execution feedback to discover multi-service harm paths that connector-by-connector testing misses.

Action now: model one high-consequence workflow as an effect graph and preserve every confirmed harmful chain as a regression fixture.

Implementability score: **0.69**

Sources: [paper v1](https://arxiv.org/abs/2610.13886v1), [project page](https://yeonsungjung.github.io/projects/x-agentred/)

Analysis: [Strategy](../Strategy/2026-10-13/sovereignty.md#x-agentred-red-team-the-path-across-services)

### 4. GitHub separates agent identity telemetry from payload capture

Copilot enterprise settings can now export user, OS-account, and host identity without collecting prompts, responses, or tool content. Five content classes remain separately controlled and off by default.

Action now: use identity and outcome receipts as the baseline, then enable narrowly scoped payload classes only for an approved investigation.

Implementability score: **0.93**

Sources: [GitHub release note](https://github.blog/changelog/2026-10-12-client-telemetry-user-attribution-and-configurable-capture), [managed settings](https://docs.github.com/copilot/reference/enterprise-administrators/enterprise-managed-settings), [VS Code OTel guide](https://code.visualstudio.com/docs/agents/guides/monitoring-agents)

Analysis: [Strategy](../Strategy/2026-10-13/sovereignty.md#github-copilot-telemetry-make-identity-and-content-capture-separate-controls)

## What is implementable now

5. Require external-state receipts before any model-authored completion closes work.
