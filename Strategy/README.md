## Latest Structured Update: 2026-09-16

### Make skill admission evidence-bearing, not popularity-bearing

Summary: In a registry that grew from 33,399 to 65,175 listings in 91 days, 85.06 percent of readable skills carried privilege evidence, 77.86 percent had no stars or comments, and three scanners disagreed on 23,702 of 61,990 shared listings. Popularity and scanner consensus cannot grant runtime authority.

Analysis: [daily analysis](2026-09-16/sovereignty.md#make-skill-admission-evidence-bearing-not-popularity-bearing)
Core source: [agent-skill ecosystem study](https://arxiv.org/abs/2609.17274v1)
Tools and methodologies worth exploring now: content-addressed skills, privilege manifests, preserved scanner disagreement, human review receipts, scoped behavioral probes, quarantine and re-review policy
Implementability score: 0.84

### Put cross-principal communication behind a social harness

Summary: Across 600 released scheduling runs, honest agents degraded with scale and concurrency while faulty agents could stall or steer outcomes. Cross-principal work needs identity, ordered communication, task norms, action guardrails, and accountability above basic transport.

Analysis: [daily analysis](2026-09-16/sovereignty.md#put-cross-principal-communication-behind-a-social-harness)
Core sources: [social-harness paper](https://arxiv.org/abs/2609.17527v1), [MIT trace artifact](https://github.com/social-harness/social-harness-paper)
Tools and methodologies worth exploring now: signed message envelopes, principal binding, protocol state machines, expiry, idempotency, bounded claims, replayable violation evidence
Implementability score: 0.68

## Current implication

Registry presence is not admission, and message delivery is not collaboration. Host policy must grant skill authority from evidence, while a shared social harness governs protocol validity without absorbing each principal's private authority.
