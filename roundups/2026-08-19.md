# Deep Dive Wednesday, 2026-08-19

## Winner

TRUSS: skill packages need an admission loop before they expand the runtime.

Durable analysis: [Skill Admission Control](../Strategy/skill-admission-control/skill-admission-control.md#august-19-deep-dive-why-truss-is-the-weeks-control-primitive)

Core source: https://arxiv.org/abs/2608.17588v1

Implementability score: 0.72

## Why it won

This week's other finalists improve important adjacent gates. HarnessRisk scores configuration, extension, persistence, action, and recovery after a capability is already mounted. Authorization Before Context keeps recalled facts inside the audience that produced them. SkillEffect lowers generated tool programs onto bounded implementations. Self-improvement fragility shows that writeback needs multi-run and shuffled-order evidence. DeepSeek Harness makes skills and sandboxes into plugins.

TRUSS sits below all of them. A skill package is a reusable procedure plus executable resources. Loading it expands the action surface. If that load is justified by later task success, every other control plane inherits an uncertified procedure.

The decisive evidence is the gap between artifact inspection and induced behavior. On 84 matched SkillInject pairs, a direct LLM checker reached 19.05% recall and 44.64% precision. Static inspection rose to 94.05% recall and 81.55% precision. Runtime evidence closed the rest and reached 100.00% precision, recall, and F1.

Repair and generation make the same point. On 155 SkillSafetyBench cases, repair cut attack success from 38.71% to 19.35% with GPT-5.5 and from 46.45% to 29.68% with GPT-5.4, with zero attack regression. On 187 SkillGenBench tasks, TRUSS raised effectiveness from 17.11% with no skills to 52.94%, and raised the benchmark Security rate from 50.80% to 100.00%. An intermediate LLM generator captured only part of that gain and left 46 unsafe outcomes.

## What is implementable now

- freeze every candidate skill as a content digest; revisions get a new digest;
- inspect the complete package, including scripts and assets, not only SKILL.md;
- keep a fixed property catalog and convert residual criteria into runtime obligations;
- run a shadow agent through brokered tools in a disposable workspace;
- pair every candidate against an empty-skill control before claiming functional gain;
- release only on safe task completion: attack suppressed and authorized task completed;
- emit an uncertified residual record when the revision budget is exhausted.

A public TRUSS implementation repository was not resolved from the immutable v1 pages. The first build is a local admission loop, not a drop-in framework.

## Weakest point

The paper is a 14-page preprint. The 100.00% detection result is on matched clean/injected pairs, not wild marketplace skills. Residual attack success after repair remains 19.35% to 29.68%. The 100.00% SkillGenBench Security rate is the paper's own property-probe score. Mock services and disabled networking hide live-network side channels unless those observers are added.

That weakness is survivable because the useful contribution is the admission loop, not a claim of solved skill safety. The guardrail is explicit: scenario coverage is part of the certificate.
