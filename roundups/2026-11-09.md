# Daily Agent Research Roundup: 2026-11-09

No new Monday arXiv listing was available at scan time. The strongest fresh signals were public implementation and control-plane releases: exact workflow training, interaction-aware MoE pruning, and API-visible review provenance.

## Top findings

### 1. Exact verifiers can make small tool agents efficient

TaxOps fine-tuned a 3.35B model on scripted oracle trajectories. It reached 93.3 percent exact success on 300 held-out synthetic returns with 0.030 wasted calls per case, then 74.0 percent on a shifted set. The key improvement changed the demonstration policy rather than adding recovery examples.

Implementability score: 0.78

Analysis: [AgenticAI](../AgenticAI/2026-11-09/reasoning.md#1-train-exact-workflows-against-executable-verifiers)

Source: [TaxOps](https://huggingface.co/blog/Manoj2142/taxops-efficient-tool-agent)

### 2. MoE pruning should preserve cooperating experts

HOPE uses pairwise expert interactions instead of independent importance scores. At 50 percent pruning it ranked 1.58 across five methods versus 2.42 for REAP, and a pruned Qwen3.5-35B checkpoint matched the unpruned model on SWE-Bench Pro in the reported run.

Implementability score: 0.58

Analysis: [AgenticAI](../AgenticAI/2026-11-09/reasoning.md#2-preserve-expert-cooperation-when-shrinking-moe-models)

Sources: [implementation walkthrough](https://huggingface.co/blog/amazon/higher-order-pruning-experts), [package](https://github.com/awslabs/HOPE)

### 3. AI review provenance is becoming an API surface

GitHub now exposes code-review policy, attribution, effort, and reported skills, MCP servers, and custom instructions through its APIs. That enables source-bound review receipts and organization-level release policy.

Implementability score: 0.91

Analysis: [Strategy](../Strategy/2026-11-09/sovereignty.md#1-make-review-provenance-a-release-input)

Source: [GitHub changelog](https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates/)
