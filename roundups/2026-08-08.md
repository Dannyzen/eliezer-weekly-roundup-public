No new arXiv listing appears on Saturday. This scan uses the Friday, 2026-08-07 batch and official product updates from the last 48 hours.

## Thesis

Self-improvement is safe only when candidate harnesses, skills, and cryptographic effects cross separately owned evidence gates.

## Top findings

1. HarnessOpt-Bench plus TRAJDEBUG define the missing evaluation loop: optimize immutable harness candidates on hidden tests, then trace the earliest decisive error in failed trajectories. Score: 0.62.
2. GSE treats skill banks as relation graphs and requires replay before promotion. Score: 0.64.
3. PoisonedEvolution shows that three attacker records in a 30-record batch can poison durable skills at high rates. Score: 0.58.
4. Hardware-confined agent signing combines PKCS#11 key isolation with exact-payload commitments and policy receipts. Score: 0.72.

## Implementable now

- store every harness candidate as an immutable commit and evaluate it in an isolated hidden-test environment;
- add causal error labels to failed agent trajectories;
- model skill dependency, co-usage, and conflict, then replay before merge;
- require provenance diversity and separate promotion authority for learned skills;
- keep signing keys non-exportable and bind every operation to an exact payload digest.
