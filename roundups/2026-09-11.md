# Daily Agent Research - 2026-09-11

## Today's thesis: trust depends on independent world evidence

The strongest Friday signal is not a new agent role. It is a better evidence boundary. Harness mutations should generalize across recurring failures, memory curators should probe the current environment before writing, commit gates should read independent state, and A2A delegation should preserve identity and context authority across hops.

## Top findings

1. **Ecdysis trains harness changes from recurring failure structures.** It reports up to 1.84x faster harness training, 18.56% higher reasoning accuracy, and full-data-comparable results from one-quarter of the training data. The public code is populated but unlicensed and unreleased. Score: 0.61. Sources: [paper](https://arxiv.org/abs/2609.11677v1), [repository](https://github.com/cuiyu-ai/Ecdysis).
2. **Environment-probing memory curation checks the world before committing a memory.** On CLBench, pass rate rose from 39% to 73% while task-agent cost fell from $3.38 to $1.68. The pattern needs no model retraining, but the study has no paper-owned public implementation. Score: 0.78. Source: [paper](https://arxiv.org/abs/2609.11060v1).
3. **VP-CONTROL shows that evidence diversity matters more than model diversity.** Cross-model voting over shared evidence approved 62.9% of unsafe proposals, versus 22.9% with an independent source. Its MIT artifact supports offline replay. Score: 0.74. Sources: [paper](https://arxiv.org/abs/2609.10969v1), [artifact](https://doi.org/10.6084/m9.figshare.33511441.v1).
4. **A2ABreak finds specification-compliant delegation failures.** It reports 11 A2A protocol vulnerabilities and ships a populated MIT benchmark and formal-analysis repository. Score: 0.73. Sources: [paper](https://arxiv.org/abs/2609.10871v1), [repository](https://github.com/arlotfi79/A2ABreak).

## What is implementable now

- Give memory curators read-only tools and require probe receipts before write admission.
- Reject verifier independence when actor and verifier evidence share the same lineage.
- Add transactional preconditions and defer states at commit boundaries.
- Bind A2A context, end-principal identity, delegation lineage, and capability attestations across every hop.
- Cluster harness failures by interaction structure and promote changes only after held-out, cross-model checks.

## Implementability range

Highest: 0.78 for environment-probing memory curation.

Lowest: 0.61 for Ecdysis harness evolution, because the available research code has no declared license or release and the training loop remains operationally expensive.
