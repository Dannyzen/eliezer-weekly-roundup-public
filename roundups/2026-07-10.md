# Daily Agent Research Roundup, 2026-07-10

## Today’s thesis

Agent reliability is moving out of prompts and into explicit control surfaces. The strongest work today makes runtime guarantees executable, evaluates the model and framework separately, lets memory abstain from intervention, and confines web content with task-scoped least privilege.

## Top findings

### 1. Executable harness contracts survive model substitution

From Prompts to Contracts moves source boundaries, routing, trace hygiene, output structure, and recommendation rules into code-owned manifests and validators around a replaceable model boundary. The reported contract checks held across 270 runs and three hosted models. Prompt-only enforcement leaked violations; a bolt-on guardrail over-refused; the integrated harness preserved safety and 120/120 utility.

Implementability: **0.90**

Sources:
- https://arxiv.org/abs/2607.08028v1
- https://github.com/hammerbaki/enterprise-llm-agent-harness

Analysis: [AgenticAI, executable harness contracts](../AgenticAI/2026-07-10/reasoning.md#executable-harness-contracts-move-guarantees-out-of-prompts)

### 2. UniClawBench makes framework choice measurable

UniClawBench provides 400 bilingual live-container tasks across five capabilities, with hidden supervisors, user simulation, checkpoints, and cross-framework comparisons. The reusable pattern is to benchmark model, scaffold, task world, and recovery loop as separate variables.

Implementability: **0.85**

Sources:
- https://arxiv.org/abs/2607.08768v1
- https://github.com/HKU-MMLab/UniClawBench

Analysis: [AgenticAI, UniClawBench](../AgenticAI/2026-07-10/reasoning.md#uniclawbench-makes-the-framework-part-of-the-eval-unit)

### 3. Selective memory intervention beats continuous context injection

Remember When It Matters treats memory as an active intervention policy. A sidecar memory agent chooses whether a grounded reminder should enter the action loop or whether it should remain silent. The paper reports gains on Terminal-Bench 2.0 and tau2-Bench, with selective intervention outperforming passive and always-on variants. The advertised repository had no default branch during this scan, so the method is ahead of the public artifact.

Implementability: **0.65**

Sources:
- https://arxiv.org/abs/2607.08716v1
- https://github.com/yifannnwu/proactive-memory-agent

Analysis: [AgenticAI, proactive memory](../AgenticAI/2026-07-10/reasoning.md#proactive-memory-turns-recall-into-a-selective-intervention-policy)

### 4. Prismata applies least privilege to content and capability

Prismata treats cross-site prompt injection as a confinement failure. It derives task-specific trust labels, limits what the planner sees, and gates what the agent can do. The paper reports attack success dropping from 85.5% to 0.7% in its main attack settings while preserving benign utility. No public implementation repository was identified, so the immediate value is architectural.

Implementability: **0.55**

Source:
- https://arxiv.org/abs/2607.08147v1

Analysis: [Strategy, Prismata](../Strategy/2026-07-10/sovereignty.md#prismata-confines-both-what-a-web-agent-sees-and-what-it-can-do)
