# Daily AI and Agent Research - 2026-08-22

## Thesis

The control plane should spend effort where measurement says it changes the decision.

## Top findings

### 1. Agent-facing files are the real documentation surface

A study of 557 coding-agent sessions and 33,097 agentic pull requests found that agent instructions and working notes made up 60.5 percent of documentation interactions. Classical technical documentation was 10.6 percent and API references 1.3 percent.

Action now: version, scope, test, and trace `AGENTS.md`, plans, working notes, and verification logs as runtime inputs.

Implementability score: 0.90

Source: https://arxiv.org/abs/2608.20195v1

### 2. Self-improvement needs a measured null

Phantom Gains found seven measurement failures in transition-level self-training audits. An unchanged model appeared to learn and regress under common evaluation practices. The released artifact provides a concrete baseline-replication pattern.

Action now: run frozen controls through the identical pipeline and gate per-task gains against a measured noise floor.

Implementability score: 0.86

Sources:
- https://arxiv.org/abs/2608.20290v1
- https://github.com/chengxuphd/phantom-gains

### 3. Better routing evidence should be purchased selectively

Pandora's Router prices the value of a better routing estimate against the cost of obtaining it. The practical lesson is to meter retrieval, partial reasoning, and tests as inspection actions rather than treating router confidence as free.

Action now: shadow a deterministic value-of-information threshold using existing route traces and realized outcomes.

Implementability score: 0.62

Source: https://arxiv.org/abs/2608.20316v1

### 4. Runtime invariants are landing in framework releases

Microsoft Agent Framework Python 1.15.0 adds recovery and steering support while tightening approval persistence, trace continuity, deserialization, MCP tool identity, duplicate messages, and telemetry forwarding.

Action now: add conformance fixtures for these invariants before upgrading an active runtime.

Implementability score: 0.92

Source: https://github.com/microsoft/agent-framework/releases/tag/python-1.15.0
