# Daily Agent Research Roundup - 2026-08-31

## Thesis

Probabilistic loop guidance should optimize progress. Deterministic controls should own authority, recovery, and acceptance. Evaluate controllers separately from workers, score evidence-bearing progress below terminal success, enforce tool grants outside the model, and admit self-modifications only with verified recovery witnesses.

## Top findings

### 1. Evaluate the controller separately from the worker

LoopArena fixes the coding Worker and evaluates a separate runtime Controller through typed Loop Contracts. Its 90-question cheap setting, 27 condensed tasks, and 27 full tasks expose a major gap: the best full-task Strict Success Rate is 24.69 percent, while condensed evaluation reduces estimated inference cost by 64.4 percent and preserves controller ordering.

Implementable now: add a controller role, typed next-step contracts, paired task states, and a small full-task anchor above cheap controller fixtures.

Implementability score: 0.86

Sources: [paper](https://arxiv.org/abs/2608.28281v1), [repository](https://github.com/AMAP-ML/LoopArena)

### 2. Score trajectory evidence, not only terminal success

GCPC uses reusable human rules, LLM-instantiated task checklists, evidence-only judging, abstention, and a scripted official-verifier override. Across 4,455 trajectories it improves PASS/FAIL discrimination from AUC 0.619 to 0.689 and exposes large hidden movement among matched runs whose binary result does not change.

Implementable now: add evidence-cited partial credit to skill and harness evaluations while preserving terminal success as the hard contract gate.

Implementability score: 0.79

Source: [paper](https://arxiv.org/abs/2608.27487v1)

### 3. Put tool authority behind an external reference monitor

Recognition Without Enforcement shows that models can identify forged authority yet still emit the conflicting tool call. Across 14,294 spoofed trials the average execution rate is low, but failures concentrate in reproducible prompt-model cells and shift across deployment windows. The external monitor rejects all tested forged, tampered, replayed, and unsigned requests.

Implementable now: authenticate authority-bearing requests, capability-gate exact tool arguments and sequence, and add replay, tamper, unsigned, and clock-skew fixtures outside the model.

Implementability score: 0.72

Source: [paper](https://arxiv.org/abs/2608.28502v1)

### 4. Admit self-modification only with a verified recovery witness

EvoUndo finds 197 capability-improving but unrecoverable mutations among 600 one-shot tasks. Exact state grounding and a richer recovery calculus recover most oracle-defined failures, while iterative repair under the original representation recovers none.

Implementable now: require exact affected-state identities, inverse semantics, counterfactual recovery tests, and independently verified recovery witnesses before admitting harness mutations.

Implementability score: 0.63

Source: [paper](https://arxiv.org/abs/2608.28363v1)

## What did not make the cut

- Logos demonstrates cross-process fault isolation and 80 resumable sessions, but exposes no public implementation artifact and adds less immediate control value than LoopArena's released benchmark.
- Offline-Verifiable Accountability provides a strong evidence-bundle pattern over 300 workflows and 1,200 valid bundles, but its offline dispute-review use case is narrower than the external reference-monitor result.
- DoCtOR improves multi-agent outcomes through decisive-error attribution, but targeted reflection overlaps existing failure-attribution coverage and exposes no public implementation artifact.
- Hugging Face and GitHub surfaced LoopArena as the strongest current implementation signal. No separate official product release displaced the paper-led findings.
