# Daily Agent Research Roundup, 2026-07-23

Today’s strongest signal is symmetric verification: test capability packages before agents load them, test native artifacts after agents produce them, and prevent untrusted context from becoming privileged authority between those points.

## Top findings

### 1. OpenSkillRisk turns skill safety into an end-to-end effect test

The benchmark contains 263 real marketplace risky skills, split between 139 unconditionally malicious and 124 context-dependent cases. Across three CLI harnesses and thirteen models, even the safest configurations still perform unsafe actions in about 17 percent of cases.

The public MIT artifact and dataset make a local admission suite practical. The key metric is the first unsafe attempted effect, not whether the model later explains the risk.

Category: AgenticAI
Implementability: **0.82**
Sources:
- https://arxiv.org/abs/2607.20121v1
- https://github.com/Miaow-Lab/OpenSkillRisk
- https://huggingface.co/datasets/Miaow-Lab/OpenSkillRisk

### 2. DocOps makes document-agent output deterministically verifiable

DocOps ships 210 executable tasks across Word, Excel, PowerPoint, and PDF, with native-state tests for formulas, styles, metadata, bookmarks, and structure. The best reported configuration passes 0.671 overall, while long-range workflows degrade sharply.

The public Apache-2.0 benchmark is the highest-readiness finding today. Start with ten representative tasks and bind verifier output to the exact artifact digest.

Category: AgenticAI
Implementability: **0.88**
Sources:
- https://arxiv.org/abs/2607.19865v1
- https://github.com/icip-cas/DocOps
- https://docopsbench.github.io

### 3. Twin Agent treats untrusted context as bounded residual information

Twin Agent separates an Explore Agent from a privileged Safe Agent and passes only compact hints. On the reported SWE-bench-injected slice, utility is 62.5 percent with 0.0 percent attack success, versus 61.2 and 97.0 percent for the default agent.

The pattern is useful, not proven. Compact hints can still carry attacks, and no exact public repository URL resolved during this scan. Use real principal separation, typed hints, and effect gates.

Category: Strategy
Implementability: **0.66**
Source:
- https://arxiv.org/abs/2607.19595v1

### 4. Channel safety needs attribution, not only safe outcomes

ChannelGuard shows that an apparently safe pipeline can rely on opaque provider filtering. Its application-owned tool-output gate blocks 30 of 30 tool-poisoning cases across three backends, but white-box adaptive paraphrase reaches about 0.667 attack success against the embedding gates.

The immediate pattern is to instrument every handoff and replay the same attacks across providers. The proposed artifact link is unresolved, so this is not try-now software.

Category: Strategy
Implementability: **0.58**
Source:
- https://arxiv.org/abs/2607.19430v1

4. Add OpenTelemetry spans and provider-counterfactual replay at every inter-agent channel.
