# Daily Roundup, 2026-07-04

Today's scan found four strong items. The common thread is preflight governance: recover the agent graph before execution, predict expensive evals cheaply, evaluate runtime permission designs, and detonate untrusted skills before they inherit tool authority.

## Top findings

### 1. Agent program static analysis becomes the new preflight gate

AgentFlow and IAL-Scan show that agent programs need their own static-analysis layer. AgentFlow builds Agent Dependency Graphs over agents, prompts, models, capabilities, memory, and policies. IAL-Scan detects infinite agentic loops by checking whether feedback paths can repeatedly reach costly or state-growing operations without effective bounds.

### 2. Proxy benchmarks can make agent routing cheap enough to run continuously

PACE and PACE-Bench provide a practical path for cheap model-selection and routing evidence. The paper reports under 4% mean absolute error, Spearman above 0.80, and around 85% pairwise ranking accuracy for predicting agentic benchmark performance at much less than 1% of full eval cost.

### 3. Runtime permission UX is a security primitive, not an approval popup

Janus turns permission management into a testable design space. It includes a modular agentic system, a harness, scenario definitions, and multiple permission assistants. The important lesson is that user involvement should be measured and context-sensitive, not reduced to endless approval dialogs.

### 4. Skill malware defeats static scanners, so skill admission needs detonation

Cloak and Detonate shows that static skill scanners can be bypassed by payload-preserving transformations. SkillDetonate points to the right admission model: run untrusted skills in a sandbox and inspect behavior through OS-boundary information-flow evidence before granting real authority.

## What is implementable now

- Add a framework-specific static extractor for agent definitions, tools, memory, handoffs, policies, and termination controls.
- Emit an Agent BOM and loop-bound coverage report as CI artifacts.
- Run PACE-style proxy evals before router or model-selection changes.
- Treat permission prompts as typed grant requests, not generic chat approvals.
- Add a skill detonation lane with fake secrets, marker files, egress traps, and sandbox traces.

## Score range

Highest score today: 0.86 for PACE, because code and dataset artifacts are public and the first use case can be offline.

Lowest score today: 0.62 for production-grade skill detonation governance, because behavior coverage is harder than static scanning and must account for trigger-dependent payloads.

## Working conclusion

The daily thesis is preflight before autonomy. If the platform cannot explain the agent graph, predict routing quality, mediate permission, and test skills behaviorally, it is granting authority on faith.
