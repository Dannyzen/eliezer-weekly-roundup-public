# Daily Roundup: 2026-11-17

## The signal

Models should judge bounded choices and propose changes. Deterministic infrastructure should assemble actions, verify effects, promote improvements, and govern which extensions are eligible.

## Top findings

### Compile tool calls instead of generating them

System 1 Agents compiles schemas and request values into finite choices, then uses a local decision model only to score those choices. On 1,952 requests it reached 97.0 percent tool-selection accuracy, and none of 10,888 calls contained ungrounded content under the study's test.

Sources: [paper v1](https://arxiv.org/abs/2611.21053v1), [Apache-2.0 repository](https://github.com/eltzanis/SystemOneAgents)

Implementability score: 0.84

### Put deterministic acceptance around agent search

An agent-guided cvc5 tuning campaign recorded 4,545 bounded proposals while a fixed harness measured complete groups, validated models, and selected per-division incumbents. Held-out identity tests showed geometric-mean gains of 7.8 percent for 2026 and 6.8 percent for 2025.

Source: [paper v1](https://arxiv.org/abs/2611.20484v1)

Implementability score: 0.68

### Rank memory by usefulness, then control the scoring surface

Jetriever replaces similarity-first retrieval with query-memory utility scores. It ranked the gold exchange first on 84.8 percent of 125 indirect-query tasks, while BM25 reached 1.6 percent and MiniLM 0 percent in the matched setup. Full-pool scoring is the scaling constraint.

Sources: [paper v1](https://arxiv.org/abs/2611.21478v1), [MIT repository](https://github.com/imlrz/Jetriever)

Implementability score: 0.60

### Govern extension provenance and runtime authority separately

GitHub now lets enterprises require skills, agents, hooks, MCP servers, and executable extensions to come from plugins or managed settings. Plugin provenance still needs marketplace restrictions, and the policy-capable Copilot harness still needs explicit permissions and sandbox configuration.

Sources: [customization controls](https://github.blog/changelog/2026-11-16-control-where-github-copilot-customizations-come-from/), [harness transition](https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027/)

Implementability score: 0.88

## What to build now

1. Compile high-impact tool calls from request-bound values and schema choices.
2. Put a deterministic verifier and promotion gate around every agent-driven optimization loop.
3. Add utility reranking after a cheap candidate stage for memories with weak lexical overlap.
4. Separate extension-source policy from runtime permissions and sandbox policy.
