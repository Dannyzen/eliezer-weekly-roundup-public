# Daily Agent Research: 2026-10-03

## Thesis

Reliable agent control depends on choosing the correct unit. Authorization must see the object composed by the team. Evaluation must select baselines without test-label privilege. Long-running execution must persist enough state to recover without replaying effects. Review should be callable from the workflow rather than left as a UI convention.

## Top findings

### 1. FlowReview governs composed information flows

Local review permitted 413 of 480 denied commits. Review of combined artifacts permitted 0 of 480 while both arms retained 459 of 480 authorized objects. Use canonical object identity, trusted permission ranking, runtime assembly, and a deterministic commit gate.

Sources: [paper](https://arxiv.org/abs/2610.00371v1), [repository](https://github.com/yunbeizhang/FlowReview)

Implementability score: 0.78

### 2. Safety routers need honest fixed-model baselines

A comparator selected on test labels had only 0.003 to 0.030 harm cost under random splits and 0.045 to 0.113 under held-out categories. Select the comparator inside each fold and report both honest and in-sample conventions.

Source: [False Floors](https://arxiv.org/abs/2610.01535v1)

Implementability score: 0.72

### 3. Copilot code review is now API-triggerable

GitHub now supports REST and GraphQL requests for Copilot review with effort selected per request. This can become a typed stage after repository-native checks and before deterministic merge gates.

Source: [GitHub changelog](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level/)

Implementability score: 0.94

### 4. Cloudflare PiHarness makes interrupted turns durable

PiHarness connects Pi Durable with the Agents SDK lifecycle so long-running work can survive restarts, crashes, network issues, and mid-turn interruption. Recovery still needs replay-safety labels and interruption fixtures.

Source: [Cloudflare changelog](https://developers.cloudflare.com/changelog/post/2026-10-02-pi-harness/)

Implementability score: 0.86
