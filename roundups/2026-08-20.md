# Daily Research Roundup - 2026-08-20

## Thesis

Agent reliability now depends on executable middle-layer verifiers and composable pre-action gates. Final-answer grading is too late, and individually correct gates become unsound when one gate changes what another gate already approved.

## Top findings

### 1. ComponentBench makes the GUI failure layer measurable

ComponentBench provides 97 component families and 2,910 deterministic tasks. The same model moved by more than 30 points when only the observation and action surface changed. This is the missing diagnostic layer between atomic grounding and long workflows.

Analysis: [AgenticAI](../AgenticAI/2026-08-20/reasoning.md#componentbench-turns-gui-reliability-into-component-contracts)

Implementability score: 0.92

Sources:
- https://arxiv.org/abs/2608.18307v1
- https://github.com/TianchenGuan/ComponentBench
- https://huggingface.co/datasets/TianchenGuan/ComponentBench

### 2. SemaPLC makes live runtime evidence the completion rule

SemaPLC requires specification, compilation, and live-runtime checks before an agent task completes. Its dynamic score reached 52.2 against baseline scores from 22.4 to 31.4 on project-context PLC tasks.

Analysis: [AgenticAI](../AgenticAI/2026-08-20/reasoning.md#semaplc-makes-runtime-verification-the-completion-condition)

Implementability score: 0.78

Sources:
- https://arxiv.org/abs/2608.18565v1
- https://github.com/midea-ai/SemaPLC

### 3. Remediation requires re-gating

One Gate Is Not Enough shows why a sequence of authority, budget, and evidence decisions can be unsound. If one gate transforms the action or evidence, prior dependent verdicts must be invalidated and recomputed.

Analysis: [Strategy](../Strategy/2026-08-20/sovereignty.md#remediation-must-invalidate-prior-gate-decisions)

Implementability score: 0.64

Source:
- https://arxiv.org/abs/2608.18360v1

### 4. Least privilege is learnable, but it is not enforcement

A tuned 4B model raised safe success from 64.36% to 98.48% and reduced excess-authority success from 4.56% to 0.79%. Use that behavior to choose safer defaults. Keep a deterministic broker as the final ceiling.

Analysis: [Strategy](../Strategy/2026-08-20/sovereignty.md#learned-least-privilege-is-a-routing-prior-not-authority)

Implementability score: 0.46

Source:
- https://arxiv.org/abs/2608.18351v1

## Implementable now

1. Add deterministic component fixtures between atomic and end-to-end GUI tests.
2. Make runtime verification, not agent narration, the completion condition for high-impact generated code.
3. Invalidate dependent gate verdicts whenever remediation changes action, evidence, context, or policy state.
4. Let models propose privilege profiles, then intersect them with deterministic user and policy ceilings.
