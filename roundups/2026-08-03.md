# Daily Agent Research Roundup - 2026-08-03

## Verdict

The strongest Monday signal is that agent reliability depends on evidence being typed before action, preserved through repair, and tested for what it actually proves. Memory adds the same requirement across time: summaries may retain information, but they may not manufacture authority.

## Top findings

### 1. BSG-VA measures whether passing tests discriminate the bug

Across 3,730 validation events from 643 rollouts on 110 tasks, 46.0 percent of positive comparable events did not distinguish the assigned bug. Replay on buggy, candidate, and gold states turns green tests into classified evidence.

Action now: bind validation commands to exact code states and block closure when no positive check discriminates the bug.

Implementability score: **0.86**

Sources:
- https://arxiv.org/abs/2607.28871v1
- https://doi.org/10.5281/zenodo.21642576

### 2. ECLoop gates edits on observed repository evidence

Across all 500 SWE-bench Verified tasks, two models, and two scaffolds, ECLoop reports Pass@1 gains of 4.8 to 11.8 percentage points and token reductions up to 12.1 percent by postponing unsupported mutations.

Action now: compile action-specific evidence requirements and place a deterministic gate in front of file writes and patch submission.

Implementability score: **0.78**

Source:
- https://arxiv.org/abs/2607.28815v1

### 3. AuditCoder makes repair responsibility-bounded

Stable task-graph identities bind commitments, code ownership, provenance, checks, and intervention history. Trace coverage is high, but only 26 of 60 audited failures yielded a supported repair boundary, which makes abstention a necessary feature.

Action now: freeze unaffected code and permit repair only for evidence-supported nodes or branches.

Implementability score: **0.72**

Sources:
- https://arxiv.org/abs/2607.29529v1
- https://github.com/puppet0x3f/AuditCoder

### 4. Memory provenance must survive consolidation

The PPMF paper shows how an external observation can be rewritten as apparent user history. Vulnerable summaries reach attack success rates up to 1.000; a platform-owned provenance and risk gate blocks all evaluated unauthorized high-risk actions under intact metadata.

Action now: keep source authority outside model-authored summaries and bind it to exact tool arguments at execution time.

Implementability score: **0.67**

Source:
- https://arxiv.org/abs/2607.29167v1

## What is implementable now

4. Keep memory provenance in platform metadata and recheck it at tool execution.
