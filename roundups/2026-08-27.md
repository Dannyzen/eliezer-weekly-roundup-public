# Daily AI and Agent Research - 2026-08-27

## Thesis

Agent control is becoming trajectory-sensitive and effect-local. The runtime should route models from measured progress, route skills from verified dependencies, admit actions through typed events, and release only the minimum necessary data to each tool.

## Top findings

### 1. Minimize data at the tool boundary

ToolMinimize reports unnecessary privacy-sensitive disclosure in 81 to 88 percent of default tool calls. A pre-execution argument rewriter reduced privacy cost by 81.2 to 92.0 percent across 307 live calls while preserving argument-level task validity. This is today's highest-implementability pattern because it can sit in existing MCP or tool middleware.

Implementability score: 0.82

Source:
- [ToolMinimize paper](https://arxiv.org/abs/2608.24957v1)

### 2. Make the runtime, not the prompt, own external effects

Metis normalizes provider streams into typed events, checks permission before effect, orders interfering calls, closes terminal results, and narrows child tool registries. Its evidence is bounded and the implementation artifact is not public, but the decomposition of policy, harness, and runtime is directly useful.

Implementability score: 0.74

Source:
- [Metis paper](https://arxiv.org/abs/2608.25322v1)

### 3. Route models from trajectory progress

ProgRouter selects models at each workflow step from progress gain, remaining difficulty, deadline, and cost. It reports strong quality-cost results across code, math, and retrieval-augmented question answering, including a 93.0 percent HumanEval Plus pass rate inside a 4,800 J budget.

Implementability score: 0.61

Source:
- [ProgRouter paper](https://arxiv.org/abs/2608.25992v1)

### 4. Admit skill edges through counterfactual evidence

CaSKG calibrates directed skill relations before graph retrieval. It improves ScienceWorld's six-model macro-average from 72.62 to 80.50 and ALFWorld success from 80.01 percent to 86.79 percent relative to Graph-of-Skills. The linked repository currently contains only a release placeholder, so the method is not yet implementation-ready.

Implementability score: 0.58

Sources:
- [CaSKG paper](https://arxiv.org/abs/2608.25500v1)
- [CaSKG placeholder repository](https://github.com/ZhiyuanLi218/Caskg)

## What is implementable now

- Add JSON Schema metadata for minimum necessary fields and precision, then rewrite tool arguments before dispatch.
- Normalize one provider's tool stream into typed proposed, admitted, executing, terminal, cancelled, and denied events.
- Add deterministic model escalation when the workflow ledger shows a stall, regression, or shrinking budget.
- Record skill prerequisites and completion checks as directed edges, then require evidence before those edges affect retrieval.
