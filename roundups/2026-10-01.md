# Daily Agent Research Roundup: 2026-10-01

Today's strongest pattern is inspectable adaptation. Harnesses, memory selectors, workflow routers, and action verifiers are becoming active control layers. They need versioned evidence and external acceptance gates.

## Top findings

### 1. SelfSearch uses modification episodes as harness-evolution data

SelfSearch improved population-mean success in all six model-benchmark settings without using downstream rewards during search. Individual gains reached 11.2 points on Terminal-Bench 2.1. The implementable pattern is to keep self-improvement episode records while keeping evaluation, selection, resource limits, and promotion outside the editable agent.

Primary category: AgenticAI
Implementability score: 0.62
Source: https://arxiv.org/abs/2609.37968v2

### 2. RECAP makes context compaction a persistent graph query

RECAP retains attention-derived importance and dependencies, then combines them with current-request relevance to select original message blocks. The paper reports about 95% lower estimated compaction and cold-restoration latency than summarization, plus lower historical context and stronger code-task accuracy. The linked code repository is empty, so this is a prototype pattern rather than ready software.

Primary category: AgenticAI
Implementability score: 0.56
Sources:
- https://arxiv.org/abs/2609.40118v1
- https://github.com/UCSB-NLP-Chang/ReCAP

### 3. HydraFusion expands workflow routing into VS Code and the Copilot app

HydraFusion chooses single, cascade, or cross-family critique workflows and exposes progress for each leg. The September 30 expansion is useful because it puts complete workflow routing in ordinary coding surfaces. It remains a closed research preview with no SLA.

Primary category: AgenticAI
Implementability score: 0.84
Sources:
- https://github.blog/changelog/2026-09-30-hydrafusion-in-vs-code-and-the-github-copilot-app/
- https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/
- https://docs.github.com/en/early-access/copilot/hydrafusion

### 4. Causal verifier certificates fail when the committed graph is wrong

A one-edge omission drove false executions from 0% to 15.3%; one direction reversal produced 48.9% false executions. Randomized attestation recovered measured safety, while auditing wrongful inaction required much more experimental budget.

Primary category: Strategy
Implementability score: 0.64
Source: https://arxiv.org/abs/2609.40027v1

## Watchlist, not promoted

Hugging Face surfaced the Agent Error Dataset, which reports 50,228 error-diagnosis pairs and strong matched-replay gains. The paper says code and data will be released, but no accessible public artifact was verified. Keep it on the watchlist until the dataset and license resolve.

Source: https://arxiv.org/abs/2609.40111v1

## Current thesis

Keep adaptation inspectable. The editable agent may propose new harnesses, memory policies, or routes. Raw evidence, hard policy, benchmark tasks, world-model checks, and promotion authority must stay outside that editable surface.
