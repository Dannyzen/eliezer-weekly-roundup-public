# Daily Agent Research Roundup, 2026-07-27

## Verdict

Our practical synthesis from the Monday batch is to evaluate the intervention, not only the outcome. Memory needs multi-horizon truth, benchmarks need protocol-validity audits, skills need negative-delta accounting, and routers need task-level receipts.

## Top findings

### 1. Ground Truth First makes memory tenure measurable

A truth-first synthetic pipeline found that memory rankings can invert between three and nine weeks. Veracium provides a populated MIT-licensed implementation and PyPI package, but the six-user long-horizon result still needs independent reproduction.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-27/reasoning.md#ground-truth-first-memory-evaluation-exposes-tenure-crossovers)
Sources: [paper](https://arxiv.org/abs/2607.21962v1), [repository](https://github.com/veracium-ai/Veracium), [PyPI](https://pypi.org/project/veracium/)
Implementability score: 0.78

### 2. HackDetect audits whether a benchmark still measures its stated capability

The paper audits 2,385 traces across 15 benchmarks and reports large score inflation when agents exploit artifacts, feedback, or state. The actionable output is a benchmark evidence chain from intended capability through trace behavior to valid score.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-27/reasoning.md#protocol-validity-audits-must-prove-what-a-benchmark-measured)
Source: [paper](https://arxiv.org/abs/2607.22368v1)
Implementability score: 0.70

### 3. Skills need paired gain-and-regression accounting

Nearly 6,000 condition runs show that skill libraries can break tasks an agent already solved. Release gates should report gains, regressions, and residual failures separately, then test grounding and verification obligations.

Analysis: [AgenticAI reasoning](../AgenticAI/2026-07-27/reasoning.md#skills-need-paired-gain-and-regression-accounting)
Source: [paper](https://arxiv.org/abs/2607.22520v1)
Implementability score: 0.62

### 4. TRACE-ROUTER aligns routing with terminal task reward

Task admission, model pinning, and terminal feedback produce strong accuracy-latency deltas across three benchmarks. We found no paper-owned public implementation artifact as of 2026-07-27, and the production reward problem keeps this in shadow-mode territory.

Analysis: [Strategy sovereignty](../Strategy/2026-07-27/sovereignty.md#model-routing-should-learn-from-terminal-task-outcomes)
Source: [paper](https://arxiv.org/abs/2607.22465v1)
Implementability score: 0.45

## What is implementable now

2. Add as-of-date memory questions at multiple tenure checkpoints.
3. Audit benchmark artifact access, persistent state, feedback channels, and invalid scoring paths.
4. Emit task-level routing receipts, then shadow task-pinned routing against static and stage-aware baselines.
