# Deep Dive Wednesday, 2026-08-12

## Winner

MAP-Graph: provenance-aware shared memory for multi-agent workflows.

Durable analysis: [Memory Authority Control Plane](../Strategy/memory-authority-control-plane/memory-authority-control-plane.md#august-12-deep-dive-memory-needs-two-gates-not-one-smarter-retriever)

Core source: https://arxiv.org/abs/2608.10509v1

Implementability score: 0.74

## Why it won

This week's other finalists improve self-evolving harnesses, realized-state safety measurement, and prompt-injection detector evaluation. MAP-Graph sits below all three. It governs the transition from retained evidence to effect.

Its decisive result is an ablation: removing the permission filter improved task success and exact accuracy, but unauthorized access rose from zero to every observed attempt. Aggregate utility can reward a system for violating the boundary it was supposed to enforce.

The architecture therefore needs two gates:

1. Retrieval gate: may this principal use this memory and its ancestry?
2. Action gate: may this evidence authorize this exact effect?

## What is implementable now

- stable IDs for principals, source events, memories, derived claims, actions, and decisions;
- permission filtering before relevance ranking;
- inherited restrictions through summaries and handoffs;
- revocation propagation to descendants;
- typed `Allow`, `Block`, `Redact`, `Reverify`, and `AskUser` decisions;
- receipts joining evidence lineage, effective policy, proposed effect, and outcome;
- deterministic fixtures for private, revoked, poisoned, stale, clean, and high-risk cases.

A relational prototype with recursive ancestry queries is enough to start. A graph database is optional until measured query cost proves the need.

## Weakest point

The benchmark is synthetic and templated, actions are simulated, and most results are single runs. MAP-Graph still made 41 impermissible Allow decisions in 450 high-risk action cases. No exact public implementation repository was resolved from the immutable v1 paper.

That weakness is survivable because the paper's useful contribution is the gate separation, not a claim of solved safety. The guardrail is explicit: provenance eligibility is deterministic policy, while high-risk effect authorization remains a separate, stricter control.
