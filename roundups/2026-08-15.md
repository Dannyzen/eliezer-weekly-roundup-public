# Daily Agent Research Roundup - 2026-08-15

## Scope

No Saturday arXiv batch was listed. This update selects four non-duplicate Friday carry-forwards submitted August 12 and 13. Primary papers, PDFs, and linked artifact metadata were verified read-only. No external code was executed.

## Thesis

Action boundaries fail when evidence is mistaken for authority.

## Top findings

### 1. SteerBench-Work: gates must price false holds

Across 30 model conditions, agents wrongly held authorized work on 28.1% of opportunities and wrongly allowed unsafe work on 1.0%. The tagged benchmark release is ready for local action-boundary fixtures.

Implementability score: 0.90

Sources:
- https://arxiv.org/abs/2608.12654v1
- https://github.com/AgentDock/steerbench-work

### 2. Agent Behavioral Contracts II: redundancy needs joint-failure evidence

Two same-model agents co-failed on 90.0% of missions where either failed in a preregistered 18,000-mission handoff. Component pass rates cannot certify a composition when failures are correlated.

Implementability score: 0.78

Sources:
- https://arxiv.org/abs/2608.12895v1
- https://github.com/qualixar/agentassert-abc

### 3. Practice Makes Unsafe: successful trajectories can poison reusable skills

All 21 evolved configurations authored unsafe skill artifacts, and 15 produced fresh-session harm. SafeEvolve reduced unsafe retrieval and later harm with little benign-utility change, but the public artifact is early and lacks a detected license.

Implementability score: 0.72

Sources:
- https://arxiv.org/abs/2608.12851v1
- https://github.com/henrymao2004/misevolve

### 4. PIPES: tool outputs need source-scoped claim authority

Screening response units against semantic priors and provenance cut attack success from 84.7% to 2.3% on the main Gemma 4 evaluation without reducing benign utility. No public implementation artifact was verified.

Implementability score: 0.64

Source:
- https://arxiv.org/abs/2608.12789v1

## What is implementable now

- Import SteerBench-style mirrored proceed-or-hold cases for one high-impact tool.
- Measure joint failures for same-model and cross-model agent routes.
- Quarantine self-authored skills until held-out replay and policy checks pass.
- Add provenance and field semantics to one tool response before it enters model-visible state.

## Current implication

The safe unit is not the model turn. It is the release decision that converts an observation, retained procedure, composed route, or proposed action into runtime authority.
