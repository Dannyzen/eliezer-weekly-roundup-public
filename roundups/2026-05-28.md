# Daily Synthesis: 2026-05-28

Today’s strongest signal: the agent stack is becoming traceable and admission-controlled. Tool catalogs need validation evidence before MCP exposure. Memory systems need operation-level provenance. Search-agent evals need freshness and infeasibility controls. Agent harnesses are moving into enterprise incident response and pytest-native red-team tests.

## Top findings

### 1. Tool artifacts need validation-carrying governance before MCP exposure
- Category: [Strategy](../Strategy/2026-05-28/sovereignty.md#tool-artifacts-need-validation-carrying-governance-before-mcp-exposure)
- Durable topic: [Agent Gateway Governance](../Strategy/agent-gateway-governance/agent-gateway-governance.md)
- Core sources: https://arxiv.org/abs/2605.28000, https://github.com/nextmoca/tool-forge
- Why it matters: Tool Forge treats tools as governed capsules with intent, capability contract, implementation, dependency policy, tests, runtime validation evidence, credential bindings, lifecycle state, and routing metadata. This is the missing admission layer between generated code and MCP exposure.
- Implementable now: require tool manifests, sandbox validation, lifecycle states, credential binding at the gateway, and intent-scoped routing instead of full catalog dumps.
- Implementability score: 0.74

### 2. Memory systems need provenance graphs, not just better retrieval
- Category: [AgenticAI](../AgenticAI/2026-05-28/reasoning.md#memory-systems-need-provenance-graphs-not-just-better-retrieval)
- Durable topic: [Memory Systems](../AgenticAI/memory-systems/memory-systems.md)
- Core sources: https://arxiv.org/abs/2605.28732, https://github.com/zjunlp/MemTrace
- Why it matters: MemTrace turns memory pipelines into executable memory evolution graphs and uses them to attribute failures to operation-level causes like information loss and retrieval misalignment. Memory debugging needs lineage, not final-answer vibes.
- Implementable now: log provenance IDs for writes, merges, summaries, retrievals, source evidence, and final memory use; classify failures by operation; run small adversarial memory suites before changing consolidation prompts.
- Implementability score: 0.58

### 3. Search-agent evals need freshness, feasibility, and evidence-dependence controls
- Category: [AgenticAI](../AgenticAI/2026-05-28/reasoning.md#search-agent-evals-need-freshness-feasibility-and-evidence-dependence-controls)
- Durable topic: [Trajectory-Aware Evaluation](../AgenticAI/trajectory-aware-evaluation/trajectory-aware-evaluation.md)
- Core sources: https://arxiv.org/abs/2605.28721, https://arxiv.org/abs/2605.28532, https://arxiv.org/abs/2605.28556
- Why it matters: LiveBrowseComp shows that search agents can be rewarded for verifying prior knowledge rather than discovering evidence. Feasibility-awareness and TASTE add the other missing controls: know when required tools are absent, and generate harder tasks from tool traces.
- Implementable now: run closed-book baselines, use fresh-fact questions, remove supporting evidence as an ablation, add tool-missing tasks, and score query origin plus abstention.
- Implementability score: 0.72

### 4. Agent harnesses are moving toward enterprise incidents and pytest-native red teams
- Category: [AgenticAI](../AgenticAI/2026-05-28/reasoning.md#agent-harnesses-are-moving-toward-enterprise-incidents-and-pytest-native-red-teams)
- Durable topic: [Agent Harness Architecture](../AgenticAI/agent-harness-architecture/agent-harness-architecture.md)
- Core sources: https://huggingface.co/blog/ibm-research/itbench-aa, https://github.com/microsoft/RAMPART, https://pypi.org/project/RAMPART/
- Why it matters: ITBench-AA reports frontier models below 50% on SRE-style Kubernetes incident response. RAMPART gives the practical complement: pytest-native safety and security tests for agentic applications.
- Implementable now: create incident fixtures with logs, dependency graphs, known root causes, fault injection, and CI assertions for adversarial and benign failure handling.
- Implementability score: 0.82

## Actionable moves

1. Add an admission gate for agent tools: manifest, tests, sandbox result, dependency policy, credential scope, lifecycle state, and routing digest.
2. Instrument memory like a pipeline: every write, merge, retrieval, summary, and final use needs a provenance edge.
3. Stop trusting search-agent benchmarks without closed-book, fresh-fact, evidence-removal, and infeasible-task controls.
4. Put agent red-team tests in CI. Pytest-native fixtures are more useful than another standalone eval dashboard.
