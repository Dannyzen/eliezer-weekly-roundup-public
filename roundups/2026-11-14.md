# Daily Agent Research: Prospective Proof Before Promotion

Date: 2026-11-14

No new Saturday arXiv listing exists. The research papers below were submitted November 12 and first listed Friday, November 13. llama.cpp v1.0.0 was released November 13.

## Top findings

### 1. Memory value belongs in the next task

CoReMem replaces relevance-only memory evaluation with matched next-task trials. Repository anchors and executable checks improved coding-task resolution while reducing steps and total cache-aware tokens.

Implementability score: 0.78

Source: [CoReMem v1](https://arxiv.org/abs/2611.17316v1)

### 2. Harness self-improvement can raise scores without repairing orchestration

MultiLoop improved DeepSearchQA accuracy with ten training samples, but the gains came from prompts and a new tool. Delegation and information-sharing failures remained. Structural coordination needs its own objective and regression suite.

Implementability score: 0.72

Source: [MultiLoop v1](https://arxiv.org/abs/2611.15754v1)

### 3. Agent auditors need benign controls and paired evidence variants

ReA-Bench shows that high risk recall can coexist with severe false positives. Its strongest reusable pattern is diagnostic pairing: risky and authorized-benign traces, plus shortened and evidence-completed variants that isolate retrieval, reasoning, and missing-information failures.

Implementability score: 0.81

Source: [ReA-Bench v1](https://arxiv.org/abs/2611.16493v1)

### 4. llama.cpp v1.0 makes local runtime migration a governance task

The release removes deprecated APIs and changes speculative decoding, cache, MoE, model, server, test, and packaging surfaces. Local-first operators can adopt it now, but only through pinned workload replay and rollback.

Implementability score: 0.93

Sources: [release](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0), [overview](https://huggingface.co/blog/ggml-org/llama-cpp-v1)

## What is implementable now

1. Gate coding-agent memory on measured next-task value.
2. Add structural coordination metrics to harness optimization loops.
3. Audit agents with risky, benign, shortened, and evidence-completed trace pairs.
4. Qualify llama.cpp v1.0 against pinned production-shaped workloads before promotion.

## Implementability range

Highest: 0.93 for a controlled llama.cpp v1.0 qualification and migration.

Lowest: 0.72 for structural multi-agent harness optimization, because the evaluation loop is available but generic score optimization did not repair coordination.

## Signal and limitations
