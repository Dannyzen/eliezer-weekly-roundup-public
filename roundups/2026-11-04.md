# Daily Agent Research: 2026-11-04

## Thesis

Agent systems need provenance at two boundaries: measurement and execution. Evaluators must expose the instrument that produced a score, while runtimes must prove why each consequential effect and argument is authorized.

## Top findings

### 1. Publish the evaluation instrument beside the score

Two public leaderboard audits found missing grades, duplicated cost spans, grader actions mixed into agent traces, and version-sensitive re-grades. The fixes are cheap: graded fractions, root-span cost checks, action provenance, pinned evaluators, and re-grade diffs.

Implementability score: 0.91

Sources: [paper](https://arxiv.org/abs/2611.04399v1), [reproduction repository](https://github.com/YangzeLiu/eval-instrument-disclosure)

### 2. Keep harness evolution local to the run

Meta2 freezes reusable act, avoid, and hold guidance while discarding task-specific harness edits at run end. Carrying edits across tasks reduced results by 2.67 points on Terminal-Bench and 5.33 points on DeepSWE.

Implementability score: 0.67

Sources: [paper](https://arxiv.org/abs/2611.05139v1), [project page](https://meta-square.github.io/)

### 3. Turn skill approval into deterministic runtime obligations

RuntimeTickets narrows host grants into task and skill-version-bound tickets, then enforces recipient, object, amount, and budget at effect boundaries. Its controlled 60-pair study reports no overlooked attempted attacks and no blocked benign runs.

Implementability score: 0.62

Source: [RuntimeTickets](https://arxiv.org/abs/2611.03772v1)

### 4. Authorize critical tool arguments from evidence provenance

Parameter poisoning preserves the intended tool call while changing its arguments. AuthorityFlow traces candidate values to supporting evidence and requires that the source be authorized for that fact and task before dispatch.

Implementability score: 0.70

Source: [Right Tool, Wrong Parameters](https://arxiv.org/abs/2611.04673v1)

## Implementable now

- Add graded, ungraded, failed, and dropped counts to every evaluation cell.
- Deduplicate nested model-call spans and publish evaluator and task-data versions.
- Tag trajectory actions by producer and keep grader replay separate.
- Reset task-local harness edits while retaining reviewed cross-task guidance.
- Compile delivery contracts into effect-bound tickets that can only narrow host grants.
- Require authorized evidence paths for recipients, amounts, locations, and other critical arguments.

## Evidence boundary

All external repositories and project pages were inspected read-only. No external source code was cloned, installed, built, imported, or executed. RuntimeTickets and AuthorityFlow have no verified paper-owned public implementation artifact. Meta2 code is marked coming soon. The RuntimeTickets result uses mock services, and the leaderboard audit covers two public systems.
