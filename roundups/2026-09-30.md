# Deep Dive Wednesday: 2026-09-30

## Thesis

The model-harness pair is becoming the deployment unit of the agentic stack. Raven is the strongest finding from the last seven days because it turns specialist discovery, dependency planning, artifact handoff, persistent context, and harness adaptation into one inspectable composition architecture.

## Weekly deep-dive winner

### Treat the model-harness pair as a governed worker

Raven exposes heterogeneous model-harness pairs as callable workers, then coordinates them through a Host Agent, capability registry, dependency graph, artifact ledger, and persistent archive. The public repository includes ACP, CLI, and OpenAI-compatible adapters plus presets for 13 third-party agents, including Hermes Agent.

The 140-request orchestration benchmark reported exact graph match of 0.711 versus 0.607 for the strongest Qwen3.8-27B baseline and 0.867 versus 0.762 for the strongest DeepSeek-V4-Flash-0731 baseline. The result supports better specialist selection and dependency planning. It does not establish end-to-end reliability across independently operated workers.

Action now: prototype a versioned worker contract, deterministic graph admission, immutable artifact IDs, authority manifests, and terminal receipts. Compare the composed graph with the best standalone worker before promotion. Defer self-evolution and shared group memory.

Deep dive: [Composable Agent Harnesses](../AgenticAI/composable-agent-harnesses/composable-agent-harnesses.md)

Implementability score: 0.68

Sources: [Raven paper](https://arxiv.org/abs/2609.33439v1), [Raven repository](https://github.com/EverMind-AI/Raven)

## Supporting signals from the daily scan

### 2. Benchmarks need executable contracts below their scores

The tool-contract audit confirmed seven tool defects and one evaluator property across 34 mutating tools in four benchmarks. A success string can agree with a grader while no state changes. The public artifact supplies contract schemas, static checks, dynamic probes, mutation tests, and score provenance.

Action now: require tool preconditions, state transitions, returns, and evaluator reads to pass before trusting model rankings.

Implementability score: 0.86

Sources: [Executable-contract audit](https://arxiv.org/abs/2609.37315v1), [replication artifact](https://github.com/rohithreddybc/tool-contract-conformance)

### 3. Prompt-injection evaluation should be a composable matrix

pikit separates attack wording from delivery channel, defense, target agent, trace, and verdict. The public toolkit includes 13 attacks, 16 carriers, 9 prevention strategies, and runtime adapters for OpenClaw and Hermes Agent.

Action now: use it as a fixture generator and trace collector, then add environment-specific delivery receipts and exact-effect predicates.

Implementability score: 0.88

Sources: [pikit paper](https://arxiv.org/abs/2609.36817v1), [pikit repository](https://github.com/Tencent/AI-Infra-Guard/tree/main/Research/pikit)

### 4. Bind authority before context and effect release

ToolFence binds effect classes and argument provenance in reusable capability shapes. Audience-Bound Persistent Memory carries viewer scope through capture, derivation, grants, and retrieval. Together they define the same control rule: authority must be explicit before the model sees sensitive context or dispatches a consequential action.

Action now: add typed action manifests, audience labels, provenance-preserving derivation, object-specific grants, and exact context and effect receipts.

Implementability scores: 0.64 for typed effect authorization; 0.58 for audience-bound memory.

Sources: [ToolFence](https://arxiv.org/abs/2609.37196v1), [Audience-Bound Persistent Memory](https://arxiv.org/abs/2609.36373v1)
