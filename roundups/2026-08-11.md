# Daily Agent Research Roundup, 2026-08-11

## Thesis

Agent reliability depends on which facts the runtime holds invariant while the model handles uncertainty. Today's strongest findings separate a deterministic control surface from an adaptive agent loop.

## Top findings

1. SpecPath exposes specification-path dependence: 35 of 100 complete passing blocks failed under at least one equivalent history. Score: 0.91.
2. TRACE attributes context failures before choosing a bounded CREATE or UPDATE repair. Score: 0.74.
3. OpenCodeReview combines deterministic dispatch and admission with bounded agent investigation. Score: 0.96.
4. POLIS shows that immutable provenance and recoverable denials prevent policy laundering. Score: 0.82.
