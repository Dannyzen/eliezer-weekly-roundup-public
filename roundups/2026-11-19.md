# Daily Agent Research Roundup: 2026-11-19

## The signal

Agent state is becoming governable in two different ways. Memory and instruction changes can be made visible, testable, and reversible. Tool execution still needs stronger controls because visible intent and broad permissions do not prove that a specific effect is authorized.

## Top findings

### 1. Gate personal-agent updates against the incumbent

Safe Personal RSI rejects candidate instruction updates unless they beat the current version on both safety and task utility. It rejected 20 of 21 risky update attempts in its reported study.

Source: https://arxiv.org/abs/2611.23651v1

Implementability score: 0.72

### 2. Make memory visible, scoped, and reversible

MemoSync gives developers a local workbench for reviewing memory changes, choosing turn context, tracing cited memories, and auditing actual use. The public MIT repository supports Codex, Claude, Pi, and OpenCode.

Sources: https://arxiv.org/abs/2611.24165v1 and https://github.com/SLEEPYBQ/MemoSync

Implementability score: 0.86

### 3. Treat intent contracts as provenance, not authorization

Intent Contracts improves attribution and task completion under benign extra work, but wrong-target actions remain at 40% to 49% when the trusted side cannot resolve environment references. Add live target resolution and final effect checks.

Sources: https://arxiv.org/abs/2611.24025v1 and https://github.com/zwang-devv/intent-contracts

Implementability score: 0.76

### 4. Compile skill prose into enforceable control flow

SkillCFI blocked all 240 tested procedural violations before dispatch and improved refusal recovery by listing legal next steps. Its source is not public yet, and none of 53 public skills passed compilation unchanged.

Source: https://arxiv.org/abs/2611.24185v1

Implementability score: 0.52

## What to build now

- Treat instruction and memory edits as release candidates.
- Add a visible memory board with scope, version, selection, citation, and audit.
- Log intent contracts for attribution.
- Resolve targets and authorize effects against current state at dispatch.
- Convert critical skill obligations into host-observable transition checks.

## Signal and limitations

All four papers were submitted on 18 November and first listed on 19 November 2026. MemoSync and Intent Contracts have public artifacts inspected read-only. SkillCFI promises a later code release. Safe Personal RSI exposes a method and results without a verified public implementation. No external repository code was executed.
