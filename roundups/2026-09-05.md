# Daily Agent Research - 2026-09-05

## Thesis

A cheap check is not acceptance, and a missing stop is not a missing skill. Saturday has no new arXiv listing; the newest batch is Friday, 4 Sep 2026. The unused Friday papers still change the stack: a PoC that no longer crashes can be a memorized historical patch, a GUI agent that keeps clicking under a conflict is executing without a gate, traces become memory only after indexed provenance, and tool-loop latency falls only if speculation commits into an isolated snapshot.

## Top findings

### 1. Crash-pass is not a vulnerability patch

SEC-BENCH's top three agents clear Single-PoC rates above 97%, then drop to 75-82% with multiple PoCs and to roughly half with semantic validation. 25% of agent patches match historical developer fixes. 81% of Codex + GPT-5.6 Sol patches edit the crash stack even when the root cause is elsewhere. PatchBench transplants and mutates vulnerabilities so those shortcuts fail.

Implementable now: related-PoC plus semantic oracles, diff-aware similarity against historical patches, crash-stack versus root-cause counters.

Implementability score: 0.70

Source: https://arxiv.org/abs/2609.04075v1

### 2. Index traces as an owned dataset, not a chat archive

funes indexes Claude Code, Codex, pi, and Hermes sessions into one local Lance memory, returns original text with session/turn provenance, and can publish a private-by-default Hugging Face dataset. Embedding stays on-device. The installer hook is a privileged admission object.

Implementable now: local `recall`/`get` over existing sessions; keep Hub publish optional and private; pin the binary and review the hook.

Implementability score: 0.88

Sources:
- https://huggingface.co/blog/funes
- https://github.com/huggingface/funes

### 3. GUI agents must terminate on conflict

Vanilla GUI agents stay below 10% conflict success and above 70% False Execution. ConflictGuard adds a feasibility check plus conditional steering toward termination. Feasible-task performance is preserved.

Implementable now: terminate-with-conflict as a first-class action; FEX as a separate metric; ConflictGUI's two conflict classes as fixtures.

Implementability score: 0.64

Sources:
- https://arxiv.org/abs/2609.03438v1
- https://github.com/serein356/ConflictGuard

### 4. Speculate into a snapshot, commit only on first-action match

Speculative Macro Commit drafts multi-step macros with a cheap model on an isolated snapshot, then commits only when the actor's next call matches the first drafted action. On AppWorld, wall time falls 44.9% versus sequential execution, with TGC 70/168 to 68/168.

Implementable now: isolated draft environments, exact first-action match before commit, macros as a runtime library rather than extra tools.

Implementability score: 0.55

Source: https://arxiv.org/abs/2609.03236v1
